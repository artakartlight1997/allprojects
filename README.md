## 作りかたの方針

- **ブラウザだけで動く。** サーバー処理なし、インストール不要
- **ビルドしない。** 素の HTML / CSS / JavaScript をそのまま置く
- **ライブラリを入れない。** three.js なども使わず、必要なぶんだけ手で書く
- **画像ファイルをなるべく使わない。** 絵はコードで描く（読みこみが速い）
- **音のファイルも使わない。** 音は WebAudio でその場で波を作る
- **よこ向き**が基本。たてに持つと「よこ向きにしてね」と出る
  （みんなでパーティだけは、たてでも あそべるようにしてある）
- 遊んだ記録は `localStorage` にのこる（サーバーには何も送らない）
- スマホで重くならないよう、**CPU をおとして測ってから**調整する
- **ボタンは 指で 押せる 大きさに。** よこ持ちのスマホは たてが みじかいので
  見た目を大きくしすぎると 画面がせまくなる。そこで
  **「まずきっちり当てる → どれにも当たらなかったときだけ、まわりを少しひろげて
  もう一度さがす」**の2段がまえにして、見た目はそのままで
  指の当たるはんいだけ 40px 以上にしてある（`hitBtn` / `hitRect`）

## メニューの ならびは `games.js` に 書く

**あたらしいゲームを足したのに、メニューに出てこない**ことがあった。
ブラウザが `index.html` をしばらくおぼえてしまうため。

そこでゲームのならびを `momo-adventure/site/games.js` に出して、
`index.html` からは `<script src="games.js?v=N">` で読むようにした。
ふだは JS がならべる（見た目は前とまったく同じ）。

**ゲームを足したら `index.html` の `games.js?v=` の数字を1つふやすこと。**
それだけでかならず新しいならびになる。

## 上の おび（どのゲームからでも メニューへ）

`momo-adventure/site/gamebar.js` が、ぜんぶのゲームの上に
**「≡ ゲームをえらぶ」「やりなおす」**のおびを出す（canvas の外の HTML）。
1か所直すと 65 本すべてに効くので、直したら 何本か 確かめること。

- よこ持ちのスマホでは おびを 34px、それ以外は 38px
- ボタンのまわりに **見えない 押せるはんい**（`::after`）を 13px ひろげてあるので、
  見た目 26px でも 指の当たるはんいは **40px 以上**
- よこが 560px より せまいときは ゲーム名を消して ボタンに場所をゆずる
- りなの大冒険・りなの大冒険2・おるの大冒険は、おびと同じボタンを
  画面の中にも描いていて **二重になっていた**。おびがあるときは描かない
  （`window.__gamebar` を見る）。おびが読みこめなかったときだけ出る

## 配信

`.github/workflows/pages.yml` が main への push で GitHub Pages に置く。

- `momo-adventure/site/` → サイトの root（`/play/` に りなの大冒険）
- `nihon-quest/site/` → `/nihon/`（むかしからの URL を変えないため）
- そのほかは `<フォルダ名>/site/` → `/<フォルダ名>/`

**あたらしいゲームを足すときに、ここへ書き足す必要はない。**
`*/site` をぜんぶ拾うので、フォルダを置くだけで公開される。
（以前はゲームを1つずつ手で並べていて、6本足したときに書き忘れ、
その6本だけ「ページが見つかりません」になった。同じ失敗をしないよう自動にした）

js や css を直したら、そのゲームの `index.html` の `?v=` の番号を
1つ増やすこと（ブラウザが古いファイルを使いつづけるのを防ぐため）。

## むかしのゲームと 共通エンジン

むかしのゲームセンターや 1980 年代のパソコン（MSX）、
手のひらサイズの液晶ゲームをもとにした 10 本
（`dig` / `climb` / `invader` / `pyramid` / `tsumi` /
`catch` / `bomb` / `dash` / `gold` / `sky`）は、
`momo-adventure/site/arcade.js` を共通のどうぐとして使っている。

- 画面わりつけ（たて持ちなら 90 度まわして画面いっぱい）
- ゆびを置いたところに出るスティック／わざボタン
- リナパパとまるいてきの絵
- 効果音と BGM（ファイルなし・その場で合成）
- めん えらび と クリア／ゲームオーバーのまく

なので各ゲームは `site/game.js` 1 本だけ。ルールと絵に集中している。
共通どうぐを直すと 10 本すべてに効くので、直したら 10 本ぶん確かめること。

あたらしい 5 本のもとになったもの:

| ゲーム | もと |
| --- | --- |
| たまごキャッチ | 手のひらサイズの液晶ゲーム（たまごをうける） |
| ばくだんめいろ | ばくだんでブロックをこわすアクション |
| なんきょくダッシュ | 氷の上を走る奥行きのあるアクション |
| おたからランナー | あなをほって金貨をあつめるアクションパズル |

## りなシリーズと 絵の としょかん

りなシリーズのうち 絵に かわいい ものが 出る 5 本
（`point` / `spot` / `memo` / `shop` / `slice` / `draw`）は、
`momo-adventure/site/rinaart.js` を共通の絵の としょかんとして使っている。

- `ITEMS` … りんご・ねこ・ほし など 20 しゅるい。`draw(x, y, s, col)` で描く
  - `en` / `ens` / `a` は英語（1つ・2つ以上・a か an）。えいごポインターで使う
  - `cols` はその ものが とれる色。まちがいさがしの「色ちがい」で使う
- `drawRinaFace` / `drawRinaBody` … りな本人

1 か所直すと 6 本すべてに効くので、直したら 6 本ぶん確かめること。

### えいごポインターの かんがえかた

`this / that / these / those / it / they / which / what` を
**絵の位置**だけで説明する。画面には いつも
「りなの すぐ前の台（ちかい）」と「むこうの台（とおい）」の 2 つしか出さない。

| | 1つ | 2つ以上 |
| --- | --- | --- |
| ちかい | This | These |
| とおい | That | Those |
| （もう話題に出ている） | It | They |

`which` は「どれ？」＝ならんだ中から えらぶ、`what` は「なに？」＝名まえを こたえる。
読みあげはブラウザの `speechSynthesis`（音声ファイルは使わない）。
使えない機械では だまって すすむ。

## エイトくんの ぼうけん島 のしくみ

1980年代の「ぼうけん島」もの。**南の島**がぶたい。
たいりょくがつねにへるので、走りながらフルーツを食べつづける。

### ジャンプをていねいにした

「ジャンプがぎこちない」と言われたので、いまのアクションゲームで
あたりまえになっているものを一通り入れた。

| しくみ | なにをするか |
|---|---|
| じわっと加速・げんそく | 前は速さがパッときりかわっていた。地面・空中・こおりで効きがちがう |
| **コヨーテ時間** | 足場をすぎたあとも 0.10びょうはジャンプできる |
| **さきおし（バッファ）** | 着地の 0.12びょう前におしても、着いたしゅんかんにとぶ |
| **てっぺんはゆっくり** | 上がりきるあたりだけ重力を 0.55ばいに。ふわっとする |
| 上がりと落ちで重力がちがう | 上がり 40 / 落ち 62。落ちがきびきびする |
| ボタンをはなすと止まる | 重力 96。高さを自分で決められる |
| ぐにゃっと（squash & stretch） | ふみきりと着地で体がのびちぢみする |

数字で確かめた: 走ってフルジャンプ **高さ3.14マス・とどく6.53マス・空中0.80びょう**、
ちょいジャンプ **2.34マス・4.13マス・0.50びょう**。コヨーテ時間とさきおしも
「ほんとうにとべるか」をテストで確認している。

### こうげきを4つに

ふみつけ／**スライディング**（下に入れながら走る。てきを倒し、
ひくいすきまもくぐれる）／**なげもの**（おの・ブーメラン・ばくだん）／
スケボーとっしん。なげものはたまごから出て、たまかずがある。

### 島らしさ

- **地けいがめんの名まえのとおり**。すなはま（やしの木・いかだ）／ジャングル（つた・木の上の道）／
  いわば（かいだん・落ちる岩）／かざん（ようがん・こわせるブロック）／さんご（はすの葉・さんご）／
  こおり（すべる床・こおりのさか）／しつげん（どろ・あし）／どうくつ（くらい・ようがん）／
  そらのいせき（うかぶ足場・こわれたはしら）／しろ（たいまつ・トゲ）
- **てき9しゅるい**: スライム・カニ（**上がかたくてふめない**）・へび・さかな（水からとびはねる）・
  タコ（すみをなげる）・むし・コウモリ（近づくとおそう）・ハチ（**とげがあってふめない**）・落ちる岩
- **天気がかわる**（はれ→くもり→あめ→かみなり→きり→よる）。22びょうごと。
  **かみなり**は落ちるところにまるいしるしが1びょう出てから落ちる（見てからよけられる）
- **BGMをアクションぽく**書きなおした。16分でずっと動くベース＋ドラム＋メロディ。
  テーマごとに音階とはやさがちがう（かざんは速くて低い、など）。ボス戦は音が高くなる

### ボスを10たい

どのしまにもボスがいて、たおすとゴールがひらく。
ヤドカリ大王／ハチのじょおう／いわのゴーレム／マグマへび／おおダコ／
こおりのフクロウ／どくガエル／コウモリ王／いしのとり／まおう。
どれも**あいずを出してから**こうげきする。**ふめるボスとふめないボス**がいる。

### ロボットと「けんさプログラム」で直したこと

めんの通れるかどうかは、ロボットまかせにせず**ルールでけんさ**している
（あな・ひくい天じょう・あぶないマスの連続・うまったアイテム）。見つけて直したもの:

| 見つかった問題 | どう直したか |
|---|---|
| **たすけの足場がようがんの中にできていた**（見えないしのれない） | 高さをりょうどなりの地めんから決める |

## スポーツゲーム 3本 のしくみ

`soccer` / `tennis` / `baseball` も `arcade.js` の上の 1ファイルのゲーム。
「ボタンを小さくしない」「タイミングは音の時計で計る」はダンス3本と同じ。

**まさきのPKサッカー**（`soccer/`）

- ける番は **「9つのまとから1つえらぶ」→「左右にゆれるゲージを止める」**の2だんかい。
  まん中で止めるほどねらったところへ飛び、ずれるとたまもずれて、わくの外にも出る
- まもる番は とぶところをえらぶ。ける直前に相手の目線がちらっと光る（ヒント）。
  つよい相手ほどヒントがみじかい
- 5本ずつで多いほうが勝ち。**おたがい同じ本数うったときだけ**勝敗を見る
  （かたほうだけ多くうった時点で判定すると不公平になるため）。同点なら延長

**りなのテニス**（`tennis/`）

- ゆびを置いたところへ走り、タップでうつ。ラケットのどこで当てたかでコースが変わる
- **走る速さに上限がある**（コート横断に約1.2秒）。上限がないと指の位置へ
  ワープしてどんな球もとどいてしまい、ゲームにならない
- ボールのよこ速度は**飛行時間から逆算**している。速度を一定係数にしていたときは、
  速い球ほどねらったすみに届かず、ラリーが100回以上つづいてしまった
- ラリーがつづくほど球が速くなる（最大2.6倍）。これがないと決着がつかない

**あおいのホームランきょうそう**（`baseball/`）

- ボタンは画面ぜんぶの1つだけ。球は5しゅるい（ストレート・はやい・おそい・カーブ・
  フォーク）で到達時間がちがうので、リズムをおぼえるのがコツ
- ±0.045秒でホームラン（3てん）、±0.10秒でヒット（1てん）、±0.16秒でファウル
- もくひょうの点をとればクリア。目標はだいたい満点の6わりくらいに置いている

## ダンスゲーム 3本 のしくみ

`dance` / `mane` / `freeze` の 3本は、どれも `momo-adventure/site/arcade.js`
（むかしのゲーム10本と同じ共通エンジン）の上に作ってある。
なので各ゲームは `site/game.js` 1本だけ。

**共通の考えかた**

- **タイミングは「音の時計」で計る。** 画面のコマ送りは1コマ16msずれるので、
  判定には使わない。ゆびが画面についた瞬間の `AudioContext.currentTime` と、
  音符の時刻をくらべる。スピーカーから音が出るまでのおくれ（`outputLatency`）も
  足してそろえる
- **曲はファイルなし。** その場で音を組み立てる。1小節ぶんずつ、1秒くらい先まで
  先回りして予約する（`pumpMusic`）
- **ねらう場所を小さくしない。** ダンスステージは画面をたてに4つに割ったまるごと、
  フリーズは画面のどこでもいい

**りなのダンスステージ**（`dance/`）

- 上からおりてくるやじるしを、下のパネルにかさなった瞬間にタップ
- ふりつけは曲ごとにコードから自動で作る（`buildChart`）。同じ曲ならいつも同じ
  ならびになる（種つきのさいころ）
- **やじるしのならび＝メロディ。** ふんだ音がそのまま曲になるので、
  合っていると気もちがいい
- 判定は パーフェクト(±0.075秒)／グッド(±0.135)／セーフ(±0.20)。
  それより外れたタップは**なかったことにする**（子どもをミスにしない）
- 見のがすと「げんき」がへる。ゼロで終わり。全10きょく・最初から全部えらべる

**あおいのまねっこダンス**（`mane/`）

- せんせいのポーズの順番をおぼえて、同じ順に下のふだをおす
- ポーズは6しゅるい。1つずつ音（ドミソシレファ#）がついていて、
  ならびがメロディになるので耳でもおぼえられる
- ポーズの絵は手を長くして先に手（まる）をつけ、ひと目で見分けられるようにした

**ゆいのダンスフリーズ**（`freeze/`）

- 音楽の間は画面をおしっぱなしでおどる。止まったらすぐゆびをはなす
- 止まる場所は小節のきりのいいところ。何小節つづくかは毎回かわる
- 早くはなすと「はやすぎ」、おそいと「うごいちゃった」。±0.15秒で「ぴったり」
- おす／はなすの時刻も音の時計でとる（`pressAt` / `releaseAt`）。
  ボタンをおしたときは数えない

## りなの大冒険2 のしくみ

1作目（`/play/`）を下じきに、**マリオとドンキーコングの要素**を足した
横スクロールアクション。ステージは `rina2/tools/genlevels.py` が作って
`rina2/site/levels.js` に書き出す（手で直さないこと）。

- **全25ステージ。最初からぜんぶ選べる。** クリアしたステージには ★ がつく
- **どのステージにも大きなボス**（25たい）。ボスは 8しゅるいの こうげきを
  順ぐりに出してくる（山なりのたま／3方向／地面をはしる衝撃波／こぶんを出す／
  ためてビーム／上からふらせる／とっしん／全方向にばらまく）
- **ケーキで大きくなる**（マリオのキノコ）。もう一度アイテムブロックを
  たたくと**ぶき**が出る。ぶきは 4しゅるい
  （ハートだま＝はずむ弾／こおりだま＝敵をこおらせて足場にする／
  ブーメラン＝行ってもどる／ハンマー＝目の前をなぐる。トゲの敵も倒せる）
- やられると ぶき → 大きい → ちび の順に1だんずつ下がる（マリオと同じ）
- **土管**で地下のコイン部屋へ。**4本ぜんぶ**入れて、行き来できる。**はしご**でのぼりおり
- **たる**がころがってくる、**ベルトコンベア**、**くずれる足場**、
  **とつぜんトゲ**、**ばね**、**移動床**
- 後半は遊びかたが変わる：**水中（およぐ）**／**低重力（宇宙）**／
  **くらやみ（まわりしか見えない）**／**オートスクロール**
- **かぜ**（よこに押される）、**ふきあげ**（上むきの風でふわっと上がる）、
  **こおりのゆか**（すべってすぐ止まれない）
- テーマは 家・学校・海・おかし・森・空・アート・工場・宇宙・城 など25種類

### 作るときに気をつけたこと

- **ジャンプの力は √重力 でスケールする。** 低重力の面でそのままにすると
  高さ7タイル・よこ13タイルも跳んでしまい、跳んでいるあいだ何もできずに
  穴に落ちる。√をかけると高さはいつもと同じまま、ふわっと長く跳べる
- **アイテムはブロックの上に浮かせない。** そのブロックがじゃまでとどかない。
  マリオのキノコと同じで、歩いておりてきて地面の上を行き来する
- **穴は3マスまで。** ジャンプは5.8マスとどくので、移動床やくずれる足場は
  「あるとらく」くらいにして、乗れないと進めない形にはしない
- **ボスは登場演出が出るまで動かない。** でないと広場に入る前に画面の外から
  たまが飛んできて、わけもわからずやられる
- **水の中に置くしるしは E（さかな）と Q（コイン）。** ふつうの e/o にすると
  しるしを消したところが水でなくなり、およいでいる途中で穴に落ちる
- ボス広場はゆかを1だん高くして、ボスが外へ出ないようにしている
- **うすい足場（= と F）は下からすりぬける。** かたい壁にしていたので、
  穴の上の足場に頭をぶつけてそのまま穴へ落ちることがあった
- **どかんは4本ぜんぶつながっている。** 出口のどかんに行き先がなく、
  ▼を押しても何も起きなかったので「ワープしない」と言われた。
  ▼を押しっぱなしだと行ったり来たりするので、一度はなすまで入らない
- **ボスの前に、ブロックを待たなくても拾えるぶきを置いてある**
  （「ボス戦はアイテムがないとむり」と言われたため）

## あそび きろく（管理用）

`/allprojects/stats/` は、どのゲームをどれだけ遊んだかを見るページ。
**メニューには載せていない**（入口は URL だけ）。
開くときに 4 桁のばんごうを聞く（`momo-adventure/site/stats/index.html` の
`var PIN` で変えられる）。

- 記録するのは `momo-adventure/site/stats.js`。全ページの `index.html` から読んでいる。
  ゲーム側のプログラムには手を入れていない。
- とっているのは「ひらいた回数」「画面に出ていた秒数」「セーブが変わったこと
  （ハイスコア・クリア数など）」の 3 つだけ。
- 記録は **その端末の localStorage の中だけ**。どこにも送っていない。
  サーバーがなく、公開リポジトリなので送信先の鍵を置けないため。
- 端末をまたいで見たいときは、各端末で「コピー」して管理ページに貼り、「合体」する。
  端末ごとの id で分けて持つので、同じものを何回合体しても数字は増えない。
- プレイヤーの画面には何も出ない。

**注意**: PIN はブラウザの中で比べているだけなので、子どもがうっかり入らない
ための止め木であって、本当の錠前ではない（ページの中身は誰でも読める）。
ただし記録そのものは見る人の端末の中にしかないので、他人が開いても
他人自身の記録が空で見えるだけ。
