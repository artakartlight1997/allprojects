## 作りかたの方針

- **ブラウザだけで動く。** サーバー処理なし、インストール不要
- **ビルドしない。** 素の HTML / CSS / JavaScript をそのまま置く
- **ライブラリを入れない。** three.js なども使わず、必要なぶんだけ手で書く
- **画像ファイルをなるべく使わない。** 絵はコードで描く（読みこみが速い）
- **音のファイルも使わない。** 音は WebAudio でその場で波を作る
- **よこ向き**が基本。たてに持つと「よこ向きにしてね」と出る
  （みんなでパーティだけは、たてでも あそべるようにしてある）
- 遊んだ記録は `localStorage` にのこる（サーバーには何も送らない）
- スマホで重くならないよう、**CPU をおとして測ってから**調整する

## 配信

`.github/workflows/pages.yml` が main への push で GitHub Pages に置く。
`momo-adventure/site/` の中身がサイトの root に、
ほかは `/nihon/` `/rinaleon/` `/osouji/` `/slime/` `/craft/` `/escape/` `/rhythm/` `/fuwa/` に入る。

js や css を直したら、そのゲームの `index.html` の `?v=` の番号を
1つ増やすこと（ブラウザが古いファイルを使いつづけるのを防ぐため）。

## リナパパの 5本と 共通エンジン

むかしのゲームセンターのゲームをもとにした 5 本
（`dig` / `climb` / `invader` / `pyramid` / `tsumi`）は、
`momo-adventure/site/arcade.js` を共通のどうぐとして使っている。

- 画面わりつけ（たて持ちなら 90 度まわして画面いっぱい）
- ゆびを置いたところに出るスティック／わざボタン
- リナパパとまるいてきの絵
- 効果音と BGM（ファイルなし・その場で合成）
- めん えらび と クリア／ゲームオーバーのまく

なので各ゲームは `site/game.js` 1 本だけ。ルールと絵に集中している。
共通どうぐを直すと 5 本すべてに効くので、直したら 5 本ぶん確かめること。

## あそび きろく（管理用）

`/allprojects/stats/` は、どのゲームをどれだけ遊んだかを見るページ。
**メニューには載せていない**（入口は URL だけ）。
開くときに 4 桁のばんごうを聞く（`momo-adventure/site/stats/index.html` の
`var PIN` で変えられる）。

- 記録するのは `momo-adventure/site/stats.js`。全ページの `index.html` から読んでいる。
  ゲーム側のプログラムには手を入れていない。
- とっているのは「ひらいた回数」「画面に出ていた秒数」「セーブが変わったこと
  （ハイスコア・クリア数など）」の 3 つだけ。
- 記録は **その端末の localStorage の中だけ**。どこにも送っていない。
  サーバーがなく、公開リポジトリなので送信先の鍵を置けないため。
- 端末をまたいで見たいときは、各端末で「コピー」して管理ページに貼り、「合体」する。
  端末ごとの id で分けて持つので、同じものを何回合体しても数字は増えない。
- プレイヤーの画面には何も出ない。

**注意**: PIN はブラウザの中で比べているだけなので、子どもがうっかり入らない
ための止め木であって、本当の錠前ではない（ページの中身は誰でも読める）。
ただし記録そのものは見る人の端末の中にしかないので、他人が開いても
他人自身の記録が空で見えるだけ。
