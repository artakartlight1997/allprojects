# きょうだいオールスター

これまでに作った 33 本のゲームから「いちばんおいしいところ」だけを抜き出し、
数秒のミニゲームにして次々に出す耐久ハイスコアゲーム。
りな・まさき・あおい・ゆいの 4 人きょうだいがそのままライフになっている。

公開先: <https://artakartlight1997.github.io/allprojects/allstar/>

## あそびかた

- ミニゲームが出た瞬間の大きな文字が「やること」
- そうさは 2 つだけ。**さわってうごかす** と **タップ**
- しっぱいするときょうだいが 1 人こうたい。4 人ぬけたらおしまい
- 5 本クリアするたびスピードアップ（ぜんぶで 7 だんかい）
- 12 本ごとにボス「パパロボ」が出てくる

## しくみ

- 画像ファイル・音声ファイルは 1 つも使っていない。
  絵はぜんぶ canvas に描き、音はぜんぶ WebAudio でその場で作る。
- ミニゲームは 0〜1 のざひょうで書き、`X(u)` `Y(v)` `R(k)` で画面に合わせる。
  よこ（u）とたて（v）は目もりの大きさがちがうので、あたりはんていは
  `toH()` でたての単位にそろえてから比べる。
- たてに持ったスマホでは中みを 90 度まわして画面いっぱいに使う
  （画面回転ロックが入っていても大きくあそべる）。
