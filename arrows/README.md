# りなの やじるし だっしゅつ

やじるしを タップすると、やじるしの むきに にょろにょろ すすんで ばんの そとへ でていく。
とちゅうに ほかの やじるしが あると ぶつかって ハートが へる（3つ）。
**とおれる やじるしから じゅんばんに** ぜんぶ にがせたら クリア。全30めん。

https://artakartlight1997.github.io/allprojects/arrows/

2026年に ダウンロード ランキングの 上の ほうに いる「Arrows – Puzzle Escape」
「Arrows GO!」などの やじるし だっしゅつ パズルと 同じ あそび。

## あそびかた

- やじるしを タップ → むきの ほうへ でていく（まがった やじるしは からだが あとから ついてくる）
- ぶつかると ハートが 1つ へる。3つ なくなったら やりなおし
- こまったら「ヒント」（1めん 3回）で いま だせる やじるしが ひかる
- のこった ハートの かずが ★ に なる

## めんの つくりかた

めんは たねつきの らんすうで じどうで 作る（まいかい 同じ めん）。
「あたまの まえが そとまで あいている やじるし」を 1本ずつ くわえて いくので、
**くわえた ぎゃくの じゅんに だせば かならず とける**。
30めん ぜんぶ、じどうで といて とけることを たしかめた。
ばんは 5×5 から 10×10 まで だんだん 大きく、やじるしも 長く なる。
