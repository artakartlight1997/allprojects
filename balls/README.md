# まさきの ボールふえふえ 大くずし

ボールが「×2」「×3」「×5」で どんどん ふえて、ブロックが 一気に くずれる ブロックくずし。
全15めん（5めんごとに ボス）。

https://artakartlight1997.github.io/allprojects/balls/

ブロックくずし と「ボールが ふえる」を まぜた ゲーム（BALL x PIT など）が
はやっているので、その いちばん きもちいい ところ＝**ふえた ボールで 一気に こわす** を
子どもでも すぐ あじわえる ように した。

## あそびかた

- 画面を なぞると パドルが うごく（ゆびの 下に かくれない ように、うごかした ぶんだけ うごく）
- タップで ボールを うつ。やじるしキー と スペースでも OK
- ボールが ぜんぶ おちると のこりが 1へる（3回まで）

## ボールが ふえる しくみ

| | なに | どうなる |
|---|---|---|
| ×2 / ×3 / ×5 アイテム | 黄色い ブロックや、ときどき ふつうの ブロックから おちてくる | **いま ある ボール ぜんぶ**が 2・3・5ばいに |
| +8 アイテム | 「+8」ブロック | パドルから 8こ でる |
| ゲート（×2 / ×3 の バー） | めんに おいてある。うごく ものも ある | **したから とおりぬけた** ボールが ふえる（1つの ボールは 1つの ゲートで 1.2びょうに 1回） |
| ワイド | ランダム | パドルが 12びょう ひろがる |
| ファイア | ランダム | 8びょう ボールが ブロックを つきぬける |

ボールは さいだい 400こ（スマホで おもく ならない ように）。
90こ いじょう でている ときも 60fps で うごくのを たしかめた。

## ブロック

数字は かたさ（その かいすう あてると こわれる）。💣 は まわり 8マスも いっしょに こわす。
ボスは よこに うごく でかブロックで、HPが 0に なるまで あてる。

クリアで ★（のこりの かず）。つぎの めんが ひらく。記ろくは `localStorage`（`ballsfuefue.v1`）。
