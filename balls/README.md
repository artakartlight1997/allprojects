# まさきの ボールふえふえ 大くずし

ボールが「×2」「×3」「×5」で どんどん ふえて、ブロックが 一気に くずれる ブロックくずし。
全**40めん**（5めんごとに ボス。あとの ボスほど つよくて はやい）。

https://artakartlight1997.github.io/allprojects/balls/

ブロックくずし と「ボールが ふえる」を まぜた ゲーム（BALL x PIT など）が
はやっているので、その いちばん きもちいい ところ＝**ふえた ボールで 一気に こわす** を
子どもでも すぐ あじわえる ように した。

## あそびかた

- **スマホを たてに もって あそぶ**（たて長 画面いっぱい。「あそぶ」で 全画面に なる）。
  パソコンの よこ長 画面では まんなかに たてで 出る

- 画面を なぞると パドルが うごく（ゆびの 下に かくれない ように、うごかした ぶんだけ うごく）
- タップで ボールを **5こ いっぺんに** うつ（さいしょの 6びょうは シールドで おちない）。やじるしキー と スペースでも OK
- ボールが ぜんぶ おちると のこりが 1へる（3回まで）

## ボールが ふえる しくみ

| | なに | どうなる |
|---|---|---|
| ×2 / ×3 / ×5 アイテム | 黄色い ブロックや、ふつうの ブロック（4こに 1こ くらい）から おちてくる | **いま ある ボール ぜんぶ**が 2・3・5ばいに |
| +10 アイテム | 「+8」ブロック・ランダム | パドルから 10こ でる |
| +30（ボール ばくはつ） | ランダム | パドルから 30こ いっせいに |
| シールド | ランダム | 10びょう したに おちない（ボールが たまって どんどん ふえる） |
| ゲート（×3 / ×4 の バー） | めんに おいてある。うごく ものも ある | **したから とおりぬけた** ボールが ふえる（1つの ボールは 1つの ゲートで 0.8びょうに 1回） |
| ぶんれつ | ブロックを こわすと 5こに 1こ | ボールが 1こ ふえる |
| ワイド | ランダム | パドルが 12びょう ひろがる |
| ファイア | ランダム | 8びょう ボールが ブロックを つきぬける |

ボールは さいだい **1200こ**。1200こ でも 1コマ 4ms くらいで うごく（ボールは いろ ごとに まとめて かく）。

## もりあげ

- ×3！ などの 大きな もじ・画面が ひかる・ゆれる・こなごなが とびちる
- 「ボール 100こ とっぱ！」（50・100・200・300・500・800・1000・1200）
- コンボ（つづけて こわすと ふえる。音も だんだん 高く なる）
- ボール 100こ いじょうで にじいろ、300こ いじょうで **フィーバー**（ばめんの いろが かわる）

## ブロック

数字は かたさ（その かいすう あてると こわれる）。💣 は まわり 8マスも いっしょに こわす。
16めん から **スチール**（ぎんいろ・こわれない。クリアには いらない）、17めん から **？ブロック**（こわすと アイテムが 3こ とびだす）が でる。
ステージ いちらんは 15めんずつ ◀ ▶ で ページを きりかえる。
ボスは よこに うごく でかブロックで、HPが 0に なるまで あてる。

クリアで ★（のこりの かず）。つぎの めんが ひらく。記ろくは `localStorage`（`ballsfuefue.v1`）。
