# ゆいの ぴったりブロック

8×8 の ばんに ブロックを おいて、**たて か よこ が 1れつ そろったら 消える** パズル。
3つ おききると つぎの 3つが くる。どれも おけなく なったら おしまい。

https://artakartlight1997.github.io/allprojects/blast/

2025〜2026年に 世界で いちばん ダウンロード された スマホゲームの ひとつ
「Block Blast!」と 同じ タイプの あそび。

## あそびかた

- 右の 3つから ブロックを **ドラッグ** して ばんに おく
  （ゆびで かくれない ように、もった ブロックは ゆびより すこし 上に うかぶ）
- おける ところには うすい かげ、そろう よていの れつは ひかって 見える
- 2れつ いじょう 同時に 消すと 大きな 点。つづけて 消すと コンボ
- ぜんぶ 消えたら「ぜんけし」ボーナス

## モード

| モード | ゴール |
|---|---|
| エンドレス | どこまで スコアを のばせるか（ベストを きろく） |
| ほうせき ぼうけん（全6めん） | ほうせきの 入った ブロックを れつごと 消して、ぜんぶ あつめたら クリア |

## やさしさ

くばる 3つは、**3つ とも おける じゅんばんが ある 組** だけを えらぶ
（6とおりの じゅんばんで ためしおき して たしかめる）。運だけで すぐ おわらない。
ばんが つまって きたら 5マス いじょうの 大きい かたちは 出にくく する。

じどうで あそばせた しらべ（まわりに くっつけて おく おき方）で、
1ゲーム 50〜500手 つづいた。
