# あおいのブロックくずし

ラケットでたまを打ち返してブロックをくずす。全 12 めん。
ブラウザだけで動く（サーバー処理なし・インストール不要・ライブラリなし・**画像も音のファイルも 0 個**）。

https://artakartlight1997.github.io/allprojects/block/

## 「最後の 1 こが終わらない」をなくした

ふつうのブロックくずしは、最後の数こがなかなか当たらなくて退屈になります。
このゲームには止まらないための仕組みが 3 つ入っています。

1. **ばくだんブロック** — まわり 8 こもいっしょにこわれる（はがねだけは残る）
2. **アイテム** — ラケットが広く／たまが 3 つ／ゆっくり／レーザー／たまが 1 つ増える
3. **ブロックが下がってくる** — しばらくブロックに当たらないと、たまが少し速くなり、
   それでもだめならブロックのほうが 1 だん下がってきます。
   いちばん下まで来たら、そのブロックはひとりでくずれます。

また、**ラケットのまん中で受けても必ず少しななめに飛ぶ**ようにしてあります。
まっすぐ上下に往復し続けて永久に終わらない、という状態になりません。

## ブロック

| | |
|---|---|
| ふつう | 1 回 |
| かたい | 2 回 |
| もっとかたい | 3 回 |
| はがね | こわれない（かたちを作るため） |
| ばくだん | まわりもいっしょにこわれる |
| ふしぎ | かならずアイテムが出る |

## ボスのリナパパ

4・8・12 めんには**リナパパ**が出ます。メガネのちょいぽちゃです。
ブロックとラケットの間をふらふらしていて、たまを当てるとダメージ。
ときどきケーキを落としてきて、ラケットに当たると 5 びょうラケットが小さくなります。
**ブロックを全部こわして、さらにパパをたおすとクリア**です。

## クリアできないとき

**3 回だめだとラケットが広くなり、たまがおそくなり、たまのストックが 1 つ増え、
つぎのめんも開きます**（3 だんかいまで）。

## たしかめたこと

自動でプレイするロボット（うでまえ 4 だんかい）に、各めん 8 回ずつ遊ばせました。
ロボットはたまがラケットの高さに来る場所を（かべの反射も入れて）計算して先回りします。

| | こども | よわい | ふつう | つよい |
|---|---|---|---|---|
| 1〜7 めん | 8/8 | 8/8 | 8/8 | 8/8 |
| 8〜12 めん | 1〜5/8 | 8/8 | 8/8 | 8/8 |

- **どのうでまえでも全 12 めんクリアできる。時間ぎれは 0 回**
  （はじめは「最後の 1 こが当たらない」で 5 分たっても終わらない回が何度も出たので、
  上の 3 つの仕組みを足しました）
- 1 めんあたり 65〜166 びょう
- 3 回だめだったあとの助けを入れると、**こどもロボットでも全 12 めん 8/8 勝てる**
- 2 回では次のめんが開かず、3 回で開くことを確認
- 効果音 13 ことBGM 3 つが本当に鳴っている（`OfflineAudioContext` の波形で確認）
- 実際のマウス操作でラケットが動き、たまが飛び出し、点が入る（900×440 / 1280×720）
- 667×375 / 900×440 / 1024×768 / 1280×720 / 1366×640 でくずれない
