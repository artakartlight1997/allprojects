# まさきの ボウリング

うしろから 見た レーンで ボールを なげて、10本の ピンを たおす **ボウリング**。
てんすうは ほんものと おなじ 10フレーム（ストライク・スペアの ボーナス つき、さいこう 300てん）。

https://artakartlight1997.github.io/allprojects/bowling/

## あそびかた

1. ボールを **ひだり みぎに ドラッグ** して、なげる ばしょを きめる →「ここから なげる」
2. ゆれる **やじるし** を タップで とめて、むきを きめる
3. **パワー**（みぎの メーター）と **カーブ**（うえの てん）が うごくので、タップで なげる
   - パワーが つよいほど はやい。カーブは レーンの おくで まがる
- まんなかより ほんの すこし みぎ（「ポケット」）に あたると ストライクに なりやすい
- ストライク・スペアで まさきが よろこぶ！

キーボード：← → で ばしょ、スペース・Enter で きめる。

## しくみ

ボールと ピンは まるい からだ どうしで ぶつかる けいさん（おもさ：ボール 7・ピン 1.5）。
ピンが ピンを たおす ことも ある。ベストスコアと ストライクの かずは `localStorage`（`masakibowling.v1`）に のこる。

## たしかめた こと

てんすう けいさんを パーフェクト（300）・ぜんぶ スペア（150）・ぜんぶ 9ほん（90）・ふつうの ゲーム（167）で たしかめた。
でたらめな タイミングで なげても 40〜90てん くらいに なる ように、カーブと やじるしの ゆれを やさしく した。
