# エイトくんの ベルトスクロール

「くにおくん」「ファイナルファイト」みたいな **ベルトスクロール アクション**。
てまえ・おくにも うごける みちを すすみながら、いたずら まものを パンチと キックで おいはらう。
たおした まものは ほしに なって きえる。ぜんぶで 4ステージ、さいごに おやぶんが まって いる。

https://artakartlight1997.github.io/allprojects/brawl/

## あそびかた

| そうさ | タッチ | キーボード |
|---|---|---|
| いどう（まえ・うしろ・てまえ・おく） | ひだりの スティック | やじるしキー |
| パンチ（3かい つづけると ふっとばし） | パンチ | Z・スペース |
| ジャンプ（とんで いる ときに パンチで とびげり） | ジャンプ | X |
| ひっさつ（まわりを まとめて ふっとばす） | ひっさつ（ゲージ まんたん） | C |

- まものが ひかったら こうげきの あいず。よけるか、さきに なぐって とめよう
- そらの カラスは とびげりで
- はこを こわすと おにぎり・りんご・ケーキ（げんき +30）
- まものを ぜんぶ おいはらうと「GO →」。すすむと つぎの なかまが でて くる
- おやぶんは ちいさな パンチでは ひるまない。3だんめ・とびげり・ひっさつ で ひるませよう

| ステージ | ばしょ | おやぶん |
|---|---|---|
| 1 | こうえん | おおいたずらっこ |
| 2 | しょうてんがい | メガロボ |
| 3 | こうじょう | カラスの おやぶん |
| 4 | まものの おしろ | まもの キング |

クリアした ステージと いちばん はやい じかんは `localStorage`（`eitobrawl.v1`）に のこる。

## たしかめた こと

「いちばん ちかい まものに ちかづいて なぐる」ボットで 4ステージ ぜんぶ クリアできる ことを たしかめた（1ステージ 40〜60びょう）。
