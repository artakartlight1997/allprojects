# まさきの モンスターカード

パックを あけて モンスターカードを あつめ、**3まいの チームで トレーナーと たたかう** カードゲーム。
スマホで はやっている「パックを あけて カードを あつめる」あそびを、こども むけに ちいさく した もの。

https://artakartlight1997.github.io/allprojects/cards/

## あそびかた

- **パックを あける**：1パック 5まい。さいごの 2まいは レア が でやすい。1まいずつ タップで めくる
- **むりょうパック**：ほんとうの じかんで **3じかんに 1回** あけられる（アプリを とじて いても たまる）
- **ずかん**：5タイプ × 8しゅるい = 40まい。もって いない カードは「？」
- **バトル**：じぶんの カード → あいての カード の じゅんに タップして こうげき。
  てきを ぜんぶ たおすと **パックの けん** が もらえる（はじめて かつと +2まい）

## タイプの あいしょう

🔥ほのお → 🍃くさ → 💧みず → 🔥ほのお、⚡でんき → 💧みず は **2ばい**（ぎゃくは はんぶん）。✨ひかり は ふつう。

## レア

◆ ふつう ／ ◆◆ すこし レア ／ ◆◆◆ レア ／ ◆◆◆◆ ちょうレア（キラキラ）／ ★ でんせつ

## しくみ

トレーナーは 8人。うしろの 人ほど カードが つよく なる（ようちえんの こ ×0.8 〜 ひかりの まじょ ×1.4、チャンピオンは りゅう 3びき ×1.2）。
あつめた カード・けん・かった トレーナー・むりょうパックの じかんは `localStorage`（`monstercards.v1`）に のこる。
