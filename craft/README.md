# りなクラフト

マイクラ風の 3D ボクセルゲーム。ブロックを掘って、積んで、じぶんの世界をつくる。
ブラウザだけで動く（サーバー処理なし・インストール不要・ライブラリなし）。

https://artakartlight1997.github.io/allprojects/craft/

## 遊びかた

1. 画面の**左がわ**をゆびで動かす → 歩く
2. 画面の**右がわ**をなぞる → 見まわす
3. 右がわを**ちょんとおす** → ブロックを置く
4. 右がわを**おしっぱなし** → ブロックを掘る（まわりに輪が出て、たまると割れる）
5. 下のバーで持つものをえらぶ。「もちもの」で中身ぜんぶ／クラフト
6. 夜はまっくら。**たいまつ**を置くとあかるい
7. ふかく掘ると せきたん・てつ・きん・ダイヤ・エメラルドが出てくる
8. 地面にあいた**穴**からもぐると、ぐねぐね続く**ほらあな**。たいまつを持っていこう
9. **はじめると街のひろば**に立つ。あるいていくと ほかの**村**や**街**も見つかる
10. 村や街にある**みどりの土管**にのると、**べつのせかい**へ行ける
11. 村には**村人**。夜やほらあなには**スライム**と**おばけ**（タイトルで消せる）
12. **そうぞうモード**は 60 種のブロックが全部つかえて、空もとべる

## べつのせかい（土管）

村や街のはしに**マリオみたいなみどりの土管**が立っている。
のると 0.8 秒で別のせかいへワープする。行き先はせかいごとに決まっている。

| | |
|---|---|
| **ゆきやま** | 山が高くとがっていて、地面はぜんぶ雪。水面はこおる。しらかばの林 |
| **みらい都市** | まっ平らな地面いっぱいに、鉄とガラスと青いかべの**高層ビル**（4〜8 かい） |
| **キノコの森** | 巨大なキノコの林。かさは赤か茶色で、下がぼんやり光る。空がむらさき |

**行き先は「あなの底においたウールの色」で決めている。**
こうすると土管の場所をべつに覚えておく必要がない ―― 地形と同じでたねから
作りなおせるし、セーブにも何も足さなくていい。

ついた先は**かならず街か村の中**で、そこに**もどる土管**がある。
（はじめは何もない広場に出していたが、さびしかったので変えた）

**せかいごとにたねと「いじったぶん」を別に持つ。**
ゆきやまで建てたものは、はじまりのせかいへ帰ってもそのまま残っている。

## 生きもの

| | |
|---|---|
| **村人** | 村の中をぶらぶら歩く。ちかづくと話しかけてくる。8 人まで |
| **スライム** | ぴょんぴょんはねて追いかけてくる。さわられるとへる |
| **おばけ** | ふわふわ浮かぶ。地下と夜に出る |

**タイトルで「てき　なし」にできる。** こわがりでも、のんびり作るだけでも遊べる。

セーブには入れていない。プレイヤーのまわりにわいて、遠くに行くと消える ――
そうすると「つづきから」の中身がふえないし、世界のどこかに何百ひきもたまらない。

絵ははこを何こか組みあわせただけ。毎コマ世界の座標ではこを作りなおして
1 つのバッファにまとめ、**1 回で描く**（ブロックと同じシェーダ・同じ絵）。

パソコン: WASD で歩く / ダブルクリックで見まわす / 左クリック＝掘る 右クリック＝置く /
1〜9 で持ちかえ / E でもちもの / F でとぶ

## つづきから

**世界ぜんぶは保存していない。** 保存するのは

- **たね**（数字ひとつ）
- **じぶんが掘った／置いたブロックの差分だけ**
- いる場所・向き・持ちもの・時刻

地形は毎回たねから計算しなおすので、同じたねなら必ず同じ地形になる。
だからセーブが**ものすごく小さい**。実測で **30 個いじった状態が 0.5KB**。
1万個いじってもだいたい 150KB で、`localStorage` の 5MB にはとどかない。

20 秒ごとに自動セーブ、アプリを閉じるときにもセーブ、メニューから手動セーブもできる。
タイトルの**「つづきから」**でもどれる。

確認したこと（自動テスト）: たね・差分の数・いる場所・持ちもの・置いたブロックが
保存前とまったく同じに戻ること。村のブロック 40 か所も同じに戻ること。

**街や村はチャンクをまたぐ**ので、作る順番で形が変わると継ぎ目がずれる。
村（49 チャンク）と街（81 チャンク）を **3 とおりの順番で作って、
できあがりが 1 ビットも変わらない**ことをテストで確かめている。

## 世界

16×16×72 ブロックの「チャンク」を、近いところから順に作っては捨てる。

| | |
|---|---|
| 地面の高さ | 3 種類のノイズを重ねる。山は 3 乗にしてとがらせ、へこみは浅く |
| ばしょ | そうげん 49% / もり 42% / さばく 5% / ゆき 4%、水の下 15%（実測） |
| 鉱石 | 2×2×2 でかたまる。深いほどよいものが出る |
| いちばん下 | ようがんの海（y ≤ 4）。ダイヤは y < 13 なので、となり合っている |
| 木 | もりは 5%、そうげんは 1%。チャンクをまたいで生える |
| ゆき／さばく | ゆきブロック・すな・サボテン |

## 村と街

世界を **320 ブロックごとの区画**に切って、区画ごとに「街 / 村 / なし」を
たねから決めている。実測（5 つのたね × 400 区画）で **街 217 / 村 473 / なし 1310**。
だいたい **1000 ブロックに街ひとつ、650 ブロックに村ひとつ**。

| | 大きさ | 中身 |
|---|---|---|
| **村** | 90×90 | 17×17 の区画を **5×5**。まん中に屋根つきの井戸、まわりに家 16 けん・はたけ・小さい井戸。じゃりの道が碁盤の目に通る。角に街灯 |
| **街** | 128×128 | 5 マス幅の通りで区切って **2〜4 かい建てのビル 40 むね**。まん中はふんすいのある広場。まわりを石レンガのかべで囲み、4 方向に門。交差点ごとに街灯 |

家は 木の柱＋かべ（板・しらかば・まるいし）＋**三角屋根**、ガラスのまど、
中にたいまつと本だな。ビルはかいごとに帯をまいて、まどが規則的にならぶ。
かべの色は 8 種類（レンガ・石レンガ・すな・板・まるいし・ウール 3 色）。

**地面はならしてある。** ならすのは `heightAt()` の中でやっている ——
そうすると 地形・木の生えかた・明るさの計算が**ぜんぶ同じ高さを見る**ので、
「家が宙にうく」「屋根から木が生える」が起きない。
まわり 12 ブロックかけて、もとの地面へなだらかにつなげている。

**はじめて立つ場所は街の中央ひろば**。ふんすいから 12 ブロックのところに、
ふんすいのほうを向いて立つ。ひろばには ベンチ・街灯・**土管**がそろっていて、
まわりはビルなので、はじめた瞬間に「行くところ」が目に入る。

ひろばのどこに立たせるかは、置いてあるものを避けて決めている ——
ふんすいは中央 4 ブロック、ベンチは 7、街灯は角の 9、土管は南に 9。
まっすぐ横（+10, 0）に立たせるとベンチが目のまえに来て何も見えなかったので、
ななめ（+10, +5）にずらしてある。

街が見つからないときだけ村の外（`spawnPoint()` は 街 → 村 → 草地 の順に探す）。
たね 20 個で試して **20 回とも街**、中心から 172〜912 ブロックだった。

## ほらあな

まえは 3D ノイズのしきい値だけで穴をあけていた。それだと
「ぽつぽつ空どうがある」だけで、つながっていないし入り口も見つからない。

いまは**「ミミズ」をはわせている**。ある点から向きをすこしずつ変えながら
進ませて、通り道をまるくくりぬく。ときどき大きな広間も作る。
**3 回に 1 回は地面からはじめる**ので、外から入り口が見える。

実測（12×12 チャンク = 192×192 ブロック）:

- 地上から入れそうな**穴 123 か所**
- **ひとつの入り口から歩いて行けるマスが 31,018** ——
  ちゃんとつながった、迷子になれる広さ
- 地下の空どうは 13.4%（まえは 9%）

海の底に穴があくと海がぬけてしまうので、水の下では地面ちかくを残している。

## クラフト

マイクラの 3×3 に材料をならべるやりかたは、スマホの小さい画面だとつらい。

## あかるさ

3 つに分けて頂点に持たせてある。

- **面のむき＋かどの暗さ**（上 1.0 / よこ 0.72〜0.88 / 下 0.52、まわりにブロックがあるほど暗い）
- **空からの明るさ**（地面より下はどんどん暗くなる ＝ ほらあなはまっくら）
- **たいまつの明るさ**

夜になったときは、3 つめだけ暗くしないようにしている。だから**夜になっても
地形を作りなおさなくていい**（作りなおすと一瞬止まる）。1 日 7 分。

## 速くするためにやったこと

前のゲームで「くそ遅くて遊べませんでした」と言われたので、今回は先に測った。
**CPU を 1/4・1/6 におとして**、1 コマにかかる時間を JS と描画に分けて計測している。

| やったこと | 前 | 後 |
|---|---|---|
| 頂点を 36 バイト → **16 バイト**に詰めた（位置 Int16・色 Uint8） | 57MB | 20MB |
| カメラの外のチャンクを描かない（視錐台カリング） | 295 だん | 130 だん |
| チャンクを高さ 24 ごとに 3 段に分け、段ごとに捨てる | ― | 地下のほらあなの壁を地上で描かない |
| 手前から順に描く | ― | おくが早く捨てられる |
| となりのブロックを見るのに Map を引くのをやめ、まわり 9 チャンクを配列で手もとに置いた | ― | 1 チャンクあたり 10 万回の Map 引きが消えた |

村や街を入れたあとも **JS は 1 コマ 0.1〜0.3ms**（街の中を走って計測、
わるいときで 1.6ms）。1 チャンク作るのにかかるのは 1.7〜4.6ms、
CPU を 1/4 におとして 6〜11ms。

測った結果 **JS は 1 コマ 0.1〜0.8ms** しか使っていない。残りは全部
「ピクセルをぬる」時間だった。だからこのゲームの重さは**画面の広さで決まる**。
自動調整もそれに合わせて、まず解像度を下げ、それでも足りなければ見える距離を減らす。

**ただし、ここで測っているのは GPU のないパソコン（ソフトウェア描画）**なので、
絵を出す時間は実機よりずっと遅く出る。実機のスマホでどうかは、遊んでみないとわからない。

## つまずいたところ

**カメラの行列が鏡うつしだった。** 「右」を 前×上 の逆向きに作っていたので、
行列の行列式が −1 になり、**三角形の表と裏が全部入れかわっていた**。
その結果、上をむいた面（地面）が消えて、下の面が見えるという絵になっていた
——地面のうえに立っているのに、木と草だけが空中にういて見えた。

見つけかた: 空中にたいらな草の台を作り、真上から見おろして 1 枚撮った。
**草のはずが「つち」の絵で写った**（＝上の面ではなく下の面を見ていた）ので確定した。

ほかに直したもの:

- 明るさの自動調整が **JS の時間だけ**を測っていた。JS は 0.1ms しか使っていないので、
  どんなに重くても一生発動しない設定になっていた。1 コマ全体の時間を測るように変更
- 地下の空どうの 55% をばらばらにようがんにしていて、地下がようがんだらけだった。
  いちばん下（y ≤ 4）にたまる「ようがんの海」に変更
- 世界の 47% が海だった。山をとがらせ、へこみを浅くして 15% に
- ばしょの判定がきつすぎて、さばくとゆきが多すぎた
- 村の家を「井戸を囲む輪の上」にならべたら、半径の近い家どうしが**めりこんだ**。
  区画を切って 1 区画 1 けんにしたら、かさなりようがなくなった
- あかりを 1 本の長い配列で持っていた。街の街灯が何百こにもなると、
  地形を作るたびに全部見にいくことになる。**チャンクごとに分けて**持つように変えた
  （同じ場所に二重に入らないことも確認ずみ。チャンクを作りなおしても増えない）
- 生きものが**まっ黒**になった。明るさに夜のぶんをかけてから渡していたのに、
  シェーダの中でもう一度かかっていた（二重がけ）。
  ブロックと同じく「面のむき／空／たいまつ」の 3 つに分けて渡すように直した
- 土管を村のはしに置いたら、**家のまん中に建って**かべに囲まれ、近づけなかった。
  区画をひとつ土管用にあけた
- なぐる判定がきびしすぎて、**スライムがまっすぐ見てもあたらなかった**
  （背がひくく、目の高さより 1.2 ブロック下にいるため）。
  生きものの大きさから判定のはんいを決め、たてには甘くした
