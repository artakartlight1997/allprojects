# ゆいのきせかえサロン

**きせかえ**。すきに着せかえる「じゆうモード」と、**その場に合う服を考える「お題モード」**（全 10 こ）。
ブラウザだけで動く（サーバー処理なし・インストール不要・ライブラリなし・**画像も音のファイルも 0 個**）。

https://artakartlight1997.github.io/allprojects/dress/

## 遊びかた

1. 右の「**かみ・ふく・くつ・かざり・ばしょ**」から選ぶ
2. 下の色をおすと色が変わる
3. お題モードは、そのばしょに合う服をえらぶと**星がふえる**（1〜3）

## 「なんとなく」ではなく「なぜ」で点がつく

服にはタグがついている。

| タグ | ついている もの（例） |
|---|---|
| あたたかい | コート・セーター・ブーツ・マフラー |
| すずしい | Tシャツ・ワンピース・サンダル |
| うごきやすい | たいそうふく・スニーカー・ポニーテール |
| あめ | レインコート・ながぐつ・かさ |
| スポーツ | たいそうふく・スニーカー・ぼうし |
| なつ | ゆかた・サンダル・むぎわら |
| おしゃれ | ドレス・くつ・リボン・ロング |
| とくべつ | ドレス・かんむり・ゆかた |

お題にも「ほしいタグ」が書いてあり、**そろうほど星がふえる**。
たとえば「ゆきの日」がほしいのは`あたたかい`。コート＋ブーツ＋マフラーで星 3 つ。

ちぐはぐ（「ゆきの日」なのに`すずしい`も混ざっている、など）だと星が 1 つ減る。

選んだものの下には**そのタグがそのまま表示される**ので、答えは隠していない。
「なぜそれを選んだか」を自分で説明できるようになっている。

## お題 10 こ

こうえん／あめの日／たんじょうびパーティ／うみ／ゆきの日／うんどうかい／なつまつり／おさんぽ／ふゆのよぞら／はっぴょうかい

## 直したところ

- キャラクターの絵が**画面からはみ出していた**（頭からつま先で 150 のものさしなのに 100 で割っていた）
- うしろがみが**体の高さ**に描かれていて、はねのように見えていた。頭のまわりに移した
- 服の色えんぴつとかみの色えんぴつを分けた（同じだと最初からピンクのかみになる）
- 服をえらび直したら、色はその服のもとの色にもどす（全部同じ色に見えないように）

## たしかめたこと

- かみ 6・ふく 8・くつ 5・かざり 7 を**すべて 1 枚に並べて目で確認**（見分けがつく形になっている）
