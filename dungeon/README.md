# りなのふしぎダンジョン

**ターン制**のもぐりダンジョン。地下 10 階のドラゴンをたおすとクリア。
ブラウザだけで動く（サーバー処理なし・インストール不要・ライブラリなし・**画像も音のファイルも 0 個**）。

https://artakartlight1997.github.io/allprojects/dungeon/

## 作り直しました

「コンセプトはいいけど、**マップがおかしい**。次の部屋みたいなところで敵と遭遇し、
やっつけると何故かマップがワープした感じで違うところに飛んでる」
「キャラクターが雑」「ゲーム性やストーリーも必要」という指摘を受けて、
作り方をまるごと変えました。

| | 前 | 今 |
|---|---|---|
| 地図 | 毎回ランダムに生成 | **10 階ぶんを手で作ってデータファイルに固定**（`floors.js`） |
| 見えかた | 自分のまわりだけ。画面がスクロール | **地図ぜんぶが 1 画面に出る**。スクロールしない |
| 敵 | プレイ中もわいてくる | 置いてある場所が決まっている |
| 絵 | ほぼ丸 | 主人公・敵 6 種類・道具 6 種類をそれぞれ描く |
| 話 | なし | 「光の鏡」をとりもどす話 |

### なぜワープしたように見えたのか

前は**歩いているとちゅうにも敵がわいてきて**、しかも見えるはんいが自分のまわりだけ、
さらに画面がスクロールしていました。
戦っているあいだにスクロールが動くと、終わったときに景色がすっかり変わっていて、
**別の場所に飛ばされたように見えます**。

ハイドライド・ドルアーガの塔・ドラクエと同じで、
**地図は最初から決まっていて、形は最初から全部見えている**のが正解でした。
今は 25×15 マスの地図がまるごと 1 画面に入り、
たいまつの光がとどく 4.6 マスの外は「少し暗い」だけです。
どこにいるか、どっちへ行けばいいかが、いつでも分かります。

## お話

> りなの町の宝物、「光の鏡」が盗まれた。
> 犯人は町の下にすむドラゴン。
> りなはたいまつを持って、地下への階段をおりた。

## 遊びかた

1. 右下の**十字ボタン**（パソコンは矢印キー）で 1 マスずつ進む
2. 敵のいるほうへ進むと**攻撃**。1 マス歩くと**敵も 1 回動く**
3. 金色の**階段**にのると次の階へ
4. 落ちている道具・**宝箱**をひろって、右のボタンで使う
5. 敵をたおすとレベルが上がり、体力が**ぜんぶもどる**

**ターン制なので、じっと見ていてもやられない。**あわてずに考えられる。

### かぎととびら

3 階と 7 階には**赤いとびら**があり、その先に階段があります。
同じ階のどこかに落ちている**カギ**をひろわないと開きません。
とびらの手前だけをうろうろしていても先へ進めないので、地図を見わたす必要が出ます。

（データのほうで「カギはとびらの手前にある」「とびらを通らずに階段へは行けない」を
毎回たしかめています。下の「たしかめたこと」を見てください。）

## 死んでも 1 階めからにはしない

**5 階ごとにチェックポイント**があり、力つきてもそこからやりなおせます。
最初からやりなおしだと、子どもは 2 回目を遊びません。
「いちばん深くもぐった階」はずっとのこります。

## 直したところ

### カギが取れなくなる詰み

もちものが 8 こでいっぱいのときにカギを拾おうとすると、
**カギだけは拾えないのに、とびらは開かない**という状態になっていました。
どうやっても先へ進めません。

自動で歩くロボットが 3 階でぐるぐる回りつづけたので見つかりました。
カギはもちものの数に関係なく拾えるようにしました。

### 敵の強さが NaN になっていた

地図を固定にしたとき、敵のデータから「何階から出るか」の項目を消しました。
ところが敵を作るところがまだその項目を見ていて、体力が計算できず
**数字でない値**になっていました。深さだけで強さを決めるように直しました。

### 足音がほとんど無音だった

波形を見たら、足音のピークが 0.0015（ほぼゼロ）。
1 歩ごとに鳴るのでひかえめにしたつもりが、消えていました。0.0097 まで上げました。

## たしかめたこと

### 地図データ（10 階ぶん）

- 25×15 マス、行の数・文字数がそろっている
- **入口から歩いて行けないマスが 1 つもない**（全部の床マスを塗りつぶして確認）
- とびらのある階は、**カギがとびらの手前にあり、とびらを通らずには階段へ行けない**

### 自動で遊ぶロボット（8 回ずつ）

| ロボット | クリア | へいきん到達 |
|---|---|---|
| 道具を使わない | 0 / 8 | 地下 7.1 階 |
| 道具を使う | 1 / 8 | 地下 8.4 階 |
| 道具を使う＋敵をたおしてレベル上げ | **6 / 8** | 地下 9.6 階 |
| チェックポイント（6 階）から | 7 / 8 | 地下 9.8 階 |

- **道具を使わないとドラゴンに勝てない**（0/8）＝ 道具にちゃんと意味がある
- **レベル上げをすれば勝てる**（6/8）＝ 運だけのゲームになっていない
- 止まって動けなくなる階が 1 つもない（詰みなし）
- ロボットは地図を全部知っている状態なので、実際に遊ぶ人はもう少しむずかしい
