# りなのふしぎダンジョン

**ターンせい**のもぐりダンジョン。ちか 10 かいのドラゴンをたおすとクリア。
毎回ちずがちがう。ブラウザだけで動く（サーバー処理なし・インストール不要・ライブラリなし・**画像も音のファイルも 0 個**）。

https://artakartlight1997.github.io/allprojects/dungeon/

## 遊びかた

1. 右下の**十字ボタン**（パソコンはやじるしキー）で 1 マスずつすすむ
2. てきのいるほうへすすむと**こうげき**。1 マスあるくと**てきも 1 回うごく**
3. 金いろの**かいだん**にのるとつぎのかいへ
4. おちているどうぐをひろって、右のボタンでつかう
5. てきをたおすとレベルが上がり、たいりょくが**ぜんぶもどる**

**ターンせいなので、じっと見ていてもやられない。**あわてずに考えられる。

## 死んでも 1 かいめからにはしない

**5 かいごとにチェックポイント**があり、ちからつきてもそこからやりなおせる。
そのぶんレベルとどうぐもついた状態ではじまる。

さいしょからやりなおしだと、子どもは 2 回目をあそばない。
「いちばんふかくもぐったかい」はずっとのこる。

## ちずの作りかた

毎回ランダムだが、**かならず入口から出口まで歩いて行ける**必要がある。

1. かさならないようにへやを 5〜9 こおく
2. **となりどうしのへやを順番に通路でつなぐ**

この順で作れば、つながっていないへやは原理的にできない。
ときどき最初のへやと最後のへやも直接つないで、ぐるっとまわれる道にしている
（いきどまりばかりだとつまらない）。

見えるはんいは、**へやの中にいればそのへやぜんぶ・通路ならまわり 1 マス**。
一度見たところはうすくのこる。

## つくって直したところ

### 死んだあと「もう一度」がきかなかった

`startRun()` が `G.over` を `false` にもどしていなかった。1 回ちからつきると、
そのあと何をおしても**すぐ終わったことになって動かない**。
ロボットに 8 回連続でもぐらせたら、2 回目以降が全部 0 手で終わって見つかった。

1 回しか遊ばないテストでは絶対に見つからない種類のバグ。

## たしかめたこと

ロボットに 8 回ずつもぐらせた（ちずの上で道をさがして歩く）。

| | クリア | へいきん とうたつ |
|---|---|---|
| どうぐをつかわない | 0 / 8 | ちか 8.5 かい |
| どうぐをつかう | **6 / 8** | ちか 9.9 かい |
| ちか 6 かいからはじめる | 7 / 8 | ― |

- **どうぐを使わないとドラゴンに勝てない**（0/8）＝ どうぐにちゃんと意味がある
- チェックポイントからだと高い確率でクリアできる
- ロボットは地図を全部知っている状態なので、実際に遊ぶ人はもう少しむずかしい
- 効果音 13 こと BGM 3 つが本当に鳴っている（`OfflineAudioContext` の波形で確認）
- 667×375 / 900×440 / 1024×768 / 1280×720 でくずれない
