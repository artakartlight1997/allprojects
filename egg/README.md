# ゆいのたまごっこ

たまごから育てる**育成ゲーム**。お世話のしかたで、大人になったときの姿が **8 しゅるい**に分かれる。
ブラウザだけで動く（サーバー処理なし・インストール不要・ライブラリなし・**画像も音のファイルも 0 個**）。

https://artakartlight1997.github.io/allprojects/egg/

## 遊びかた

1. たまごをトントンすると早くわれる（待っていてもわれる）
2. 下のボタンでお世話 … **ごはん・あそぶ・おふろ・ねんね・おくすり**
3. 4 つのものさし（**おなか・きげん・きれい・げんき**）をへらさない
4. 1 日は 50 びょう。**3 日で大人になる**

「あそぶ」は「どっちの手に入ってる？」を 3 回。あてるほど、きげんが大きく上がる。

## 8 しゅるいの姿

大人の姿は**どんなお世話をしたか**で決まる。

| | よくお世話した | ふつう | あまりできなかった |
|---|---|---|---|
| まんべんなく | **ユニコーン** | しろねこ | おばけ |
| あそび多め | **ドラゴン** | うさぎ | ― |
| おふろ多め | ― | ペンギン | ― |
| ごはん多め | ― | くまさん | こぶた（食べさせすぎ） |

### 「すすんでしたお世話」だけ数える

「どのボタンを何回おしたか」でそのまま決めると、**いつもごはんが 1 位**になってしまう。
おなかはだまってもへるので、だれでもごはんはあげるからだ。

そこで、

- おふろ … うんちのそうじではなく、**きれいなのに入れてあげた**ぶんだけ数える
- ごはん … おなかがへっていないのに**あげた**ぶんだけ数える
- あそぶ … そのまま数える

としている。これで「うさぎに会いたいからたくさん遊ぼう」が成立する。

レア（ユニコーン・ドラゴン）は、ほとんど泣かせないことに加えて
**ごはん・あそび・おふろを全部やっている**ことが条件。1 つのボタンだけ押していてもレアにはならない。

## 直したところ

### お別れになるのがきびしすぎた

最初は 4 つのものさしのどれかが 0 のまま 25 びょうでお別れにしていた。
ところが**うんちが 4 つたまると「きれい」が 22 びょうで 0 になる**ので、
少し手をぬいただけで 1.5 日でお別れ。
これでは「あまりお世話できなかった姿（おばけ）」に一度も会えない。

いまはお別れになるのは**おなかが 0**と**びょうきを 60 びょう放っておいた**ときだけ。
きげんやきれいが 0 でも、すぐにはお別れにならない（そのかわり大人の姿には出る）。

## たしかめたこと

お世話のしかたを 9 通りに変えて、自動で育てるロボットを走らせた。

| ロボット | なった姿 |
|---|---|
| ていねい・まんべんなく | ユニコーン |
| ていねい・あそび多め | ドラゴン |
| ていねい・おふろ多め | ペンギン |
| ふつう・まんべんなく | しろねこ |
| ふつう・あそび多め | うさぎ |
| ふつう・ごはん多め | くまさん |
| ごはんばかり | こぶた |
| ほったらかし | おばけ |

**8 しゅるい全部に会えた**。しかも「そういうお世話をしたらそうなる」という納得のいく対応になっている。

- 効果音 15 ことBGM 2 つが本当に鳴っている（`OfflineAudioContext` の波形で確認）
- 667×375 / 900×440 / 1024×640 / 1280×720 でくずれない・コンソールエラー 0
