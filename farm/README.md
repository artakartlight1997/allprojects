# ゆいの はたけ日記

「牧場物語」「Hay Day」みたいな **のんびり はたけ ゲーム**。
たねを まいて、みずを やって、そだったら しゅうかく。みんなの ちゅうもんに こたえて レベルアップ！

https://artakartlight1997.github.io/allprojects/farm/

## あそびかた

- みぎの「たね」で やさいを えらんで、はたけの マスを タップ → たねを まく（コインを つかう）
- 「💧 みずやり」を えらんで タップ → つぎの だんかい まで **2ばい はやく** そだつ（だんかいは 3つ）
- ★が ひかったら タップで しゅうかく。かごに はいる
- 「ちゅうもん」… りな・あおい・まさき・エイトの ちゅうもんを わたすと、うるより たくさん コインと けいけんちが もらえる
- 「かご」… のこりを ぜんぶ うる
- レベルが あがると あたらしい たね・にわとり（たまごを うむ）・ひろい はたけ が ひらく

## つづきから

**ほんとうの じかんで そだつ** ので、とじて いる あいだも やさいは おおきく なり、にわとりは たまごを うむ（さいだい 24じかん ぶん）。
つぎに ひらくと「おかえり！ やさいが ○こ そだったよ」と おしえて くれる。ぜんぶ `localStorage`（`yuifarm.v1`）に じどうで のこる。
