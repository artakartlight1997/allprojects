# あおいの フルーツがっちゃん

はこの 上から くだものを おとして、**同じ くだもの どうしが くっつくと ひとつ 大きく なる**
おちもの パズル。さくらんぼ → いちご → ぶどう → デコポン → かき → りんご → なし → もも →
パイナップル → メロン → **スイカ**。

https://artakartlight1997.github.io/allprojects/fruit/

2023年に 大ブームに なり、2026年7月には パソコン版（Steam）も でた
「スイカゲーム」と 同じ タイプの あそび。

## あそびかた

- 画面を おさえて よこに うごかし、**はなすと おちる**（やじるしキー と スペースでも OK）
- 同じ くだものが ふれると がっちゃん！ で 1つ 大きく なる
- 赤い てんせんを こえた まま **2びょう** たつと おしまい
- みぎに「つぎ」と「しんかの わ」（どこまで 大きく なるか）

## しくみ

まるい からだの ぶつりは 自分で 計算して いる（ライブラリなし）。
1コマを 4つに わけて うごかし、かさなりを 3回 なおす と、つみあがっても くずれにくい。
大きい くだものほど おもく、ぶつかった ときに 小さい ほうが おされる。

ベストスコアと「いちばん 大きく できた くだもの」は `localStorage`（`fruitgaccha.v1`）。
