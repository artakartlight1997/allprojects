# ふわふわふわりな

タップすると りなが **ふわっと** うかぶ。そのまま 空を とんで、てきと たたかう
よこスクロールの シューティング。**全 10 面**（5 面と 10 面は ボス）。
ブラウザだけで動く（サーバー処理なし・インストール不要・ライブラリなし・**画像も音のファイルも 0 個**）。

https://artakartlight1997.github.io/allprojects/fuwa/

## 遊びかた

**ボタンは 1 つだけ。画面のどこでもタップ。**

1. タップすると ふわっと 上がる。はなすと ゆっくり 下がる
2. **あわは かってに 前へとぶ。** 高さを合わせてぶつける（照準はいらない）
3. てきや てきのたまに ぶつかると たいりょくが 1 へる。0 でおしまい
4. ピンクの **ハート**＝たいりょく回ふく／きいろの **ほし**＝あわが 3 ほうこうに 11 秒
5. 上のバーが右はしまでいけばクリア。ほしは 3 つまで（ノーダメージで ★3）

パソコンはスペースキー。

## 「ふわっと」の作りかた

ふつうに重力をかけると、ただの落下でぜんぜん「ふわっ」としない。
**タップしたあと 0.26 秒だけ重力を 30% に落としている**（浮いている時間）。

- 1 回タップで **126px** 上がる（画面のたては 450px）
- てっぺんまで **0.52 秒**、もとの高さに戻るまで **0.99 秒**

このおかげで、押した瞬間にふわっと上がって、しばらく空中でとまってから落ちる。
おしっぱなしにすると上がっているあいだの重力がさらに 25% 減るので、
細かく連打できない子でも高さを保てる。

## 子どもが 詰まない ようにしたこと

作ったあと、**自動で遊ぶ AI**（ふつうに遊ぶくらいの強さ）に 10 面ぜんぶ通させて、
クリアできない面を 1 つずつ潰した。最初は **3/10** しかクリアできなかった。

| 直したこと | なぜ |
|---|---|
| あたり判定を見た目より小さく（半径 19 → 15） | 「当たってないのに当たった」がいちばんいやになる |
| あわを速く・多く（540→700px/s、0.50→0.38 秒ごと）、大きく（9→12） | てきが来る前に倒せないと、避けるしかなくなる |
| ボスのたまを**まっすぐ左**に（ねらいうちをやめた） | ねらいうちだと「当てるには前にいる → 必ず当たる」で避けようがない |
| ボスのたまの間隔を 1.7→2.5 秒に | 画面に 2 発以上あると、よけ続けるだけで攻撃できない |
| **ボスが出たら たいりょく全かい** | ボスはそこだけの勝負にする。道中のきずで詰ませない |
| ボスの前にハートとほしを必ず置く | 同上 |
| アイテムが近づくと**吸いよせる** | とれないアイテムがあると、ただのストレス |
| たいりょく 3 → 4、むてき 1.4 → 1.8 秒 | |

これで **10/10 クリア**、★は 1〜3 とばらけるところまで持っていった。

**それでもだめなとき**は、同じ面で 2 回失敗するとハートが増えててきが遅くなり、
3 回で次の面も開く（1 つの面で止まって、ほかを全部見られないのがいちばんもったいない）。

## 音

音のファイルは 1 つも置いていない。ぜんぶその場で波を作る。
BGM は 1 小節ずつ先に予約する（鳴らす瞬間に作るとスマホでは必ず遅れる）。

**iPhone・iPad は横の消音スイッチを切っていると WebAudio がまるごと無音になる。**
無音の音楽を 1 つ流しっぱなしにして「動画あつかい」に変え、スイッチを切っていても鳴るようにした。
タイトルに「♪ 音を ためす」ボタンもある。

## 画面の大きさ

たては**いつも 450 として計算**して、描くときだけ画面に合わせてのばす。
どのスマホでも同じ見た目・同じむずかしさになる。よこ幅だけは画面なり
（よこ長のスマホは少し先まで見える）。実測 568×320 / 667×375 / 812×375 / 1024×600 で
ゲーム内よこ幅 768〜974px。
