# りなの パターゴルフ

うえから 見た **ミニゴルフ（パターゴルフ）**。ボールを うしろに ひっぱって はなすと うてる。
ひっぱる ほど つよく とぶ。かべで はねかえる のを つかって カップを ねらおう。ぜんぶで 9ホール。

https://artakartlight1997.github.io/allprojects/golf/

## あそびかた

- ボールの ちかくを おさえて、**うちたい ほうこうと はんたいに ひっぱって はなす**（てんてんが とぶ むき、したの バーが つよさ）
- **パー** は めやすの うちかず。パーより すくないと バーディー・イーグル、1かいで いれたら ホールインワン！
- 1ホール 8うち まで。こえたら つぎの ホールへ

| しかけ | どうなる |
|---|---|
| かべ | はねかえる |
| ピンクの まる | ぽよーんと つよく はねる |
| すなば | ころがりにくい |
| いけ | 1うち ふえて、うつ まえの ばしょに もどる |
| さか（しろい やじるし） | やじるしの ほうへ ながされる |
| かざぐるま | まわる はねに あたると はじかれる |

さいごに スコアカード。ホールごとの ベストと ごうけいの ベストが `localStorage`（`puttgolf.v1`）に のこる。

## たしかめた こと

いろんな むき・つよさを ためして いちばん いい うちかたを さがす ボットで、9ホール ぜんぶ パーいないで はいる ことを たしかめた。
