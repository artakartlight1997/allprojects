# まさきのまもれ！ひみつきち

みちを あるいてくる てきを、とうを おいて たおす タワーディフェンス。**12 めん**。
ブラウザだけで動く（サーバー処理なし・インストール不要・ライブラリなし・**画像も音のファイルも 0 個**）。

https://artakartlight1997.github.io/allprojects/guard/

## 遊びかた

1. 右のボタンで**とうをえらぶ** → 草の上（しかくが出るところ）をタップ
2. てきはみちをあるいてきちへむかう。とうはかってにうつ
3. てきをたおすと**おかね**。とうをふやしたり、つよくしたり
4. おいたとうをタップすると「つよくする」が出る（レベル 3 まで）
5. きちに入られると ♥ がへる。0 になるとまけ

「いま よぶ」でつぎのなみを早くよぶと、そのぶんおかねがもらえる。**× 2** でばやおくりもできる。

## つくって直したところ

### `W` という名前が ui.js とぶつかって、画面がまるごと動いていなかった

`maps.js` に なみを書くための `function W(f, n, gap)` を置いていた。
`ui.js` には `let W = 0`（画面のよこはば）がある。どちらもグローバルなので、
**`ui.js` が丸ごと読みこまれなくなっていた**。ロボットは `update()` を直接よぶので
テストは通り、ブラウザで開いてはじめて分かる種類のバグ。`WV` に改名した。

グローバルに置く名前に 1 文字は使わない。

### なみを手書きしない

さいしょは 12 めんぶんのなみを手で書いていて、
**「8 めん目の 1 なみ目がいきなり 20 ひき」**のような形になっていた。
めんのばんごうからなみを作る `makeWaves(stage)` にして、
どのめんも「小さく始まってだんだん増える」ことを式で保証した。

### そらのてき **だけ** のなみを作らない

`kind === 2` のなみを 100% こうもりにしていたら、こおりを 1 つも持っていないと
**手も足も出ずに ♥ が全部なくなる**。ロボットは 5 めん目以降、毎回きっちり
6 なみ目で全滅した。じめんのてきと半分ずつまぜて、
「こおりが要る」と気づけて、気づかなくても即死しない形にした。

### 数字の調整

こおりのつよさ 5 → 11（安い対空がよわすぎた）、ボスのたいりょく 900 → 450、
かたいの 130 → 100、パンチ 13 → 16。

## おたすけ

同じめんで 3 回やぶられるごとに、**はじめのおかね +20%** と **♥ +4**（3 だんかい）。
3 回やぶられればつぎのめんもあくので、1 つのめんで止まったままにならない。

## たしかめたこと

ロボットに 12 めんを通しでまもらせた。

| | まもりきった |
|---|---|
| パンチだけおく（対空を知らない） | 4 / 12 |
| そらのてきを見てこおりも作る | 10 / 12 |
| ＋ おたすけ（9 回やぶられた後） | **12 / 12** |

- 対空を知らないと 5 めん目で止まる ＝ **こおりを覚える必要がちゃんとある**
- おたすけが最大まで入れば 12 めんすべてまもりきれる（どこかで永久に止まらない）
- `ui.js` が 4 つの画面サイズすべてで**ほんとうに読みこまれている**ことを毎回確認
- 効果音 15 こと BGM 3 つが本当に鳴っている（`OfflineAudioContext` の波形で確認）
- 667×375 / 900×440 / 1024×768 / 1280×720 でくずれない
