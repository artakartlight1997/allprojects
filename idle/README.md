# あおいの ぽちぽち パン工場

パンを タップして やき、やけた パンで おてつだいを やとうと、**じどうで どんどん パンが ふえる**
「ほうち（放置）ゲーム」。ねこの てんいん から はじまって、オーブン・パンやさん・ベルトコンベア・
こうじょう・トラック・ひこうき・うちゅう パン まで ふえて いく。

https://artakartlight1997.github.io/allprojects/idle/

## あそびかた

- まんなかの しょくパンを **タップ** → パンが やける（スペースキーでも OK）
- みぎの「おてつだい」を かうと、1びょう ごとに パンが ふえる（×1 / ×10 / MAX で まとめがい）
- 「パワーアップ」で おてつだい や タップが **×2**
- ときどき でる **きんいろ クロワッサン** を タップ → フィーバー（20びょう ×7）か パンが どさっと
- たくさん やいたら「あたらしい まち」へ。さいしょから に なるけど **⭐ほし** が もらえて、⭐1こで ずっと +10%

## つづきから

ゲームを とじても **いない あいだも パンは やける**（さいだい 8じかん ぶん）。
つぎに ひらくと「おかえり！ ○じかん の あいだに ○○こ やけたよ」と でる。
セーブは 5びょう ごと・がめんを とじた とき に `localStorage`（`panfactory.v1`）へ じどうで のこる。

## しくみ
