# まさきのカートレース

見おろし型のカートレース。**10 コース**、3 しゅう勝負、CPU 3 台といっしょに走る。
ブラウザだけで動く（サーバー処理なし・インストール不要・ライブラリなし・**画像も音のファイルも 0 個**）。

https://artakartlight1997.github.io/allprojects/kart/

## 遊びかた

**アクセルは自動。左右にまがるだけ。**

1. 画面の**左はしをおすと左**、**右はしをおすと右**にまがる
2. 同じむきにまがりつづけると**火花がたまる**（青 → きいろ → ピンク）
3. ゆびを**はなしたしゅんかんにダッシュ**（＝ドリフト）
4. **? のはこ**をとるとアイテム。まん中のまるをおすとつかう
5. 3 しゅうまわって **3 いまでに入ればクリア**

パソコンは ← → か A / D、スペースでアイテム。

| アイテム | なにが おきる |
|---|---|
| いなずま | しばらく大ダッシュ |
| バナナ | うしろにおく。ふんだ人はくるくるまわる |
| みどりのたま | まえの人をおいかけていって当たる |

草の上とみずたまりの上はおそい。オレンジのやじるし（かそくパッド）をふむとダッシュ。

## コースの作りかた

コースは「**まん中の線**」と「**はば**」だけで持っている。曲がりかどを 1 つずつ図形で
置くのではなく、10〜14 この点をカットマル・ロム曲線でなめらかにつないで、
それを 14 分割した折れ線が「まん中の線」になる。

じぶんの位置からいちばん近い線の場所を出すだけで、

- 道の上か草の上か（線からのきょり ＞ はば なら草）
- いま何しゅう目のどこか（線にそったきょり ÷ 1 しゅうのながさ）
- CPU がどこへむかえばよいか（先の点）
- アイテムのはこ・かそくパッド・みずたまりをどこに置くか（「1 しゅうの 0〜1」で指定）

が**ぜんぶ同じ計算**で出せる。あたり判定用のポリゴンを別に持つ必要がない。

さがすときは、まえのコマの答え（`hint`）のまわり ±26 区間だけ見る。
毎回ぜんぶ見ると 10 コース × 170 点をカート 4 台ぶん、毎コマ調べることになる。

| # | コース | はば | とくちょう |
|---|---|---|---|
| 1 | はじめての サーキット | 64 | ひろい。かどもゆるい |
| 2 | なみなみ ロード | 60 | S 字がつづく |
| 3 | もりの ぐるぐる | 58 | みずたまりが 1 こ |
| 4 | さばくの ダッシュ | 56 | みずたまり 2 こ |
| 5 | よるの ネオン | 54 | かそくパッド 3 こ |
| 6 | ゆきやま サーキット | 52 | ながい。みずたまり 2 こ |
| 7 | あめの ハイウェイ | 50 | みずたまり 3 こ |
| 8 | まちなか クランク | 46 | かくかくした かど |
| 9 | かざんの ぐらぐら | 44 | みずたまり 4 こ |
| 10 | うちゅう グランプリ | 42 | いちばんほそい・いちばんながい |

## 大事にしたところ

### 1. カメラがカートといっしょにまわる

じぶんのカートはいつも画面の上をむいていて、**世界のほうがまわる**。
地図のむきを固定すると、下にむかって走るときに「左をおす → 画面では右に動く」に
見えて、小さい子には操作できない。

ひきぐあい（`ZOOM = 0.70`）は、**つぎのかどが見えるかどうか**で決めた。
1 : 1 だとかどが来てから気づくので、まがりきれない。

### 2. はやいほどまがりにくい（アンダーステア）

最初はどのかども全開でまがれてしまい、**ドリフトをおぼえるいみがなかった**。
速度に応じてまがる力を下げ（最大 0.66 倍）、そのかわり**ドリフト中は 1.40 倍**にした。
これで「まがりきれないかどはドリフトでまがる」になり、ごほうびにダッシュもつく。

### 3. CPU も人とまったく同じしくみで走る

`steer` を −1 / 0 / +1 で決めて、あとは人とおなじ `moveKart` に わたすだけ。
ワープさせたりレールの上をすべらせたりしていない。

ただし最初、CPU は**一度もドリフトできなかった**。ねらいから 0.05 ラジアンずれるたびに
反対に切っていて、ハンドルがぶるぶるして火花がたまる前にリセットされていたため。
「いちど切ったらまっすぐにもどるまで同じむきでにぎりつづける」に直すと、
CPU もドリフトダッシュを使うようになった。

### 4. ゴムひもでつないだような速度調整

まえにいる CPU は少しゆっくり、うしろの CPU は少しはやく走る。
これがないと、**1 回草に出ただけでもう追いつけず**、小さい子がレースをあきらめる。
きき目はつよさで変える（やさしい 0.55 → つよい 0.02）。

### 5. まよったときのやじるし

一度くるっとまわると、どっちへ行けばいいのか分からなくなる。
つぎにむかう場所へ**大きなやじるし**を出し、完全に逆をむいていたら
「ぎゃくそう！」も出す。

### 6. 1 しゅうめをただでもらわない

スタート位置はゴール線の**てまえ**なので、走り出してすぐ線をこえる。
`lap` を 0 から始めると、そこで 1 しゅうめが終わったことになり、
「3 しゅう」と書いてあるのに**実際は 2 しゅうで終わって**しまう。
`lap = -1` から始めて、最初の通過で 0 になるようにした。

## あいての つよさ

| | CPU の速さ | かどでのへらし | ゴムひも | アイテム |
|---|---|---|---|---|
| やさしい | 0.82 | 0.55 | 0.55 | 0.7 |
| ふつう | 0.99 | 0.38 | 0.26 | 1.0 |
| つよい | 1.14 | 0.22 | 0.02 | 1.6 |

3 回まけると、じぶんのカートが少しはやくなる（最大 +9%）。
3 回まけたらつぎのコースもあくので、1 つのコースで止まったままにならない。

## 音

`sound.js` で WebAudio から作る。音のファイルは 0 こ。

**エンジンだけは鳴らしっぱなし**にして、速度でつまみ（音の高さ・大きさ・フィルタ）を
うごかしている。1 コマごとに音を作ると数が多すぎて重くなるため。

ほかに カウントダウン／はこ／ダッシュ／バナナ／こうら／スピン／草／しゅう回／ゴール。
BGM は 4 拍 1 小節ずつ先に予約していき、**さいごの 1 しゅうで 10% はやくなる**。

## たしかめたこと

ロボットに 2 しゅるいのうでまえで 10 コース × 3 回 × つよさ 3 だんかいを走らせた。

| | やさしい | ふつう | つよい |
|---|---|---|---|
| こども（はんのう 0.26 びょう）3 いいない | 26/30 | 20/30 | 12/30 |
| こども　1 い | 20/30 | 9/30 | 2/30 |
| じょうず（0.12 びょう）3 いいない | 30/30 | 30/30 | 24/30 |
| じょうず　1 い | 30/30 | 21/30 | 15/30 |

- **180 レースぜんぶでゴールできた**（コースの外に出て走れなくなることがない）
- つよさが上がると成績が下がる（どちらのうでまえでも順番どおり）
- 効果音 10 こ・エンジン音・BGM 3 つが本当に鳴っている（`OfflineAudioContext` の波形で確認）
- 667×375 / 900×440 / 1024×768 / 1280×720 でくずれない
