# まさきのカートレース

うしろから見る立体のカートレース。全 10 コース。
ブラウザだけで動く（サーバー処理なし・インストール不要・ライブラリなし・**画像も音のファイルも 0 個**）。

https://artakartlight1997.github.io/allprojects/kart/

## 作り直しました

最初は**真上から見おろす**形でしたが、
「小さくて見にくい・操作性もスピード感もない」という指摘を受けて、
**うしろから見る立体の道**（アウトラン方式）に作り直しました。

道を短い「セグメント」に切って、遠いセグメントほど小さく、近いほど大きく描きます。
道が向こうから流れてくるので、**速さがそのまま画面に出ます**。
カートも大きく描けるようになりました（前は画面のごく一部でした）。

- カーブ … セグメントごとの「曲がり」を足していくと道が曲がって見える
- 坂 … セグメントごとの「高さ」を変えると のぼり／くだりになる
- 遠くは 1 回のグラデーションでかすませる（セグメントごとに塗ると重い）

## そうさ

**画面の左半分をさわると左、右半分をさわると右**。指を置いている間ずっと曲がります。
アクセルは自動。パソコンは ← → でも動きます。

ボタンをさがす必要がないので、小さい子でも迷いません。

## 速く走るしくみ

| | |
|---|---|
| **ドリフト** | 同じ向きに曲がりつづけると火花がたまり、**指をはなした しゅんかんにダッシュ** |
| **ダッシュパネル** | 道の上のオレンジのパネルを ふむとダッシュ |
| 草の上 | 出るとガタガタして 最高速度が 46% まで落ちる |

## コース

10 コース。まっすぐ・カーブ・坂・ヘアピンの組み合わせと、
9 種類の色づかい（昼／海／森／夕やけ／さばく／雪山／夜／かざん／天空）。
1 レース 74〜122 秒（3 周）です。

## あいての強さ

3 だんかい。えらんだ人以外の 5 台が走ります。
はなされすぎ／勝ちすぎを防ぐ**ゴムひも**（少しだけ速さを合わせる）が入っているので、
ずっとひとりぼっちのレースになりません。

## クリアできないとき

**3 回まけると自分のカートが少し速くなり、つぎのコースも開きます**（3 だんかいまで）。

## たしかめたこと

自動で走るロボット（うでまえ 4 だんかい）に、各コース 4 回ずつ走らせました。

| むずかしさ | 子どもロボットの成績 |
|---|---|
| やさしい | 1〜2 位（かならず 3 位以内） |
| ふつう | 2.8〜4.3 位（コースによって勝ったり負けたり） |
| つよい | 5〜6 位（ほぼ勝てない） |

- **うまいロボットは全 10 コースで 3 位以内に入れる**（クリア不能なコースはない）
- **時間切れ 0 回**（コースアウトしたまま走れなくなる形になっていない）
- 3 回まけたあとの助けを入れると、**子どもロボットでも勝てる**
  （コース 6 で 2/8 勝 → 8/8 勝）
- 実際のマウス操作で、左半分＝左・右半分＝右・はなすとまっすぐ、が効く
- 効果音 11 ことBGM 3 つが本当に鳴っている（`OfflineAudioContext` の波形で確認）
- 667×375 / 900×440 / 1024×768 / 1280×720 でくずれない
