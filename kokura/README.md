# 小倉っ子クエスト 〜とまった モノレール〜

（おぐらっこ クエスト）ドラクエ みたいな 見おろし型の RPG。ぶたいは **千葉市 若葉区の 小倉台（おぐらだい）** と その まわり。
りな・ゆい・まさき・あおいの 4きょうだいが、まおう ヤミタカに うばわれた「モノレールを うごかす 3つの でんきだま」を
とりもどして、とまって しまった モノレールを また はしらせる。

https://artakartlight1997.github.io/allprojects/kokura/

**セーブ して「つづきから」あそべる。** まちに 出入りした とき・たたかいの あと・やどや・
えきちょうさん・メニューの「きろく」、それと 30歩ごとに じどうで きろくする
（子どもは セーブを わすれるので、とちゅうで とじても ちかい ところから つづけられる）。
きろくは `localStorage` の `kokuraquest.v1`。サーバーには 何も 送らない。
（まえの「北九州ばん」の きろくも そのまま つづきから あそべる。なかの なまえを かえて いないため）

## すすみかた

| じゅん | ばしょ | なかま・できごと |
|---|---|---|
| 1 | 小倉台（おぐらだい） | 小倉台駅の えきちょうさんに はなしを きく（りな・ゆい） |
| 2 | 千城台（ちしろだい） | まさき が なかまに |
| 3 | 大草谷津田（おおくさ やつだ） | 大ザリガニ キング → あかい でんきだま。北への みちが ひらく |
| 4 | 都賀（つが） | あおい が なかまに |
| 5 | よるの モノレール レール | 大ガラス ガーガー → あおい でんきだま。西への みちが ひらく |
| 6 | 桜木（さくらぎ）→ 加曽利貝塚（かそり かいづか） | どきまじん（縄文どきの まじん）→ きいろい でんきだま |
| 7 | やみの 御殿 | 3つの でんきだまで とびらが ひらく。まおう ヤミタカ |

ワールドの ちずでは、モノレールの レールが じっさいの 2号線と おなじ じゅん（千城台 ― 小倉台 ― 桜木）で つながって いる。
クリアまでは 小倉台駅で「うんきゅう」の まま とまって いて、クリアすると はしりだす。
ばしょの むき（北・西 など）は ゲームの ために かえて いる ところが ある。

とおせんぼ（けいびいん）と「でんきだまが ないと ひらかない とびら」で、じゅんばん どおりに すすむ。
ワールドは `tools/worldgen.py`、ダンジョンは `tools/dungen.py` で 作り、
「とおせんぼが 1つ ひらくごとに、つぎの ばしょ だけが 行けるように なる」ことを さがしかた（BFS）で たしかめた。

## あそびかた

- **いどう**：左下の じゅうじキー ／ 行きたい マスを タップ（みちを さがして あるく）／ やじるしキー
- **しらべる・はなす**：右下の「しらべる」／ 人や たからばこに ぶつかる ／ Enter・スペース
- **メニュー**：つよさ・どうぐ・じゅもん・きろく
- **たたかい**：たたかう／じゅもん／どうぐ／ぼうぎょ／にげる
- **タイミング ガード**：てきが こうげきして くる とき、わっかが まんなかの 円に
  かさなった しゅんかんに タップすると ダメージ はんぶん。
  （さいきんの RPG で はやっている「タイミングで ふせぐ」しくみ。しなくても すすめる）
- ぜんめつ しても さいごに よった まちで めを さます（おかねは はんぶん）

## バランス

`node kokura/tools/sim.js` で ゲームを はじめから おわりまで じどうで あそばせて、
「レベル上げに なんかい たたかうか」「ボスに かてる わりあい」を 数えて ととのえた。
（ガードは 3回に 1回 せいこう する ことに して いる）

| ばめん | レベル上げの たたかい | ボスに かつ わりあい |
|---|---|---|
| 大ザリガニ キング（Lv5 × 3人） | 約11かい | 100% |
| 大ガラス ガーガー（Lv10 × 4人） | 約23かい | 100% |
| どきまじん（Lv14） | 約27かい | 99% |
| まおう ヤミタカ（Lv18） | 約22かい | 100% |
