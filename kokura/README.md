# 小倉っ子クエスト 〜きえた 祇園太鼓〜

ドラクエ みたいな 見おろし型の RPG。りな・ゆい・まさき・あおいの 4きょうだいが、
北九州の 小倉・旦過市場・門司港・八幡・皿倉山 を 旅して、まおう くろがねに うばわれた
「小倉祇園太鼓」の ちからを とりもどす。

https://artakartlight1997.github.io/allprojects/kokura/

**セーブ して「つづきから」あそべる。** まちに 出入りした とき・たたかいの あと・やどや・
とのさま・メニューの「きろく」、それと 30歩ごとに じどうで きろくする
（子どもは セーブを わすれるので、とちゅうで とじても ちかい ところから つづけられる）。
きろくは `localStorage` の `kokuraquest.v1`。サーバーには 何も 送らない。

## すすみかた

| じゅん | ばしょ | なかま・できごと |
|---|---|---|
| 1 | 小倉の じょうかまち | とのさまに はなしを きく（りな・ゆい） |
| 2 | 旦過市場 | まさき が なかまに |
| 3 | 紫川の どうくつ | 大ガニ キング → あかい ばち。北への みちが ひらく |
| 4 | 門司港 | あおい が なかまに |
| 5 | 関門トンネル | 大ダコ カンモン → あおい ばち。西への みちが ひらく |
| 6 | 八幡 → 皿倉山 | テングまる → きいろい ばち |
| 7 | くろがね城 | 3本の ばちで とびらが ひらく。まおう くろがね |

とおせんぼ（兵士）と「ばちが ないと ひらかない とびら」で、じゅんばん どおりに すすむ。
ワールドは `tools/worldgen.py`、ダンジョンは `tools/dungen.py` で 作り、
「とおせんぼが 1つ ひらくごとに、つぎの ばしょ だけが 行けるように なる」ことを さがしかた（BFS）で たしかめた。

## あそびかた

- **いどう**：左下の じゅうじキー ／ 行きたい マスを タップ（みちを さがして あるく）／ やじるしキー
- **しらべる・はなす**：右下の「しらべる」／ 人や たからばこに ぶつかる ／ Enter・スペース
- **メニュー**：つよさ・どうぐ・じゅもん・きろく
- **たたかい**：たたかう／じゅもん／どうぐ／ぼうぎょ／にげる
- **タイミング ガード**：てきが こうげきして くる とき、わっかが まんなかの 円に
  かさなった しゅんかんに タップすると ダメージ はんぶん。
  （さいきんの RPG で はやっている「タイミングで ふせぐ」しくみ。しなくても すすめる）
- ぜんめつ しても さいごに よった まちで めを さます（おかねは はんぶん）

## まめちしき（まちの 人が 話す こと）

小倉城は 細川忠興が きずいた／小倉は 焼うどん 発祥の まち／旦過市場は「北九州の 台所」／
門司港は バナナの たたき売り 発祥／門司港駅は 大正時代の えき／関門トンネルは 歩いて 下関まで
いける／八幡の 製鉄所は 世界遺産の ひとつ／皿倉山からの 夜景は 新日本三大夜景。

## バランス

`node kokura/tools/sim.js` で ゲームを はじめから おわりまで じどうで あそばせて、
「レベル上げに なんかい たたかうか」「ボスに かてる わりあい」を 数えて ととのえた。
（ガードは 3回に 1回 せいこう する ことに して いる）

| ばめん | レベル上げの たたかい | ボスに かつ わりあい |
|---|---|---|
| 大ガニ キング（Lv5 × 3人） | 約10かい | 100% |
| 大ダコ カンモン（Lv9 × 4人） | 約25かい | 100% |
| テングまる（Lv13） | 約25かい | 77〜94% |
| まおう くろがね（Lv18） | 約25かい | 92〜100% |
