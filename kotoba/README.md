# まさきの ことばあて

ひらがな **4もじ** の ことばを **6回** までに あてる パズル。
英語の「Wordle（ワードル）」と おなじ あそびかたを、ひらがな・こども むけに した もの。

https://artakartlight1997.github.io/allprojects/kotoba/

## あそびかた

- 五十音ひょうの キーボードで 4もじ いれて「こたえる！」
- もじの いろ が かわる
  - **みどり** … もじも ばしょも あってる
  - **きいろ** … その もじは はいってる けど ばしょが ちがう
  - **はいいろ** … その もじは はいって いない
- 「゛゜」で か→が、は→ば→ぱ。「小」で つ→っ、や→ゃ
- こたえの **カテゴリ**（たべもの・いきもの など）が さいしょから ヒントに でて いる
- 「ヒント」ボタンで 1もじ だけ おしえて もらえる（1回だけ）
- パソコンなら ひらがな入力 と Enter・Backspace でも うてる

## きょうの もんだい と れんしゅう

- **きょうの もんだい**：1日 1もん。だれが あそんでも その日は おなじ こたえ。れんぞく きろく つき
- **れんしゅう**：なんかいでも
- とちゅうで とじても **つづきから**（`localStorage` の `kotobaate.v1`）

ことばは `site/words.js` に 94こ（ぜんぶ ひらがな 4もじ）。
