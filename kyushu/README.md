# りなのきゅうしゅうパズル

九州の県を、**形をはめて自然におぼえる**ゲーム。全 10 めん。
ブラウザだけで動く（サーバー処理なし・インストール不要・ライブラリなし・**画像も音のファイルも 0 個**）。

https://artakartlight1997.github.io/allprojects/kyushu/

## なぜ「はめる」ゲームなのか

「りなの全国制覇」（`/nihon/`）はすごろく＋クイズで、**答えを覚える**ゲームです。
こちらは**自分の手で形をはめる**ので、

- となりの県とのつながり（福岡の下は熊本、そのとなりは大分…）
- 大きさの感じ（佐賀はいちばん小さい、鹿児島は南に長い）

が、クイズに答えなくても手を動かしているうちに身につきます。

## 遊びかた

1. 右にならんだ**かけら**をゆびでひっぱる
2. 地図の正しいところではなすと、ぴたっとはまる
3. ぜんぶはまったらクリア

**まちがえてもへらない。** おぼえるためのゲームなので、まちがいをばつにしません。
そのかわり「◯◯けんは 北のほう だよ」とヒントが出て、**1 回もまちがえずにできると ★★★**。

| めん | やること |
|---|---|
| 1 | ぜんぶならんだ地図で、言われた県をタップ（まず見てみる） |
| 2〜3 | かげ（点線）を見ながらはめる |
| 4 | 名まえさがし |
| 5 | **かげなし**ではめる |
| 6 | 沖縄もいれて 8 つ |
| 7〜8 | 名まえさがし／かげなし 8 つ |
| 9〜10 | タイムアタック |

## 県のかたちについて

本物の地図をそのまま写したものではなく、**となりどうしのつながりと大きさの感じ**を
あわせたかんたんな形にしてあります。こまかい出入りまで入れると、
小学生には「はめられない」パズルになってしまうためです。

位置関係（北に福岡・佐賀・長崎、まん中に熊本、東に大分と宮崎、南に鹿児島）は
本物どおりなので、おぼえたことはそのまま本物の地図で使えます。

## たしかめたこと

- かたちが**かさなっていない**（0.5 きざみで 26034 点しらべて、2 つ以上に入る点は 6 点＝
  となりどうしのさかい目の線だけ。0.02%）
- **どの県も、まん中の点が自分のかたちの中にある**（はめる目じるしに使うため）
- 10 めんすべてを正しくといて、まちがい 0 でクリアできる
- わざとちがうところに置くと、ちゃんとまちがいになる
- 効果音 8 こと BGM 3 つが本当に鳴っている（`OfflineAudioContext` の波形で確認）
- 667×375 / 900×440 / 1024×768 / 1280×720 でくずれない
