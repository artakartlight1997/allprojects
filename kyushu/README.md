# りなのきゅうしゅうパズル

九州の県を、**形をはめて自然におぼえる**ゲーム。全 10 めん。
ブラウザだけで動く（サーバー処理なし・インストール不要・ライブラリなし・**画像も音のファイルも 0 個**）。

https://artakartlight1997.github.io/allprojects/kyushu/

## なぜ「はめる」ゲームなのか

「りなの全国制覇」（`/nihon/`）はすごろく＋クイズで、**答えを覚える**ゲームです。
こちらは**自分の手で形をはめる**ので、

- となりの県とのつながり（福岡の下は熊本、そのとなりは大分…）
- 大きさの感じ（佐賀はいちばん小さい、鹿児島は南に長い）

が、クイズに答えなくても手を動かしているうちに身につきます。

## 遊びかた

1. 右にならんだ**かけら**をゆびでひっぱる
2. 地図の正しいところではなすと、ぴたっとはまる
3. ぜんぶはまったらクリア

**まちがえてもへらない。** おぼえるためのゲームなので、まちがいをばつにしません。
そのかわり「◯◯けんは 北のほう だよ」とヒントが出て、**1 回もまちがえずにできると ★★★**。

| めん | やること |
|---|---|
| 1 | ぜんぶならんだ地図で、言われた県をタップ（まず見てみる） |
| 2〜3 | かげ（点線）を見ながらはめる |
| 4 | 名まえさがし |
| 5 | **かげなし**ではめる |
| 6 | 沖縄もいれて 8 つ |
| 7〜8 | 名まえさがし／かげなし 8 つ |
| 9〜10 | タイムアタック |

## 県のかたちについて

**本物の地図から起こしたデータです。**
geolonia/japanese-prefectures が公開している日本地図の SVG（都道府県ごとのパス）から
座標を取り出して、ゲーム用のデータファイルにしました。

- 島原半島・国東半島・薩摩半島／大隅半島（鹿児島湾のくびれ）など**半島の形**
- 長崎のギザギザした海岸線
- 島（対馬・壱岐・五島列島・天草・種子島・屋久島・甑島）

が入っています。1 県あたり 18〜54 個の点で、細かすぎず、形の特ちょうはつかめる量です。

沖縄は本物の地図でも別わくに書くほど遠いので、九州の南西へ動かして置いてあります。

はめるときは、**形の中でなくても「置く目じるし」の近くならはまる**ようにしました。
細い半島の中にぴったり指をはなすのは小学生には無理だからです。
目じるしは「県の中でいちばん縁から遠い点」を作るときに計算してあります
（頂点の平均だと、長崎のようにくねくねした県では県の外に出てしまいます）。

## たしかめたこと

- かたちが**かさなっていない**（0.5 きざみで 51936 点しらべて、2 つ以上に入る点は 3 点＝
  となりどうしのさかい目の線だけ。0.01%）
- **どの県も、置く目じるしが自分のかたちの中にある**（8 県すべて）
- **どの県の目じるしも、ほかの県の中に入っていない**（まちがってはまらない）
- 10 めんすべてを正しくといて、まちがい 0 でクリアできる
- わざとちがうところに置くと、ちゃんとまちがいになる
- 効果音 8 こと BGM 3 つが本当に鳴っている（`OfflineAudioContext` の波形で確認）
- 667×375 / 900×440 / 1024×768 / 1280×720 でくずれない
