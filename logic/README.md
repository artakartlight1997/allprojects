# あおいの おえかきロジック

「ピクロス」「イラストロジック」とも よばれる **おえかきロジック**。
たて と よこの すうじを ヒントに マスを ぬると、かくれた えが でて くる パズル。

https://artakartlight1997.github.io/allprojects/logic/

## あそびかた

- すうじは その れつで「**つづけて ぬる マスの かず**」。「3 1」なら 3マス ぬって、1マス いじょう あけて、1マス ぬる
- 「ぬる」で マスを ぬる。「✕」は ぬらない しるし（ぬる まえの メモ）
- ゆびで なぞると まっすぐ まとめて ぬれる
- まちがえて ぬると あかい ✕ に なって おしえて くれる。まちがい 0 で ★3、2かい までで ★2
- れつが そろうと すうじが うすく なり、のこりは じどうで ✕ に なる
- できると いろが ついて えが でる！

| むずかしさ | もんだい |
|---|---|
| かんたん 5×5 | ハート・チューリップ・さかな・きのこ・ほし・いえ |
| ふつう 8×8 | りんご・ねこ・かさ・おばけ・ロケット・さくらんぼ |
| むずかしい 10×10 | モノレール・パンダ・ちょうちょ・くるま・あおい・ソフトクリーム |

`tools/solve.py`（れつ ごとに ありえる ならべかたを しぼって いく とき方）で たしかめた。

とちゅうの ぬりかたと ★は `localStorage`（`oekakilogic.v1`）に のこる。
