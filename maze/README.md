# あおいのパクパクめいろ

**ドットイート**（めいろの おかしを ぜんぶ 食べる）タイプの レトロゲーム。めいろ 6 種・全 10 面。
ブラウザだけで動く（サーバー処理なし・インストール不要・ライブラリなし・**画像も音のファイルも 0 個**）。

https://artakartlight1997.github.io/allprojects/maze/

## レトロに見せるためにやったこと

- 絵は**すべて四角**（ドット絵）。曲線を一切使わない
- キャラは**文字の並び**で書いて、それを四角で描く（`'..1111..'` の `1` の位置だけ塗る）
- 数字は **3×5 ドットの手作りフォント**
- 画面全体に**走査線**（3 ドットごとの薄い黒線）と**ふちの暗がり**を重ねてブラウン管っぽく
- 音は**四角い波とノイズだけ**。BGM もアルペジオ（和音をばらして鳴らす）という、昔のゲーム機の作り

## 遊びかた

1. 十字ボタン（パソコンは矢印キー）でうごく。画面をなぞってもよい
2. めいろのおかしをぜんぶ食べるとクリア
3. おばけにつかまると 1 機へる。3 機なくなるとおしまい
4. 四すみの**大きいおかし**を食べると、おばけが青くなって食べられる（200・400・800・1600 点）

左右のはしはつながっていて、ぬけると反対がわに出られる。

## おばけ 4 ひきは性格がちがう

| | 考えかた |
|---|---|
| あか | まっすぐ追いかけてくる |
| ピンク | あおいの **4 マス先**をねらう（まわりこむ） |
| みず | 近いとはなれ、遠いと近づく |
| オレンジ | 気まぐれ。ときどきこっちを見る |

## めいろのデータ

6 つのめいろは 19×15 の文字データ。作るときに次を機械で確かめている。

- おかしが**ぜんぶ歩いて行ける**
- おばけ 4 ひきが**家から出てあおいのところまで行ける**
- **左右がつながっている段（トンネル）がある**
- いきどまりが多すぎない（6 か所まで）

まん中の「おばけの家」はどのめいろでも同じ形にしてある。こうすると幅の数えまちがいが起きない。

## 作りながら直したところ

### おばけが家から出てこなかった

おばけは「あおいに近づく向き」を選ぶ。あおいが家より下にいると、家の中でぐるぐる回りつづけて出てこなかった。
**家の中にいるあいだは、まず「出口の 1 つ上」をめざす**ようにして直した。

### ずっと追いかけてくると、だれもクリアできない

自動プレイのロボット 3 段階すべてが **0/10** だった。
本家と同じで、ときどき**四すみへちらばる時間**（7 秒 → 追いかけ 16 秒 → …）を入れた。
切りかわった瞬間はおばけが向きを反対にするので、目でも分かる。

あわせて、あおいのほうがはっきり速くなるように速さを調整した（1 面でおばけの 2.4 倍）。

## たしかめたこと

自動プレイのロボット 3 段階で 10 面ずつ遊ばせた。

| ロボット | クリア |
|---|---|
| おばけをよけない | 4 / 10 |
| 2 マス手前からよける | 5 / 10 |
| 3 マス手前からよける | **6 / 10** |

よけるほど強くなる、という当たり前のことがちゃんと起きている（＝逃げる操作に意味がある）。
もとのゲームと同じで簡単ではないが、3 機あり何度でもやり直せる。

- 効果音 14 ことBGM 2 つが本当に鳴っている（`OfflineAudioContext` の波形で確認）
- 667×375 / 900×440 / 1024×640 / 1280×720 でくずれない・コンソールエラー 0
