# りなのモグラたたき

あなから出てくるものをたたく。全 10 めん。
ブラウザだけで動く（サーバー処理なし・インストール不要・ライブラリなし・**画像も音のファイルも 0 個**）。

https://artakartlight1997.github.io/allprojects/mogura/

## 「連打すれば勝てる」を防ぐ作り

モグラたたきは、全部たたけばいいだけだと**画面を見ずにめちゃくちゃ連打するのが最適解**になり、
すぐ飽きてしまいます。そこで**たたいてはいけないもの**を混ぜました。

| 出てくるもの | 点 | |
|---|---|---|
| もぐら | +100 | たたく |
| きんもぐら | +300 | たたく |
| すばやいもぐら | +180 | たたく（出ている時間が短い） |
| ばくだん | **−250** | たたかない |
| ケーキ | **−150** | たたかない |
| **リナパパ**（ボス） | **+900** | たたく。**4 回**たたかないとひっこまない |

見てから決める必要があるので、連打はかえって損になります。
つづけて成功すると**れんぞくボーナス**（最大 2 倍）が付くので、
「あわてず、でも止まらず」がいちばん点が伸びます。

## ボスのリナパパ

ときどきパパが出てきます。**メガネのちょいぽちゃ**です。
4 回たたかないとひっこまないので、パパにかかりきりになっている間に
ほかのあなからどんどんモグラが出て手がまわらなくなる、というのがねらいです。
のこり回数は頭の上のバーで見えます。

## クリアできないとき

ほかのゲームと同じで、**3 回だめだと目ひょうが下がり、つぎのめんも開きます**（3 だんかいまで）。
1 つのめんで詰まって先に進めなくなることはありません。

## たしかめたこと

自動でプレイするロボット（うでまえ 3 だんかい）に、各めん 8 回ずつ遊ばせました。

| | よわい | ふつう | つよい |
|---|---|---|---|
| 1〜2 めん | 全勝 | 全勝 | 全勝 |
| 3〜8 めん | ときどき勝つ | ほぼ勝つ | 全勝 |
| 9〜10 めん | ほぼ負ける | 勝つ | 全勝 |

- **つよいロボットは 10 めんすべて 8/8 勝**（クリア不能なめんはない）
- **よわいロボットは 3 めん目以降は全勝しない**（連打だけでは勝てない）
- 目ひょうを下げたあと（3 回失敗後）は、**よわいロボットでも 10 めんすべて勝てる**
- 効果音 12 こと BGM 3 つが本当に鳴っている（`OfflineAudioContext` の波形で確認）
- 実際のクリックであなに当たる（667×375 / 900×440 / 1280×720 で確認）
- 667×375 / 900×440 / 1024×768 / 1280×720 / 1366×640 でくずれない
