# りなの へやから 脱出

スマホで ながく にんきの「**脱出ゲーム**」。とじこめられた へやの 4つの かべを 見てまわり、
どうぐを みつけて なぞを といて、とびらを あけて そとへ でる。ぜんぶで **10へや**。
へやが すすむ ごとに **あたらしい しかけ** が 1つずつ ふえる（まえの しかけも また でて くる）。

https://artakartlight1997.github.io/allprojects/nazo/

## あそびかた

- **◀ ▶** で かべを かえる。あやしい ところを **タップ** で しらべる
- みつけた どうぐは したの「もちもの」に はいる。どうぐを タップで えらんでから、つかいたい ところを タップ
- どうぐ どうしを あわせる ことも ある（でんち ＋ かいちゅうでんとう、えのぐ どうしを まぜる）
- えらんだ どうぐを もういちど タップすると「しらべる」（アヒルの おなかが あく など）
- ばんごうの かぎ・いろの かぎ・とけいの かぎ・やじるしの かぎ・ことばの かぎ・本の ならべかえ・ランプ パズル・ベル（おとの じゅんばん）が ある
- こまったら「**ヒント**」。おなじ ところで もういちど おすと、もっと くわしく おしえて くれる

| へや | なぞの ながれ |
|---|---|
| 1. りなの へや | まくら → ちいさな かぎ → ひきだしの メモ → ぬいぐるみを かぞえて 3けたの ばんごう |
| 2. キッチン | ながしの ドライバー → かべの ねじ → メモ → カレンダーの くだものの いろで れいぞうこ → ドアの かぎ |
| 3. にわの ものおき | かいちゅうでんとう → とけいの はこ → でんち → くらい すみを てらして 2けたの ばんごう |
| 4. おふろば 🆕シャワー・しらべる | おふろの せんを ぬく → アヒル → アヒルを しらべて ハンドル → シャワーの ゆげで かがみに 3けたの ばんごう |
| 5. リビング 🆕やじるしの かぎ | クッションの したの リモコン ＋ とけいの でんち → テレビに「↑ → → ↓」 |
| 6. しょさい 🆕本の ならべかえ・むしめがね | 本を ひくい じゅんに → ひきだしの むしめがね → ちずの ちいさな もじで 4けたの ばんごう |
| 7. アトリエ 🆕えのぐを まぜる | あか・あお・きいろを あつめて まぜ、むらさき・みどり・オレンジで 花を ぬる → ドアの かぎ |
| 8. やねうら 🆕ランプ パズル | でんとうで くらい かべの ヒント → おすと となりも かわる 3×3の ランプを ぜんぶ つける |
| 9. おんがくしつ 🆕おとの じゅんばん | ピアノの いすの ねじ → オルゴールの いろと おとの じゅんに ドアの ベルを ならす |
| 10. げんかん 🆕ことばの かぎ | ながぐつ・きんこ（ポスターの ばんごう）・くらい クローゼットの カード 3まい → 「そ と へ」 |

## つづきから

とちゅうで とじても、いまの へやで しらべた ことと もちものは のこる（`localStorage` の `nazoescape.v1`）。
クリアした へやも のこり、つぎの へやが ひらく。
自動テストで 10へや ぜんぶ さいごまで とける ことを たしかめた。まえの バージョンの セーブ（3へや クリア）も そのまま つかえる。
