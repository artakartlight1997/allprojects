# にっぽん大冒険

横スクロールアクションで遊びながら、47都道府県の**場所・形・県庁所在地・名産**を
おぼえるゲーム。ブラウザだけで動く（サーバー処理なし・インストール不要）。

https://artakartlight1997.github.io/allprojects/nihon/

## ねらい

**何度も遊んでいるうちに、クイズとして都道府県が分かるようになること。**
そのために、次の作りにしている。

- 出題は 9 種類。同じ県でも聞きかたを変えるので丸暗記になりにくい
- **まちがえた県ほど出やすい**。おぼえるまで何度でも出てくる
- 正解でも不正解でも、かならず**答えとまめちしき**を見せる
- 記録はブラウザに残る（localStorage）。次に開いてもつづきから
- **スタンプ帳**で、日本地図がおぼえ具合に応じて色づいていく

## 遊びかた

| 操作 | 動作 |
|---|---|
| ◀ ▶ | 歩く |
| ▲ | ジャンプ（長おしで高く跳ぶ） |
| 1〜4 キー | クイズの答えをえらぶ（PC） |

1 回の「たび」は **5 ステージ**。ステージごとに地方が 1 つ選ばれる。
ステージには**鳥居が 4 つ**立っていて、くぐるとその地方の都道府県クイズが出る。

- 正解 → **アイテムがもらえる**＋1000点＋のこり時間ボーナス
- 不正解 → コイン 3 まい。答えとまめちしきが出る（ペナルティはなし）

5 ステージ終わると、日本地図つきの結果画面になる。

## クイズの種類

| 種類 | 問題 |
|---|---|
| かたち → 名前 | シルエットを見て都道府県を当てる |
| 名前 → かたち | 4 つのシルエットから選ぶ |
| 場所 → 名前 | 地図の赤いところを当てる |
| 名前 → 場所 | 地図の ①〜④ から選ぶ |
| 県庁所在地 | 「〇〇県の県庁所在地は？」 |
| 県庁所在地 → 県 | 「〇〇市があるのはどこ？」 |
| 名産 → 県 | 「『りんご』でゆうめいなのは？」 |
| 県 → 名産 | 「〇〇県でゆうめいなものは？」 |
| 地方 | 「〇〇県はどの地方？」 |

はじめは**場所と名産**の問題だけ。おぼえた県が増えるにつれて、
形・県庁所在地の問題も混ざるようにしている（`kindsFor`）。
まちがいの選択肢も、はじめは**遠い地方**から選び、慣れてくると
**同じ地方**から選んで難しくする（`distractors`）。

### 答えが 2 つある問題を作らない

「みかん」は和歌山・愛媛・静岡のどれでも正しい。こういう名産は
**「この名産はどこ？」の問題に使わない**（`UNIQUE_FAMOUS`）。
逆に「〇〇県でゆうめいなものは？」では、まちがいの選択肢が
正解の県の名産と重ならないようにしている。

## 毎回ちがうところ

単調にならないよう、遊ぶたびに次が変わる。

| 変わるもの | 中身 |
|---|---|
| 地形 | 毎回その場で作る。同じ面は二度と出ない |
| 地方 | まだおぼえていない地方が選ばれやすい |
| 見た目 | 地方ごとに背景がちがう（雪原・町・寺・海・南国・森・山） |
| 時間帯 | あさ / ひる / ゆうがた / よる |
| 仕掛け | なし / かぜ / おいかけっこ / まっくら / 雨 |

### ハラハラする仕掛け

| 仕掛け | 中身 |
|---|---|
| かぜ | 左右にゆっくり押される。ジャンプの着地がずれる |
| おいかけっこ | 大きなだんごが転がって追ってくる。走っていれば追いつかれない |
| まっくら | りなのまわりだけ明るい。夜のステージだけ |
| 雨 | 雨が降る（見た目だけ） |

1 面には仕掛けを入れない（まず操作に慣れてもらうため）。

## やさしくしてあるところ

- 体力は 3。敵・トゲに 3 回当たるまで平気。落ちても 1 減るだけ
- 体力が 0 になっても**ゲームオーバーにはならない**。その場から再開
- 鳥居の手前とトゲの手前には、かならずチェックポイント
- クイズをまちがえても、進行に不利にはならない
- 追ってくるだんごは、りなより**おそい**（4.4 対 7.5 タイル/秒）

## ステージ生成の決まり

`world.js` は、作るときの決まりで「クリアできない面」が出ないようにしている。

- 穴のはばは **2 タイル**まで（ジャンプで 5.9 タイル跳べる）
- 段差は **2 タイル**まで（ジャンプで 3.4 タイル上がれる）
- 浮いている足場は地面から **3 タイル**上（跳んで届く高さ）
- 足場は**平らな所の上にだけ**置く。置いたあと、穴や上り段差の真上に
  かぶさっているものは消す（天井になって跳べなくなるため）
- スタートから **14 タイル**以内に敵は置かない
- トゲはステージ 3 以降だけ

作ったあと `verify()` が決まりを守れているか数える。

### 自動プレイでの確認

「右に進んで、穴か壁か敵があれば跳ぶ」だけの単純な自動プレイに
**300 ステージ**遊ばせて、ゴールにたどり着けるかを見ている。
直近の結果は **292 / 300 クリア**、1 ステージあたりのクイズ 3.8 問、
やられた回数 0.44 回。残りは自動プレイの下手さによるもので、
落ちてもチェックポイントから再開できるので詰みはしない。

## 地図データ

`site/data.js` は `tools/genprefdata.py` が作る。**手で編集しないこと。**

```
python3 tools/genprefdata.py site/data.js
```

- もとデータは国土数値情報由来の GeoJSON（`dataofjapan/land`）。
  13MB あるのでリポジトリには入れず、無ければ実行時に取りに行く
- 県境の点を Ramer-Douglas-Peucker で減らし、0〜2000 の整数にしている
- たて・よこを同じ倍率でちぢめているので、日本の形はゆがまない
- 遠くの離島（小笠原・南鳥島・沖ノ鳥島・奄美・先島）は落としてある。
  入れると地図が間延びして、都道府県が豆粒になるため
- 沖縄は、日本の地図でよくあるように**左上の枠**の中に移してある
- シルエットのクイズでは、いちばん大きい島に対して小さすぎる島は描かない
  （東京都が伊豆諸島のせいで豆粒になるのを防ぐ）

県庁所在地・地方・名産・まめちしきも同じスクリプトの中に書いてある。

## ファイル

| ファイル | 役割 |
|---|---|
| `site/data.js` | 47都道府県のデータ（生成物） |
| `site/quiz.js` | 問題づくり・おぼえ具合の記録 |
| `site/world.js` | ステージの自動生成 |
| `site/game.js` | 物理・当たり判定・進行 |
| `site/render.js` | 地図・キャラ・背景の描画 |
| `site/ui.js` | タイトル・HUD・クイズ画面・スタンプ帳・入力・ループ |
| `tools/genprefdata.py` | 地図データの生成 |

物理の数値（`GRAVITY` / `JUMP_V` / `MOVE_SPEED`）は「りなの大冒険」と同じ。
キャラは一回り大きくしてある（当たり判定 0.85 × 1.15 タイル、見た目は 1.35 倍）。

## 画面について

- 横画面でないと「よこ向きにしてね」と出る。横スクロールなので幅が要る
- タイトルの「ぜんがめん」で全画面にできる。iPhone の Safari は
  要素の全画面表示に対応していないので「ホーム画面に追加」を案内する
- ノッチのある端末で操作ボタンが隠れないよう、セーフエリアを避けている
- りながボタンと重なる位置にいるあいだ、ボタンを薄くする

## 配信

`.github/workflows/pages.yml` が main への push で GitHub Pages に置く。
「りなの大冒険」と同じサイトの `/nihon/` に入る。

js を直したら `site/index.html` の `?v=` の番号を増やすこと。
増やさないと、前に遊んだ人のブラウザが古い js を読んだままになる。
