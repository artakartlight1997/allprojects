# りなの全国制覇

日本地図をめぐるすごろく（桃鉄のような遊びかた）＋横スクロールアクションで、
47都道府県の**場所・形・県庁所在地・名産**をおぼえるゲーム。
ブラウザだけで動く（サーバー処理なし・インストール不要）。**対象は小学4年生**。

https://artakartlight1997.github.io/allprojects/nihon/

## 2 つのモード

| モード | 中身 |
|---|---|
| **すごろく（全国制覇）** | サイコロで日本地図をめぐり、47県の名産カードを集める。パパとの競争 |
| **アクション** | 横スクロールで進み、鳥居をくぐるとクイズ。1回の旅は5ステージ |

記録（おぼえ具合・スタンプ帳）は 2 つのモードで共通。すごろくは途中でやめても
localStorage に残るので、次に開くとつづきから。

## すごろく「全国制覇」

### 盤面

47都道府県が「マス」で、**となり合う県が道でつながっている**。
道は本物の県境から自動で作った（`tools/genprefdata.py`）。海をわたる所は、
実際に行き来できるルートだけを手で足してある。

| 海をわたる道 | |
|---|---|
| 北海道 ― 青森 | 青函トンネル |
| 兵庫 ― 徳島 | 淡路島・大鳴門橋 |
| 岡山 ― 香川 | 瀬戸大橋 |
| 広島 ― 愛媛 | しまなみ海道 |
| 山口 ― 福岡 | 関門トンネル |
| 鹿児島 ― 沖縄 | 船・ひこうき（地図では点線） |

道は全部で 93 本。長野が 8 県ととなり合うなど、実際のとなり関係と一致している。

### 遊びかた

1. **サイコロを ふる**（1〜6）
2. **ちょうど出た目のぶんだけ進んだ県**が緑に光る。行きたい県をタップ
   （行ったり来たりしてよいので、選べる県はけっこう多い＝どこへ行くか考える楽しさ）
3. 止まった県で
   - カードを持っていない → **クイズ1問。正解でその県の名産カード**（+500）
   - カードを持っている → **その土地のミニゲーム**
   - たまに **ハプニング**（温泉・宝箱・新幹線・まいご・おみやげ）
4. **もくてきち**に先に着いた方が +3000。着くと次のもくてきちが決まる
5. **地方をぜんぶそろえると +5000**（九州制覇！ 東北制覇！）
6. **47枚 集めたら 全国制覇**

ライバルは**パパ**。正解率は 55% にしてあるので、子どもがちゃんと勝てる。

### コース（地方で区切って遊べる）

短い時間で遊びたいときのために、地方ごとのコースがある。

| コース | 県の数 |
|---|---|
| 日本一周 | 47 |
| 北海道・東北 | 7 |
| 関東 | 7 |
| 中部 | 9 |
| 近畿 | 7 |
| 中国・四国 | 9 |
| 九州・沖縄 | 8 |

北海道は 1 県しかないので東北とまとめ、四国は 4 県なので中国とまとめている。
どのコースでも、その中だけで全部の県を行き来できることを確かめてある。

## ミニゲーム（止まった場所で変わる）

**どのミニゲームになるかは地方で決まり、中身はその県のものになる。**

| 地方 | ミニゲーム | 中身 |
|---|---|---|
| 北海道・東北 | **めいさんキャッチ** | 落ちてくる名産のうち、**その県のものだけ**を受け止める。よその県の名産はおじゃま |
| 関東・近畿 | **はやおしクイズ** | その県の問題を 3 問つづけて |
| 中部・中国 | **はしってゴール** | 短い横スクロール。背景はその地方の景色。タップでジャンプ（2回まで） |
| 四国・九州沖縄 | **きたからじゅんに** | 4 つの県を**北から順にタップ**。南北が 50km 以上はなれた県だけを選ぶので、運まかせにならない |

どれも 20〜30 秒。しっぱいしてもコインは減らない。

## クイズ

出題は 9 種類。同じ県でも聞きかたを変えるので、丸暗記になりにくい。

| 種類 | 問題 |
|---|---|
| かたち → 名前 | シルエットを見て都道府県を当てる |
| 名前 → かたち | 4 つのシルエットから選ぶ |
| 場所 → 名前 | 地図の赤いところを当てる（見つけやすいよう輪を描く） |
| 名前 → 場所 | 地図の ①〜④ から選ぶ |
| 県庁所在地 | 「〇〇県の県庁所在地は？」 |
| 県庁所在地 → 県 | 「〇〇市があるのはどこ？」 |
| 名産 → 県 | 「『りんご』でゆうめいなのは？」 |
| 県 → 名産 | 「〇〇県でゆうめいなものは？」 |
| 地方 | 「〇〇県はどの地方？」 |

- はじめは**場所と名産**の問題だけ。おぼえた県が増えると形・県庁所在地も混ざる
- まちがいの選択肢も、はじめは**遠い地方**から、慣れると**同じ地方**から選ぶ
- **まちがえた県ほど、次から出やすい**（`weightOf`）
- 正解でも不正解でも、**答えとまめちしきを必ず見せる**

### 答えが 2 つある問題を作らない

「みかん」は和歌山・愛媛・静岡のどれでも正しい。こういう名産は
「この名産はどこ？」には使わない（`UNIQUE_FAMOUS`）。逆に
「〇〇県でゆうめいなものは？」では、まちがいの選択肢がその県の名産と
重ならないようにしている。

## スタンプ帳

日本地図が**おぼえ具合で色づく**（灰 → 黄 → 黄緑 → 緑）。
地図をタップすると、その県の形・よみ・県庁所在地・地方・名産・まめちしき・
これまでの正解数が出る。すごろくからもアクションからも開ける。

## アクションモード

横スクロール。ステージは毎回その場で作る（同じ面は二度と出ない）。
鳥居を 4 つくぐると 4 問のクイズ。1 回の旅は 5 ステージ。

- 地形・地方・背景・時間帯（あさ/ひる/ゆうがた/よる）が毎回変わる
- 仕掛けが毎回 1 つ：かぜ / おいかけっこ / まっくら / 雨
- 体力 3。体力 0 でもゲームオーバーにはならず、その場から再開
- 穴は 2 タイルまで、段差は 2 タイルまで、と作るときの決まりで無理な面が出ないようにしている

## 小学4年生むけに気をつけたこと

- 都道府県の漢字は 4 年生で習うので、そのまま漢字で出す。ふりがなはカードに載せる
- 説明はやさしい日本語（「もくてきち」「めいさん」など）
- しっぱいしても損をしない。クイズをまちがえてもコインはもらえる
- パパは弱め。勝てるからまたやりたくなる
- ミニゲームは 1 回 20〜30 秒。飽きる前に終わる

## 地図データ

`site/data.js` は `tools/genprefdata.py` が作る。**手で編集しないこと。**

```
python3 tools/genprefdata.py site/data.js
```

- もとデータは国土数値情報由来の GeoJSON（`dataofjapan/land`）。
  13MB あるのでリポジトリには入れず、無ければ実行時に取りに行く
- 県境の点を Ramer-Douglas-Peucker で減らし、0〜2000 の整数にしている
- たて・よこを同じ倍率でちぢめているので、日本の形はゆがまない
- 遠くの離島（小笠原・南鳥島・沖ノ鳥島・奄美・先島）は落としてある
- 沖縄は、日本の地図でよくあるように**左上の枠**の中に移してある
- **となりの県**は県境の点の近さ（約 2.7km 以内）から自動で求め、
  海をわたる 6 本を手で足している。全部つながっているかも検査する

県庁所在地・地方・名産・まめちしきも同じスクリプトの中に書いてある。

## 確かめかた

ブラウザ（Playwright）で自動的に遊ばせて確かめている。

- **すごろく**: 自動でサイコロを振り、県を選び、クイズに答え、ミニゲームを
  こなして地方制覇までいくのを通しで実行。エラーが出ないこと
- **コース**: どのコースでも、その中の全県が行き来できること
- **ならべかえ**: 96 回作って、南北が近すぎる（運になる）組み合わせが 0 件
- **アクション**: 「右に進んで穴か壁か敵があれば跳ぶ」だけの自動プレイに
  300 ステージ遊ばせ、292 がゴール到達
- **クイズ**: 2000 問作って、選択肢の重複・答えの範囲・空の問題文がないこと
- **描画**: 全 8 地方 × 4 時間帯 × 5 仕掛け（160 とおり）でエラーなし

## 画面について

- 横画面でないと「よこ向きにしてね」と出る
- タイトルの「ぜんがめん」で全画面にできる。iPhone の Safari は
  要素の全画面表示に対応していないので「ホーム画面に追加」を案内する
- ノッチのある端末で操作ボタンが隠れないよう、セーフエリアを避けている

## 配信

`.github/workflows/pages.yml` が main への push で GitHub Pages に置く。
「りなの大冒険」と同じサイトの `/nihon/` に入る。

js を直したら `site/index.html` の `?v=` の番号を増やすこと。
増やさないと、前に遊んだ人のブラウザが古い js を読んだままになる。
