# りなのおそうじ大作戦

画面をこすってよごれを落とすゲーム。落とし物を掘り出してコインを集め、
道具を強くして、もっと速くきれいにできるようになっていく。
ブラウザだけで動く（サーバー処理なし・インストール不要）。

https://artakartlight1997.github.io/allprojects/osouji/

## 遊びかた

1. 画面を**ゆびでこする**とよごれが落ちる
2. よごれの下に**おとしもの**がかくれている。掘り出すとコインになる
3. **98.5%** まで落とすとその部屋は終わり。**97% 以上でピカピカボーナス**
4. 部屋のあいだの**おみせで道具を強くできる**。道具はずっと残る

1回のそうじで **5部屋**まわる。

## よごれは3しゅるい

下じきを3まいに分けて重ねている。上から順に落としていく感覚になる。

| | 見た目 | 1こすりで落ちる量 | 効く道具 |
|---|---|---|---|
| ほこり | うすい灰色 | 0.22 | せんざい |
| あぶら汚れ | こい茶色 | 0.09 | せんざい |
| こびりつき | 黒っぽい | 0.03 | せんざい＋**たわし** |

きれい度は 3まいの残りを 60×34 に縮めて透明度を足し合わせて出している。
こびりつきは重みを 2.4 倍にしてあるので、落としたときの手ごたえが大きい。

## 道具（買うとずっと残る）

| 道具 | 効果 | 最大 |
|---|---|---|
| ブラシ | こする幅が広がる（28 → 82） | Lv6 |
| せんざい | よごれ全体の落ちが速くなる（→ 310%） | Lv6 |
| たわし | こびりつきに強くなる（→ 450%） | Lv5 |
| ロボット | かってにそうじしてくれる（最大5だい） | Lv5 |
| すいとう | そうじの時間がのびる（40秒 → 80秒） | Lv5 |
| おこづかい | もらえるコインがふえる（→ 225%） | Lv5 |

道具・コイン・記録は `localStorage`（`osouji.v1`）に残る。
遊ぶほど汚れも増えるが、それ以上に道具が強くなるので前より速く終わる。

## おとしもの

100円玉・10円玉・ヘアピン・ビー玉・ネコのおもちゃ・シール・ボタン・あめ玉。
よごれの下にランダムに 5〜10 個うまっていて、その場所の透明度が下がると
出てくる。「おこづかい」レベルでもらえる額が増える。

## 手ごたえの調整

自動プレイ（1秒で画面幅の1.1倍うごく指をまねる）で測った結果。

| 道具 | きれい度 | 点 | のこり時間 |
|---|---|---|---|
| なし | 96〜97% | 1,300前後 | 0秒 |
| なかば | 98.8% | 2,800〜4,000 | 42秒 |
| MAX | 99% | 5,000〜6,300 | 69秒 |

道具なしでは時間いっぱい使ってもピカピカに届かないことがあり、
そろえると半分以下の時間で終わって時間ボーナスが乗る。
**同じ部屋を前より速くきれいにできる**、が数字で出るようにしてある。

## 部屋

キッチン / おふろ / げんかん / まど / いえのまえ の5つ。
どれも画像を使わず図形で描いている。よごれの置きかたは種から決まる
乱数なので、同じ種なら同じ汚れかたになる。

## ファイル

| `site/rooms.js` | 部屋の絵・よごれの生成・おとしもの |
| `site/game.js` | こする・きれい度の計測・道具・お金まわり |

## 確かめたこと

- 道具なし / なかば / MAX × よごれレベル1・4・7 の9とおりで、
  きれい度と残り時間に はっきり差が出ること
- 900×460 / 667×375 / 568×320 / 1280×720 で 5部屋通してエラーが出ないこと
- 部屋をこなすごとに点が伸びること（1,434 → 3,624）
- おとしものが全部見つかること

## 配信

`.github/workflows/pages.yml` が main への push で GitHub Pages に置く。
同じサイトの `/osouji/` に入る。js を直したら `site/index.html` の
`?v=` の番号を増やすこと。
