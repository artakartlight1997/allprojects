# ゆいのねこオセロ

**オセロ（リバーシ）**。8×8。あいての強さは **5 だんかい**。
ブラウザだけで動く（サーバー処理なし・インストール不要・ライブラリなし・**画像も音のファイルも 0 個**）。

https://artakartlight1997.github.io/allprojects/othello/

## 遊びかた

1. あなたは**くろねこ**。ひかっているますをおす
2. 自分のこまであいてのこまをはさむと、ぜんぶ自分の色になる（ななめもはさめる）
3. ますの**数字は「そこに置くと何こ取れるか」**
4. どちらも置けなくなったらおしまい。多いほうの勝ち

置けないときは自動でパスになる。ヒント（置ける場所と取れる数）はいつでも消せる。

## あいての強さ

| | 考えかた |
|---|---|
| こねこ | てきとうに置く |
| こどもねこ | いちばんたくさん取れるところ |
| おとなねこ | ますの「うれしさ」で決める（四すみをねらう） |
| せんせいねこ | 2 手先まで読む |
| ねこの王さま | **4 手先まで読む**（アルファベータ法） |

ますの「うれしさ」は、四すみが +120、四すみのとなりが -40。
四すみのとなりに置くとあいてに四すみを取られるので、大きなマイナスにしてある。

## たしかめたこと

人がわを 3 とおりの打ちかたに置きかえて、5 だんかいと対戦させた。

| 人がわ | こねこ | こどもねこ | おとなねこ | せんせいねこ | ねこの王さま |
|---|---|---|---|---|---|
| てきとうに打つ | 42% | 25% | 17% | 8% | **0%** |
| たくさん取る | 42% | 0% | 100% | 0% | **0%** |
| 四すみをねらう | 67% | 100% | 100% | 0% | **0%** |

（数字は人がわの勝率。てきとうに打つ相手には **42 → 25 → 17 → 8 → 0%** と、きれいに強くなっている。
「たくさん取る」「四すみ」は打ちかたが毎回同じなので、同じ試合になり 0% か 100% になる）

考える時間は**ねこの王さまで最大 83 ミリびょう**（へいきん 25）。待たされる感じはない。
