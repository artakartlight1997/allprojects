# ゆいの パクパク おおきくなれ

大きな テーブルの 上で おかしを パクパク たべて、**60びょうで いちばん 大きく なった 子が かち**。
小さい あいてに ぶつかると すこし もらえる（大きい 子に ぶつかると とられる）。全5カップ。

https://artakartlight1997.github.io/allprojects/paku/

2026年の 小学生に 人気の ソフト「カービィのグルメフェス」（たべて 大きく なって きそう）を
ヒントに した あそび。

## あそびかた

- 画面を おさえた ところが スティックの まんなか。**ひっぱった ほうへ すすむ**（やじるしキーでも OK）
- いちご 1・クッキー 2・ドーナツ 3・プリン 5・ケーキ 10 だけ 大きく なる
- 大きく なるほど すこし おそく なる
- 3い いないで つぎの カップが ひらく。メダル（1〜3い）が のこる

## ライバル（CPU）

いちばん とくな おかし（ねだん ÷ きょり）を ねらい、大きい 子からは にげる。
カップが すすむほど はやく、かしこく なり、キングカップでは 小さい 子を ねらって くる。
「いちばん ちかい おかしを たべつづける だけ」の じどう プレイで、
いちごカップは 大きく かち、キングカップは ぎりぎり かつ くらいに した。
