# みんなでパーティ

**1 だいの スマホ／タブレットを かこんで、2〜4 人で同時に**あそぶミニゲーム集。
画面を人数ぶんに分けて、それぞれのばしょがその人のボタンになる。
ブラウザだけで動く（サーバー処理なし・インストール不要・ライブラリなし・**画像も音のファイルも 0 個**）。

https://artakartlight1997.github.io/allprojects/party/

## 遊びかた

1. スマホやタブレットを**たいらに置いて**、まわりに集まる
2. タイトルで**人数（2〜4 人）**・**なんかい勝負（3／5／7）**・**キャラ**・**名前**をえらぶ
3. ミニゲームが 1 つ出る → だれかがおすと **3・2・1** のカウントダウン
4. **自分のばしょ**をおす。ミニゲームごとにおしかたがちがう
5. 1 い 3 てん、2 い 2 てん、3 い 1 てん、4 い 0 てん
6. ぜんぶ終わって、いちばんてんすうが多い人がゆうしょう

パソコンでためすときは **Z / X / N / M** が 1P / 2P / 3P / 4P。

## 5 このミニゲーム

| # | なまえ | なにをする | まけになるの |
|---|---|---|---|
| 1 | はやおし | まん中が光ったら**すぐおす**。早い人が 1 い | 光る前におすと**フライング**で最下位 |
| 2 | れんだ | **5 びょう**でできるだけたくさんおす | ― |
| 3 | ぴったり | わっかが小さくなって**消える瞬間**におす | ずれた分だけ順位がさがる |
| 4 | いろあわせ | まん中が**自分の色のときだけ**おす。12 びょう | ちがう色でおすと **−1** |
| 5 | ながおし | ずっとおしておく → 光ったら**すぐはなす** | 光る前にはなすと最下位 |

じゅんばんは毎回シャッフルされる。5 かい勝負なら 5 こぜんぶが 1 回ずつ出る。

## 名前と CPU

タイトルで、それぞれのばしょに**名前を入れられる**（6 文字まで）。
名前のところをおすとキーボードが出る。入れなければキャラの名前がそのまま使われる。
入れた名前は `localStorage` にのこるので、つぎからは入れなおさなくてよい。

名前の下の **人／CPU** をおすと、そのばしょが CPU にかわる。
**3 人しかいないときは 1 つを CPU にすれば 4 人ぶんで遊べる。**

つよさは 3 だんかい。はんのう時間・ばらつき・ミスの多さがかわる。

| つよさ | はんのう | れんだ | ぴったりのずれ | フライング |
|---|---|---|---|---|
| よわい | 0.44 びょう ± 0.15 | 5.2 かい/びょう | ± 0.10 | 14% |
| ふつう | 0.31 びょう ± 0.10 | 6.9 かい/びょう | ± 0.058 | 7% |
| つよい | 0.20 びょう ± 0.05 | 9.2 かい/びょう | ± 0.028 | 2% |

**CPU も人とまったく同じ `playerDown` / `playerUp` をつかっておす。**
中でこっそり点を足したりしないので、「CPU だけずるをしている」ことにならないし、
人と CPU がまざっててんすうのつけかたを分けなくてよい。

はんのう 0.30 びょうの人とくらべて、CPU がラウンドをとったわりあいは
**よわい 18% / ふつう 41% / つよい 82%**（24 試合ずつ、自動で対戦させて計測）。

### 名前を入れるところだけ HTML の input

キャンバスに自分で字を打つしくみを作ると、**かな漢字の入力がつかえない**。
なので名前のはこだけは、ブラウザの `<input>` をそのばしょにかさねて出している。

`mousedown` で `preventDefault()` をしないと、そのあとブラウザがキャンバスに
フォーカスをうつして、ひらいたばかりの入力欄がすぐ閉じてしまう。

## 4 人が同時にさわる、をどうやるか

### 1. ゆびを 1 本ずつ見わける

`touchstart` / `touchend` の `identifier` を**だれのばしょか**に対応づけて持っておく
（`touchOwner`）。ゆびがはなれたとき、同じ人のゆびがまだ残っていないかを見てから
「はなした」にする。こうしないと、1 人が 2 本のゆびでおしているときに
片方をはなしただけで「はなした」になってしまう。

`click` イベントは 1 つしか来ないので使っていない。

### 2. 向かいがわの人には字をさかさまにしない

4 人が台をかこむと、向かいの 2 人からは画面が**上下さかさま**に見える。
なので上がわ 2 人のばしょは、中身をぜんぶ **180 度まわして**描いている
（`drawInZone` が `ctx.rotate(Math.PI)` する）。名前・てんすう・「フライング！」などが
その人の向きで読める。

| 人数 | ばしょのわけかた |
|---|---|
| 2 人 | 上下に半分ずつ（上の人はさかさま） |
| 3 人 | 下を左右 2 つ、上に 1 つ（上の人はさかさま） |
| 4 人 | 4 すみ（上の 2 人はさかさま） |

### 3. まん中には字を書かない

まん中のあいずは**両方の人から同時に見える**必要がある。字だとどちらかが読めないので、
まん中は**まる・色・わっかだけ**にしてある。

- カウントダウンの「3・2・1」→ **まるの数**（3 こ→2 こ→1 こ）
- はやおしの「いま！」→ 大きな**びっくりマーク**（左右対称なのでさかさまでも読める）
- いろあわせ → **色のまる**そのもの

### 4. 自分の色がわかるようにする

いろあわせは「まん中の色 = 自分の色か？」を見るゲームなので、
**自分の色**がひと目でわかる必要がある。ばしょのふちと、名前のよこの**小さい色のまる**が
その色。キャラの顔の色（りな＝きいろ、あおい＝ピンク）とはべつなので、
色のまるは顔に重ねずによこに置いている。

ばしょが光っているときは下じきがその色になるので、**字はこい色**に切りかえる
（白い字のままだと読めない）。

## たて向きでも遊べる

ほかのゲームは「よこ向きにしてね」と出すが、これだけはたて向きでも遊べる。
**みじかいほうの辺を 450 にそろえる**ようにした（`layout()`）。

| | よこ向き | たて向き |
|---|---|---|
| きめうちにする辺 | たて = 450 | よこ = 450 |
| 1 人ぶんのばしょ（4 人・iPhone） | 487 × 225 | 225 × 487 |

たてを 450 に固定したままだと、たて向きのときによこが 208 しかなくなって、
1 人ぶんのばしょが細長くなりすぎてしまう。

たて向きのときは、あいたところに**台をかこんでいる絵**とヒントを出す。

## とちゅうでやめる

あそんでいる最中はまちがっておさないように**やめるボタンは出さない**。
ミニゲームのせつめいが出ているあいだだけ、まん中に小さい **×** が出る。
アプリを裏に回したときも（`visibilitychange`）タイトルにもどる。

## 音

`sound.js` で WebAudio から作る。音のファイルは 0 こ。

- **カウントダウン**（3・2・1 で音が上がる）・**スタート**・**タップ**（人ごとに音の高さがちがう）
- **せいかい**／**ミス**・**ラウンド終わり**・**ゆうしょう**
- BGM は 4 拍 1 小節ずつ**先に予約**していく（`bgmPump`）。3 しゅるいのコード進行

iPhone の**マナーモードでも鳴る**ように、無音のループ音を 1 つだけ鳴らしっぱなしにして
`navigator.audioSession.type = 'playback'` を立てている（ほかのゲームと同じしくみ）。

### 音が鳴っているかのたしかめかた

耳で聞けないので、`OfflineAudioContext` で波形を出して、20 ms ごとの音の大きさで見た。

```
sfxCount(3)  さいだい 0.188   sfxGo()  さいだい 0.504   sfxWin()  さいだい 0.612
BGM0 さいだい 0.368  鳴っている 91%
BGM1 さいだい 0.384  鳴っている 91%
BGM2 さいだい 0.369  鳴っている 88%
```

## たしかめたこと

- ロボットに 4 人ぶんをおさせて 1 試合を通し、**2 人・3 人・4 人**すべてで最後まで進む
- **人＋CPU のまざった試合**（人 2＋CPU 1、人 1＋CPU 3、ぜんぶ CPU）が最後まで進む
- CPU のつよさ 3 だんかいが、**よわい→ふつう→つよい の順にちゃんと強くなる**
- 名前を入れて Enter → その名前がばしょとけっか画面に出る
- うでの差（はんのう速度）をつけると、**うまい人ほどてんすうが高くなる**
- 4 本のゆびを**同時に**つけて、それぞれが自分のぶんだけカウントされる
- 667×375／844×390／1024×768／1280×720／390×844（たて）でくずれない
- 5 つの効果音と 3 つの BGM が**ほんとうに鳴っている**（波形で確認）
