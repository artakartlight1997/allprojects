# りなのキラキラパズル

となりと入れかえて、同じたまを 3 つならべて消すパズル。**20 めん**。
ブラウザだけで動く（サーバー処理なし・インストール不要・ライブラリなし・**画像も音のファイルも 0 個**）。

https://artakartlight1997.github.io/allprojects/puzzle/

## 遊びかた

1. たまをおして、つぎに**となりのたま**をおすと入れかわる
2. 同じたまが**たてかよこに 3 つ**ならぶと消える
3. そろわないときはもどるだけ。**手はへらない**
4. たまが落ちてまたそろうと**れんさ**。れんさするほど点が高い
5. 手がなくなるまでに**もくひょう**をたっせいすればクリア

## とくべつな たま

| ならべかた | できるもの | はたらき |
|---|---|---|
| 4 つならべる | すじのたま | そのれつ（よこ or たて）ぜんぶ消える |
| たてとよこが十字 | ばくだん | まわり 3×3 が消える |
| 5 つならべる | にじいろのたま | となりと入れかえると、**その色ぜんぶ**消える |

**とくべつなたまどうしを入れかえると両方はつどう。** 作るかちを出すため。

## もくひょうは 3 しゅるい

| しゅるい | ないよう | めん |
|---|---|---|
| てんすう | きめられた点をためる | 1〜5, 17, 20 |
| いろあつめ | きめられた色を何こか消す | 6〜10, 16, 18 |
| こおりわり | こおりのマスをぜんぶわる | 11〜15, 19 |

こおりのマスは、**その上のたまを消すと 1 まいわれる**（あついこおりは 2 まい）。

## つくって直したところ

### こおりを すみっこに おかない

さいしょ、こおりをばんめんの**四すみ**に置いていた。すみのマスは
「よこ 1 本」か「たて 1 本」でしかそろえられないので、
**さいごの 1 マスがどうしても消えない**ことが起きる。

ロボットにとかせたら、こおりのめんで **98% までいって何回もしっぱい**した。
すみっこをやめて、まん中よりの形にしたら 4/4 クリアになった。

### こおりを うすく する

こおりを濃く描くと、**下のたまの色がわからなくなって**そろえられない。
うすい水色 ＋ 白いふち ＋ ひび だけにして、あついこおりは
「ふちのふとさ」と「ひびの本数」で見わけるようにした。

### 色だけでなく 形も 変える

ハート・ほし・しずく・はっぱ・ほうせき・まる。色の見えかたがちがう人でも、
**形でならんでいるかわかる**ようにしてある。

### 見た目とルールを分ける

ルールはさわった瞬間にぜんぶ計算してしまい（`swapDo` → `resolveStep`）、
**見た目だけを時間をかけて追いつかせる**。こうしないと、
アニメのとちゅうでもう 1 回さわられたときにばんめんがこわれる。

### 動かせる手がなくなったら まぜなおす

そろう手が 1 つもない状態になったら自動でまぜなおす（`reshuffle`）。
まぜたあとに「そろっていない」かつ「手がある」になるまでやりなおす。

## おたすけ

同じめんで 3 回しっぱいするごとに、**手が 4 つふえる**（3 だんかい、さいだい +12）。
3 回しっぱいすればつぎのめんもあくので、1 つのめんで止まったままにならない。

## たしかめたこと

ロボットに 20 めん × 4 回ずつとかせた（手の選びかたを 2 しゅるい）。

| | クリア |
|---|---|
| てきとうに消す | 51 / 80 |
| もくひょうを見て選ぶ | 72 / 80 |
| もくひょうを見て選ぶ ＋ おたすけ（9 回しっぱい後） | **78 / 80** |

- ばんめんがこわれたりフリーズしたりしない（80 × 3 回まわして 0 件）
- **おたすけを入れれば、20 めんすべてで 4/4 クリアできる**（＝どこかで永久に止まらない）
- 効果音 12 こと BGM 3 つが本当に鳴っている（`OfflineAudioContext` の波形で確認）
- 667×375 / 900×440 / 1024×768 / 1280×720 でくずれない
