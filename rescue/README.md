# あおいのどうぶつレスキュー

ぬいぐるみを**ひっぱって はなして**とばし、つみきをくずして、
おりに入ったどうぶつをたすけるゲーム。**20 めん**。
ブラウザだけで動く（サーバー処理なし・インストール不要・ライブラリなし・**画像も音のファイルも 0 個**）。

https://artakartlight1997.github.io/allprojects/rescue/

## 遊びかた

1. 左のぬいぐるみを**ゆびでひっぱる**（うしろに引くほど遠くへとぶ）
2. はなすととんでいく。**白い点**がとぶ道すじのめやす
3. きいろい**おり**をこわすと、中のどうぶつがたすかる
4. おりをぜんぶこわせばクリア。たまがなくなるとおわり

つみきがくずれて下じきになってもおりはこわれる。ちょくせつ当てなくても、
**下をくずす**ほうが早いことがある。

## 物理をどう作ったか

### つみきは まわらない

つみきは**ぜんぶ「まわらない しかく」**としてあつかっている。
まわるつみきは見た目はよいが、あたり判定がむずかしくなって、
少しまちがえるだけで**すり抜けたり、ぶるぶるふるえたり**する。

まわさないと決めるだけで、やることは 2 つだけになる。

1. かさなっているぶんだけ**おしのける**（重いほうが動かない）
2. **はやさをうつす**（ぶつかった強さぶん、いたむ）

### 1 コマを 4 回に分けて計算する

たまはとてもはやい（さいだい 1200 px/びょう）。1 コマ 1/60 びょうで
一気に動かすと **20 px のつみきを飛びこえて**しまう。
1 コマを 4 回に分けて、少しずつ動かしながら当たり判定をしている。

### つみきどうしは 2 回まわす

1 回だけだと、下がおしのけられたぶん上がめりこんだままになって、
つみあがったときにゆっくり沈んでいく。
同じ計算を 2 回まわすと、ちゃんと止まって積み上がる。

## つくって直したところ

### いしにかこまれたおりは、どうやってもこわせない

19 めんは中のゆかもぜんぶ「いし」にしていた。おりがいしにはさまれていると、
上からも下からもくずせず、**ロボットは 40% までしかたすけられなかった**。
中のゆかを木にかえて「くずれる」ようにしたら通るようになった。
18 めんも同じ形だったので直した。

### たまの数をけちらない

たまののこりがそのままスコアなので、**たまをふやしてもむずかしさはのこる**。
6 めん目いこうは 2 つずつふやして、「どうやってもむり」がなくなるようにした。

### とぶ道すじの点が空にとけていた

白い点だけだと水色の空に見えない。こいふちをつけて、少し大きくした。

## おたすけ

同じめんで 3 回だめだと、**たまが 2 つふえる**（3 だんかい、さいだい +6）。
3 回だめならつぎのめんもあくので、1 つのめんで止まったままにならない。

## たまが「スタック」する問題を直しました

たまが**つみきの上やすきまで止まった**とき、9 びょうたつまで消えず、
その間つぎのたまがうてませんでした（止まって見える）。

いまは**どこにいてもほとんど動かなくなったら消える**ようにしました。
実際に 4 つの面で撃ってみて、たまが消えるまで **0.8〜1.3 びょう**です。

## たしかめたこと

ロボットに 20 めん × 3 回ずつとかせた（ねらいのブレを 2 しゅるい）。

| | クリア |
|---|---|
| ざっくりねらう（±26 px のブレ） | 41 / 60 |
| ていねいにねらう（±6 px） | **57 / 60** |
| ざっくり ＋ おたすけ（9 回だめの後） | 55 / 60 |

- つみきがすり抜けたり、ふるえたまま止まらなくなったりしない
- ねらいがうまいほどクリアできる ＝ **うでまえがちゃんときいている**
- 効果音 11 こと BGM 3 つが本当に鳴っている（`OfflineAudioContext` の波形で確認）
- 667×375 / 900×440 / 1024×768 / 1280×720 でくずれない
