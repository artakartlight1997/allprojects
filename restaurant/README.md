# みんなのレストラン経営

YouTube「[ハヤトの野望](https://www.youtube.com/c/hayayabo)」の けいえい シミュレーション 実況に インスパイアされた、**レストラン けいえい ゲーム**。
はじめの お金で 土地・かぐ・食材を 買うと すぐ **赤字**。そこから 料理を どんどん 出して、アルバイトを やとい、さいごは 日本中に 支店を 出して **億万長者（1億円）** を めざす！

https://artakartlight1997.github.io/allprojects/restaurant/

もとに なったのは 子どもが 手がきした 構想メモ「みんなのレストランけいえい」（3まい）。

- 1まいめ: タイトル画面（キャラの ならび・はじめのお金 1000 / 10000・はじめから / つづきから）、キャラの とくいわざ
- 2まいめ: えいとの とくいわざ（かぐルーレット）、つづきから できる、**お店の 名前は はじめに きめる**、**☆5つの レビューで 全てが きまる**、**なんいど イージー / ノーマル / ハード / 鬼（おに）**
- 3まいめ: ハードと 鬼（おに）の ルール、**VIPの お客さん**、**増築**

## あそびかた

1. タイトル画面で **キャラ**・**はじめの お金（1000円 / 10000円。あおいは 30000円）**・**なんいど（イージー / ノーマル / ハード / 鬼）** を えらんで「はじめから」
   → **お店の 名前**（「おまかせ」も ある）を きめて スタート（この 画面でも なんいどを かえられる）
2. **じゅんび**（タブで きりかえ）
   - お店 … 土地を 買う（住宅街 → 商店街 → 駅前。買いかえると まえの 土地は 半がくで 下取り）、**増築**（2かいまで・テーブル +2・コンロ +1）、テーブル・コンロ・かざりを おく
   - 食材 … 10こ セットで 買う。ふつうは 開店して 10びょうで とどく
   - メニュー … 料理を 開発して メニューに のせる（6つ まで）。ねだんは やすい / ふつう / たかい
   - スタッフ … キッチン係（料理を 自動で つくる）・ホール係（自動で 出す・テーブルを そうじ）を やとう。まいにち お給料が かかる
   - 支店 … ★2 から 日本地図に 支店を 出せる。まいにち りえきが 入る（赤字の ときは 出せない）
3. **開店する！** … お客さんの ふきだしを タップ → 料理を つくる → できあがったら もう一回 タップで 出す。
   またせすぎると おこって かえって しまう
   - **そうじ** … たべおわった テーブルは よごれる。タップで ピカピカに（よごれた テーブルに すわった お客さんは レビューが 下がる）
   - **めいわく客**（サングラス・「ガヤガヤ」）… タップで おいだす。おそいと まわりの お客さんの レビューが 下がる
   - **VIP**（おうかん・きんいろ）… いちばん たかい 料理を たのみ、3ばいの お金を はらう。レビューも 3ばいの ちから
4. **レビュー** … お客さんは かえる とき ★1〜5 の レビューを つける（はやく 出す・やすい ねだん・かざりで 上がる／またせる・たかい ねだんで 下がる・おこって かえると ★1）。
   お店の ★（ひょうばん）は レビューで きまり、**お客さんの かず・支店の もうけ・支店を 出せるか・テレビ取材** が ぜんぶ ★しだい
5. **1日の おわり** … 売上・チップ・お給料・光熱費・支店の りえきを 計算。きょうの レビューの へいきんと お客さんの ひとことも 見られる
6. 雨の日（お客さん へる）・おまつり（ふえる）・テレビ取材（★3 から・すごく ふえる）などの イベントも ある

お金は **-5万円** まで 赤字に できる（それより 下は 買えない）。まいにち 自動で セーブ されるので「つづきから」で もどれる。

## なんいど

| なんいど | レビュー | チップ | かぐの ねだん | めいわく客を おいだす まで |
|---|---|---|---|---|
| イージー | あまい | 多く くれる | ふつう | 10びょう |
| ノーマル | ふつう | たまに もらえる | ふつう | 8びょう |
| ハード | きびしい | もらえない | すこし 高い（1.3ばい） | 6びょう |
| 鬼（おに） | よごれが のこって いたら ★1・めいわく客を おいださないと ★1 | なし | イージーの 2ばい | 3びょう |

メモに ない こまかい 数字（1.3ばい・びょう数・お客さんの がまん）は こちらで きめました。

## キャラの とくいわざ

| キャラ | とくいわざ |
|---|---|
| りな | 野菜を 切ったり 料理が はやい（1.5ばい） |
| ゆい | 買った 食材が すぐ とどく |
| まさき | アルバイトを やとう お金が たまに 半がく |
| あおい | はじめの お金が 30,000円（1,000円 / 10,000円の えらびは なし）・たまーに お金が もらえる |
| えいと | テーブルなど（テーブル・コンロ・かざり）を 買う とき ルーレットが 出て、2ぶんの1で 半がく |

## バランスの めやす

自動プレイの テスト（いつも ほどよく 買い物する bot）で:

- 赤字から 黒字に もどるのは だいたい **4〜6日め**
- **1億円** に とどくのは: イージー 約52日・ノーマル 約62〜73日・ハード 約81日・鬼 約95日（そうじ・おいだしを すぐ する ばあい）

1日は 約70びょう（「はやく すすめる」で 早おくり できる）。
