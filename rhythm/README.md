# りなりなリズム

リズム天国 みたいな、ビートに合わせてタップするゲーム。**ぜんぶで 50 面**
（ミニゲーム 39 ＋ リミックス 11）。10 面ずつ 5 つのワールドに分かれている。
ブラウザだけで動く（サーバー処理なし・インストール不要・ライブラリなし・**画像も音のファイルも 0 個**）。

https://artakartlight1997.github.io/allprojects/rhythm/

## 遊びかた

**画面のどこでもいいのでタップ**するだけ。ちょうどの瞬間にたたけると「ピッタリ！」。
**ながおし**の面（ねじまき ロボ／ロケット／そうじき／まほうの つえ／ワープ ゲート）だけは
**おしっぱなしにして、はなす**。パソコンはスペースキーでも遊べる。

## 50 面を どう ならべたか

**1 画面に 50 個ならべると 字がつぶれる。** ミニゲームえらび は
**10 面ずつ 5 つのワールド**にページ分けして、←→ とページの丸で行き来する。
1 ページ 10 枚（5 列 × 2 行）なら、名前が 2 行に折り返しても読める大きさになる。
えらぶ画面をひらくと、**いま遊ぶべき面のワールド**が最初に出る。

ワールドは 1 はじまり／2 おそと／3 おうち／4 まほうの もり／5 うちゅう。
**それぞれ 8 つのミニゲーム ＋ リミックス 2 つ**（最後のワールドだけ リミックス 3 つ）で、
だんだん BPM が上がっていく（96〜140）。

## クリアできない子を 置いていかない

**「合ってるのにミス」を自動で直す。** スマホは音が耳にとどくまで 30〜360ms かかる
（Bluetooth のイヤホンだと 300ms 超えもふつう）。ここが合っていないと**全部ミス**になる。
子どもは自分で「ずれ合わせ」をやらないので、**遊んでいる最中に勝手に直す**ようにした。

- タップのずれを覚えておいて、**5 回ぶんの中央値**が 35ms 以上かたよっていたら
  その分だけ設定をずらす（平均だと 1 回の暴発で狂う。中央値なら効かない）
- **外したタップも手がかりに使う**。当たったときだけ見ていると、
  いちばん直したい「全部ミスの子」がいつまでも直らない
- 直したときは「タイミングを 合わせたよ！」と 1 回だけ出す

**「あわてた！」のタップも手がかりに加えた（50 面にするときに直した）。**
ずれが 340ms を超えると、タップは「その音符のミス」ではなく「あわてた！」の側に落ちる。
そこだけ手がかりを捨てていたので、測りなおしたら
**360ms おくれる端末（Bluetooth のイヤホン）はいつまでも直らなかった**
—— いちばん助けたい子がちょうど直らない、といういやなバグ。
あわてたタップも中央値に入れるようにして直した。
でたらめにたたく子は**ずれの向きがそろわない**（4 分の 3 が同じ向きでないと動かさない）ので、
設定が荒れることはない。これも実測で確かめてある。

実測: 音が 150 / 260 / **360ms** おくれる端末をまねて、
どれも **5 個目までに直って、以降はぜんぶピッタリ**になった。

**同じ面で 2 回だめだと、こっそりやさしくする。**
セーフの まどが ±150 → ±210 → ±270ms に広がり、クリアの line も 65% → 57% → 49% に下がる。
画面のすみに「やさしく してるよ」と出る。クリアすると元にもどる。

**3 回だめだと、次のミニゲームも開ける。** 1 つの面で止まって、
ほかを全部見られないのがいちばんもったいないので。

## なにをすればいいか わかること

**遊びかたがわからないゲームは、それだけで「だめ」。**
ミニゲームを始める前に、かならず**あそびかたの画面**を出すようにした
（リズム天国も毎回これをやる）。1 行で「なにを見て、いつタップするか」を書いて、
4 つの玉がビートで光る。始まったあとも、カウントの 2 小節のあいだは
同じ文を画面の下に出しっぱなしにしている。

**なわとびは作り直した。** はじめは「りなのまわりを楕円がぐるぐる回る」絵で、
なわがどこにあって、いつ足もとに来るのかが読めなかった。

- **2 人が大なわを回す**形にした。なわは手から手へたれ下がる 1 本の線で、
  下がってくるときは手まえ、上がっていくときはうしろに描く
- **足もとに光るしるし**を置いて、なわが近づくほど明るくする
- 半拍まえに**「ひゅっ」という音**を鳴らす
- りなは来る直前にしゃがみ、タップした瞬間にはもう空中にいる
- リズムのならびが**そのままなわの速さ**になる。`'o...o...'` はゆっくり、
  `'o.o.o.o.'` はふつう
- **8 分のペア（`'oo..'`）は入れない。** なわの速さが小節のとちゅうで 2 倍になって、
  いきなりむずかしくなるため。BPM も 116 → 108 に落とし、音符を 53 → 47 個にした

## 音が出ないとき（いちばん大事）

**iPhone・iPad は 横の消音スイッチ（マナーモード）を切っていると WebAudio が丸ごと無音になる。**
動画は鳴るのにゲームだけ鳴らない、という一番つらいやつ。

対策として、**無音の音楽を 1 つ流しっぱなしにしている**。こうするとページの音が
「動画あつかい（playback）」に変わって、スイッチを切っていても鳴る。
`navigator.audioSession.type = 'playback'` も、対応しているブラウザでは同時に立てている。

それでもダメなときのために、タイトルに **「♪ 音を ためす」** ボタンと、
消音スイッチと音量を確かめてね、という案内を出している。
ボタンの下には `AudioContext` がいま鳴らせる状態かどうかも出る。

## リズムゲームでいちばん大事なところ

**時計に `requestAnimationFrame` を使わない。** 画面のコマ送りは 1 コマ 16ms ずれるし、
スマホでは落ちる。ぜんぶ **AudioContext の時計（`currentTime`）**で動かしている。

- 音は **1 小節先まで予約**しておく（さきよみスケジューラ）。鳴らす瞬間に作ると必ず遅れる
- 絵は「いまが何拍めか」を `beatNow()` から計算して描く。コマ落ちしても音とずれない
- はんていは **ゆびが画面についた時こく**を音の時計になおして、音符の時こくと比べる

**ずれ合わせ（キャリブレーション）を入れた。** スマホは音を出してから耳にとどくまで
30〜150ms かかる。ここを合わせないと「合ってるのにミス」になって、いちばんしらける。
タイトルの「ずれ合わせ」で、メトロノームに合わせて 8 回たたくと、
ずれの**中央値**をとって保存する（平均だと 1 回のミスタップで狂う）。
やらなくても `AudioContext.outputLatency` を使うので、そこそこは合う。

はんていの まど: **ピッタリ ±70ms / セーフ ±150ms**。
150〜300ms は「その音符のミス」、それより外は「あわてた！」。
同じタップで「あわてた」と「ミス」の二重どりにはしない。

**ながおし**は「はなすところ」だけで点をつける。おすほうは ±350ms とゆるくしてある。
子どもは早めにおさえるので、そこで落とすと理不尽になる。

## 音

音のファイルは 1 つも置いていない。ぜんぶ その場で 波を作っている。

| | 作りかた |
|---|---|
| バスドラム | サイン波を 150Hz → 45Hz に落として 0.24 秒で消す |
| スネア | 帯域をしぼったノイズ ＋ 210Hz の三角波 |
| ハイハット | 6〜12kHz のノイズを 0.035 秒 |
| メロディ | 三角波 ＋ 5 度ずらした矩形波。ローパスを閉じながら減衰 |
| ベース | のこぎり波を 420Hz のローパスで丸める |
| わおん | 三角波 3 つ。**のばす**（切ると曲がすきまだらけになる） |
| ながおしの音 | のこぎり波を 1 オクターブ上へグライド。てっぺんではなす |
| ぽちゃん・ぽよん・ビーム | サイン／のこぎり波の高さをすべらせる（`glide`） |
| チン（トースター・はとどけい・おさら） | 高いメロディ音を 2 つ重ねる |
| まほう | 高さを上げながら 3 連射 |
| はなび・ロケット | バスドラム ＋ 低いノイズを 0.3 秒 |

ドラムの型は 9 しゅるい（basic / march / funk / taiko / disco / rock / latin / soft / drive）。
面ごとに 型・コード進行・音階を変えているので、50 面ぜんぶ曲がちがう。

**音がすきまだらけだった問題。** はじめは全部を指数カーブで一気に減衰させていて、
波形を測ると **10% の時間がほぼ無音**、まん中の音量も 0.005 しかなかった
（ドラムだけがドンと鳴って、あいだがスカスカ）。
わおんとベースを「のばしてから切る」形にして、メロディも 2 段階で減らすように直した。
うしろでは常に**アルペジオ**が鳴っていて、たたいていない間もさびしくない。

**それでも小節のつなぎめが 0.1 秒ぬけていた。** 50 面ぶんの曲を書き出して測りなおしたら、
1 小節に 1 回、次の小節に入る直前に音がほぼ消える瞬間が残っていた
（わおんを 3.7 拍で切っていて、アルペジオの最後の音も先に消えていたため）。
**わおんを 4.15 拍にのばして次の小節にかぶせ**、最後まで音量を保ってから落とすようにして、
アルペジオも 0.46 → 0.60 拍に伸ばした。
いちばん静かな 0.1 秒が **0.0003 → 0.032（100 倍）**になり、50 面すべて音がとぎれなくなった。

**たたくところは かならず曲のメロディになっている。** 音符の位置から
自動でメロディを鳴らしているので、リズムどおりにたたくと曲ができあがる。
「ねこパンチ」「もぐら」は 1 拍前に「くるよ」の音が鳴る（リズム天国の「ヒュー…ポカッ」）。

**「おぼえて まねる」面は、こたえる小節のガイド音をわざと鳴らしていない。**
鳴らすと覚える必要がなくなって、おもしろさが消えるので
（まねっこ たいこ／ノック／まじょの じゅもん／うちゅうじん）。
おなじ よびかけ と こたえ でも、**やまびこ と ピンポン ラリー はガイド音を鳴らす**。
耳でついていけるので、こちらは やさしい方の面として ワールドの前半に置いてある。

## リズムの書きかた

1 小節 = 8 文字。文字の位置がそのまま拍になる（i 文字め = i/2 拍）。

```
'o' きみがたたく   'c' パパがたたく（お手本）   's' かけ声   '.' なし
'h' 1拍 ながおしして ここではなす   'H' 2拍 ながおし

'o.o.o.o.'  4分音符 4つ
'o...oo..'  1拍め と 3拍め＋その裏
'.o.o.o.o'  ぜんぶ裏拍（ロボダンス）
'..h...h.'  1拍めからおして2拍めではなす、3拍めからおして4拍めではなす
'c.o.c.o.'  あいて → じぶん → あいて → じぶん（ラリー）
```

## 確かめたこと（自動テスト）

ブラウザなしで本物の js をそのまま動かす検査と、Chromium で実際に開く検査の 2 本立て。

**リズム譜（50 面ぜんぶ）**

- 1 小節が 8 文字、知らない文字が入っていない
- 音符が 8 分のますにきっちり乗っている。近すぎる音符がない（いちばん短い間で 0.21 秒）
- ながおしの「おす → はなす」の間に別の音符が入っていない
- ながおしの面にタップの音符を混ぜていない（混ざると理不尽）
- 1 面あたり 音符 23〜79 個・30.9〜58.3 秒

**あそび**

- **ぴったりの時こくでたたくと 50 面ぜんぶ全部ピッタリ**（ずれ 0・ミス 0・あわてた 0・ハイレベル！）
  ながおしは「おす」「はなす」も時こくどおりに再現して確認
- 何もたたかないと 46 ミス → もういちど
- はんていのまど: 0/50/69ms → ピッタリ、90/140ms → セーフ、160ms → ミス、400ms → あわてた
- ずれ合わせ: 80ms 遅れてたたく子をまねると 80ms と判定
- 音が 150 / 260 / 360ms おくれる端末をまねて、どれも 5 個目までに自動で直り、
  そのあとは全部ピッタリになる
- でたらめにたたいても ずれの設定は動かない（向きがそろわないため）
- 同じ面で 2 回だめ → まどが ±210ms に広がる。3 回だめ → 次の面が開く

**絵**

- 50 面 × 全部の拍 × 4 つの画面サイズ（568×320 / 667×375 / 812×375 / 1024×600）で
  エラーなく描け、文字の座標に NaN が出ない
- タイトル・ミニゲームえらび（5 ワールドぶん）・あそびかた・せいせき も同じく
- えらぶ画面のさわれるところが**画面の外にはみ出さない・小さすぎない**（4 サイズ全部）
- Chromium で実際に開いて JS エラーなし。各面のスクリーンショットを目で確認

**音**

- 50 面ぶんの曲を 4 小節ずつ OfflineAudioContext に書き出して波形を測定。
  さいだい 0.32〜0.51 ／ まん中 0.072〜0.19 ／
  **いちばん静かな 0.1 秒 0.032〜0.047**（＝どこにも音のぬけがない）
- 面が指定しているドラムの型が実在する（打ちまちがえると黙って basic に落ちるため）

**すすみかた**

- 1 面だけ開いていて、クリアすると次が開く。50 面ぜんぶクリアできる
- 「つづきから」がまだクリアしていない一番前の面を指す
