# りなりなリズムオールスターズ

「リズム天国 ミラクルスターズ」みたいに、**ミニゲームを えらんで あそぶ**リズムゲーム。
ひげ抜き・忍者・タップダンス…といった あそびかたを もとに、
テーマは ぜんぶ 別もの（トマト・ねこざむらい・ぺんぎん・かえる・ロボ・おばけ）にしてある。
**よこ向き せんよう**で、UI も キャラクターも 大きめ。

https://artakartlight1997.github.io/allprojects/rhythmstars/

ブラウザだけで動く（サーバー処理なし・インストール不要・ライブラリなし・**音のファイルは 0 個**、
画像は アイコン 1 枚だけ。キャラクターは ぜんぶ コードで 描いている）。

## 遊びかた

タイトルの **「▶ はじめる」→ ミニゲームを えらぶ**。
どれから あそんでも いい（じゅんばんに あける しくみは なし）。
**画面の どこでも いいので タップ**。パソコンは スペースキーでも 遊べる。
かえるコーラス だけ **おしっぱなし → はなす**。

えらぶ 画面の 右上で **「🐢 ふつう / 🔥 はやい」**を きりかえられる。
「はやい」は 曲の はやさが 1.2 ばい。記ろくは べつべつに のこる。

| | ミニゲーム | もとにした あそび | しかけ | BPM |
|---|---|---|---|---|
| 1 | **もじゃもじゃトマト** | ひげ抜き | 1拍まえに ピョコッと 出る → ちょうどで ぬく | 112 |
| 2 | **ねこざむらい** | 忍者 | とんでくる ものを 目の まえで きる。2連続あり | 126 |
| 3 | **ぺんぎんタップ** | タップダンス | よびかけと こたえ（1小節 おぼえて まねる） | 120 |
| 4 | **かえるコーラス** | コーラスメン | **ながおし**。ぼうが 上の せんに ついたら はなす | 100 |
| 5 | **ロボこうば** | もちつき | 「ドン（じどう）→ タン（きみ）」の **うら拍** | 128 |
| 6 | **おばけドア** | みならい忍者 | ピンクは たたく／あおは **たたかない** | 118 |
| 7 | **オールスター リミックス** | リミックス | 2小節ごとに ゲームが かわる（6つ ぜんぶ） | 124 |

けっかは **もういちど／クリア／オールスター**の 3だんかい。
★2つ（オールスター）は ほとんど ピッタリで たたけた とき。

## こまかい くふう

- **音の 時計で しんぱん する。** 画面の コマ送りは 1コマ 16ms も ずれるので、
  ゆびが ついた 時こく を `AudioContext.currentTime` に なおして 音符と くらべる
- **ずれ合わせ。** スマホは 音が 30〜150ms おくれて 出る。タイトルの
  「♪ ずれ合わせ」で 8回 たたくと 合う。やらなくても、いつも 同じ 向きに
  ずれている 子は **あそびながら じどうで 直す**（`autoFixLatency`）
- **やさしくなる。** 同じ 面で つづけて だめだった ときは、はんていの まどを
  すこし ひろげる（「ぜんぜん できない」まま おわらせない ため）
- **iPhone の 消音スイッチ**でも 音が 出るように、無音の音を 流しっぱなしに して
  ページを 動画あつかいに している（`unmuteIOS`）
- 記ろくは `localStorage`（`rhythmstars.v1`）。サーバーには 何も 送らない

## ファイル

| ファイル | なかみ |
|---|---|
| `site/audio.js` | 音。ドラム・ベース・わおん・たたいた音 を その場で 作る |

| `site/games.js` | ミニゲームの え と リズム。リズムは 16 もじ／小節 の もじれつ |
| `site/play.js` | しんぱん・とくてん・記ろく・ずれ合わせ |
| `site/ui.js` | タイトル／えらぶ／あそびかた／あそぶ／けっか の 画面と ループ |

### リズムの 書きかた（`games.js` の `pats`）

1小節（4拍）を 16 もじ。1もじ ＝ 16分音符。

```
'.' なにもない          'x' きみが タップ
'c' おてほん（じどう）   'o' タップ しちゃ だめ
'H' おしはじめ          'R' はなす（ここで てんすう）
```

リミックスだけ `{ p: 'x...x...', g: 'ninja' }` のように 小節ごとに ゲームを 書く。
