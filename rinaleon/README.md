# めっちゃリナレオン

まっしろな りな に**じぶんで色をぬって**、かべに擬態して隠れるかくれんぼ。
ブラウザだけで動く（サーバー処理なし・インストール不要）。1人用。

https://artakartlight1997.github.io/allprojects/rinaleon/

## 遊びかた

1. **ぬる** — まっしろな りな に色をぬる。右のステージ見本を
   **スポイト**でつつくと、その場所の色がそのまま使える
2. **かくれる** — りなをドラッグして隠れる場所を決める。
   背景と似ているほど **ぎたい度** が上がる
3. **さがされる** — パパが探しにくる。**30秒**見つからなければ勝ち。
   動くと見つかりやすいので、じっとしてやり過ごす

これを **3ステージ**くり返す。

## ぎたい度のしくみ

このゲームの心臓部。**描いた絵と、隠れた場所の背景を実際に見くらべている。**

1. りなの絵を 48×60 に縮める
2. 隠れた四角の中の背景も、同じ 48×60 に切り出して縮める
3. りなの形の中だけ、1 ピクセルずつ RGB の距離を測って平均する
4. 平均のずれが 0 なら 100%、0.30（見ればすぐ分かるくらい）以上なら 0%

だから**ごまかしが効かない**。ちゃんと似た色を塗って、似た場所に立つしかない。

### ぎたい度と逃げきりやすさ

見つかる速さは `0.05 + 2.4 × (1 - ぎたい度)^1.9` を土台に、
近さ・向き・動いたか・じっと見られているか を掛けて決めている。
自動で 30 回ずつ試した結果は次のとおり。

| ぎたい度 | 逃げきり率（1回目 / 3回目） |
|---|---|
| 97% | 100% / 100% |
| 90% | 100% / 100% |
| 80% | 83% / 97% |
| 70% | 40% / 43% |
| 50% | 30% / 13% |
| 20% | 17% / 3% |

**スポイトで色をとって「ぜんぶ」で塗りつぶす**だけで、合う場所なら
おおむね 70〜90% になる。そこから模様を描き足すと 90% 台に届く。

## ステージ

どれも**3つのゾーン**に分かれていて、ゾーンごとに柄がちがう。
自分が塗った色に合うゾーンを選ぶのが勝負どころ。

| ステージ | ゾーン |
|---|---|
| おうちのかべ | レンガ / 木のドア / つた |
| はなばたけ | 花ばたけ / しましま / 空 |
| よるのおへや | 水玉 / 本だな / 星空 |
| そうこ | だんボール / タイル / 木 |

同じ色で塗っても、**ゾーンを間違えるとぎたい度がガタ落ちする**。
実測（1色で塗りつぶした場合）:

| 柄 | 合う場所 | ちがう場所 |
|---|---|---|
| レンガ | 89% | 61% |
| つた | 90% | 12% |
| はなばたけ | 87% | 0% |
| だんボール | 90% | 1% |
| 本だな | 16% | 32% |

本だなだけは色数が多いので、塗りつぶしでは合わない。
ちゃんと本を描くか、ほかのゾーンに逃げる。

## ポーズ

**たつ / まるまる / ばんざい** の3つ。形がちがうので、
背景の中の物（本・箱・葉っぱのかたまり）に合わせて選べる。
まるまるは小さいので、そもそも見つかりにくい。

## 背景のつくり

背景は画像を使わず、その場で図形を描いている。大事なのは
**模様の大きさを「画面の幅」だけで決めている**こと。
こうすると、お絵かき画面の小さな見本が本番のちょうど縮小版になり、
見本どおりに塗れば本番でもぴったり合う。乱数は使わず、
番号から決まる式で模様を置いているので、毎回同じ絵になる。

## ファイル

| ファイル | 役割 |
|---|---|
| `site/stages.js` | 背景の柄・ステージ・りなのシルエット |
| `site/game.js` | お絵かきの下じき・ぎたい度の計算・パパの目 |
| `site/ui.js` | 画面（タイトル / ぬる / かくれる / さがされる / けっか）・入力・ループ |

記録（最高点・クリア回数）は `localStorage`（`rinaleon.v1`）に残る。

## 確かめたこと

- 4ステージ × 3ゾーンで、合う場所とちがう場所のぎたい度に差が出ること
- ぎたい度 0.2〜0.97 について 30 回ずつ自動で逃げさせ、難易度の曲線が
  なだらかに上がること
- 900×460 / 667×375 / 568×320 / 1280×720 で 3ステージ通しでエラーが出ないこと
- どの画面サイズでもボタンが画面からはみ出さないこと

## 配信

`.github/workflows/pages.yml` が main への push で GitHub Pages に置く。
「りなの大冒険」と同じサイトの `/rinaleon/` に入る。

js を直したら `site/index.html` の `?v=` の番号を増やすこと。
