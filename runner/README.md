# りなの レーンダッシュ

「Subway Surfers」みたいな **3レーンの エンドレスランナー**。うしろから 見た りなが どんどん はしる。
よけて・とんで・すべって、どこまで はしれるか ちょうせん。

https://artakartlight1997.github.io/allprojects/runner/

## あそびかた

- **ひだり／みぎ に スワイプ**（← →）… レーンを かえる
- **うえに スワイプ**（↑・スペース）… ジャンプ（あかしろの ひくい さくを こえる）
- **したに スワイプ**（↓）… スライディング（きいろい「しゃがめ」バーの 下を くぐる）
- あかい ✕の はこ・あおい ながい はこ は とびこえられない。レーンを かえて よける
- 1かい ぶつかると つまずく。すぐ（4びょう いない）に もういちど ぶつかると おしまい。はこに ぶつかると すぐ おしまい
- コインは 1まい 10てん。🧲マグネットで コインを すいよせ、⭐で むてき
- はしるほど はやく なる。900m ごとに けしきが かわる（しょうてんがい → こうえん → ゆうやけ → よる）

## ためる

ベストスコアと あつめた コインの ごうけいが `localStorage`（`lanedash.v1`）に のこる。
コインが 300まいで **ゆい**、700まいで **あおい** も はしれる。

## たしかめた こと

「まえを 見て よける」かんたんな ボットに 8かい はしらせて、1800〜3100m まで いけた
（かならず どこか 1レーンは とおれる ように ならべて いる）。
