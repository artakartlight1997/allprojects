# りなのしこくツアー

四国の 4 県を、**名産のおつかい**と**まわる地図**でおぼえるゲーム。全 10 めん。
ブラウザだけで動く（サーバー処理なし・インストール不要・ライブラリなし・**画像も音のファイルも 0 個**）。

https://artakartlight1997.github.io/allprojects/shikoku/

## なぜ「地図がまわる」のか

四国は 4 県しかないので、ふつうのパズルだとすぐ終わってしまいます。
それに、画面のどこにあるかを**位置でまる暗記**しただけでも解けてしまう。

そこで 7 めん目から、**問題ごとに地図が 90 度ずつまわります。**

- 「香川は画面の上」でおぼえた子 → まわったとたんに分からなくなる
- 「香川は**北がわ**」でおぼえた子 → 北の矢じるしを見ればすぐ分かる

まわしただけで、**いちかんけいでおぼえる**しかなくなります。

## 遊びかた

「◯◯を とどけて！」と言われたら、その県をタップ。

| めん | やること |
|---|---|
| 1 | 名まえでタップ（まず見てみる） |
| 2 | 形をはめる |
| 3 | 名まえさがし（名まえがかくれる） |
| 4 | **おつかい**（うどん→香川、みかん→愛媛…） |
| 5 | **ばしょ**（「北がわの けん」→香川） |
| 6 | かげなしではめる |
| 7〜9 | **地図がまわる**（名まえ／おつかい／はめる） |
| 10 | まわるタイムアタック |

まちがえてもへりません。「◯◯けんは 北のほう だよ」とヒントが出ます。
1 回もまちがえずにできると **★★★**。

| けん | 名さん | ばしょ |
|---|---|---|
| 香川 | さぬきうどん | 北がわ |
| 徳島 | すだち | 東がわ |
| 愛媛 | みかん | 西がわ |
| 高知 | かつお | 南がわ |

## 作るときに気をつけたところ

- **さわったところは、地図とぎゃくにまわしてから**県をしらべる。
  そうしないと、まわっているときにずれたところを押したことになる
- **字はまわさない。** 地図といっしょに字までまわすと、小学生には読めない
- **北の矢じるしは画面のきまったところ**に出す。地図といっしょに動かすと、
  まわったとき地図の上にかさなってしまう
- まわるめんでは、たてとよこが入れかわる。まわす前の大きさで地図をあわせると
  **まわしたとたんはみ出す**ので、みじかいほうにあわせている

## 県のかたちについて

**本物の地図から起こしたデータです。**
geolonia/japanese-prefectures が公開している日本地図の SVG から座標を取り出しました。

- **佐田岬半島**（愛媛から西へ長くのびる細い半島）
- **室戸岬**と**足摺岬**（高知の東と西、2 本のツノ）
- **小豆島**（香川の島）

といった、四国とすぐ分かる特ちょうがそのまま出ます。

はめるときは、形の中でなくても「置く目じるし」の近くならはまるようにしてあります。
細い半島の中にぴったり指をはなすのは小学生には無理だからです。

## たしかめたこと

- かたちが**かさなっていない**（0.5 きざみで 23593 点しらべて、2 つ以上に入る点は 0 点）
- **どの県も、置く目じるしが自分のかたちの中にある**（4 県すべて）
- どの県も、まん中の点が自分のかたちの中にある
- 10 めんすべてを、まちがい 0 でクリアできる
- わざとちがうところに置くと、ちゃんとまちがいになる
- 効果音 8 こと BGM 3 つが本当に鳴っている（波形で確認）
- 667×375 / 900×440 / 1024×768 / 1280×720 でくずれない
