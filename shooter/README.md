# まさきのうちゅうシューティング

左から右へすすむ横スクロールのシューティング。全 10 めん。
ブラウザだけで動く（サーバー処理なし・インストール不要・ライブラリなし・**画像も音のファイルも 0 個**）。

https://artakartlight1997.github.io/allprojects/shooter/

## なぜ「横」で「たまは自動」なのか

- 画面は**横長**です。たてスクロールにすると上下がすぐ画面の外に出てしまうので、
  **左から右へすすむ形**にしました。
- 小学生が「よける」と「うつ」を同時にやるのは大変なので、**たまは自動で出ます**。
  やることは**ゆびでなぞって船を動かす**だけ。パソコンではやじるしキーでも動きます。
- ゆびで船がかくれないよう、船は**ゆびの場所へすーっと寄っていく**作りです。

## アイテム

てきをたおすとときどき落ちてきます。

| | |
|---|---|
| **P** | たまが強くなる（最大 4 段階。3 以上は 3 方向＋まん中が強い） |
| **♥** | ライフが 1 つもどる |
| **B** | バリア。1 回だけ守ってくれる |

やられるとたまの強さが 1 段階下がります（2 より下にはならない）。

## ボスのリナパパ

4・7・10 めんのボスは**リナパパ**。メガネのちょいぽちゃが円ばんに乗って出てきて、
ケーキをばらまいてきます。体力が減ると弾が増えて速くなります。

## クリアできないとき

ほかのゲームと同じで、**3 回やられるとライフが 1 つ増え、てきの弾がおそくなり、
つぎのめんも開きます**（3 だんかいまで）。1 つのめんで詰まって先に進めなくなることはありません。

## たしかめたこと

自動でプレイするロボット（うでまえ 4 だんかい）に、各めん 10 回ずつ遊ばせました。
ロボットは「これから 0.3〜1.3 びょうの間にあぶない場所」を点数にして、
いちばん安全で、しかもてきに弾が当たる高さへ動きます。

| | 1〜3 めん | 4〜6 めん | 7〜10 めん |
|---|---|---|---|
| こども（おそい・見える範囲がせまい） | 9〜10/10 | 6〜9/10 | 2〜6/10 |
| よわい | 10/10 | 10/10 | 10/10 |
| ふつう | 10/10 | 10/10 | 9〜10/10 |
| つよい | 10/10 | 10/10 | 9〜10/10 |

- **つよいロボットは全 10 めんクリアできる**（クリア不能なめんはない）
- **こどもロボットは 1〜3 めんはほぼ勝てて、7・10 めん（リナパパ）で 2/10 まで落ちる**
  ＝いきなり難しすぎず、後半は手ごたえがある
- 3 回やられたあとの助けを入れると、**こどもロボットでも全 10 めん 9〜10/10 勝てる**
- 2 回では次のめんが開かず、3 回で開くことを確認
- 効果音 13 ことBGM 3 つが本当に鳴っている（`OfflineAudioContext` の波形で確認）
- 実際のマウス操作で船が動き、点が入る（900×440 / 1280×720）
- 667×375 / 900×440 / 1024×768 / 1280×720 / 1366×640 でくずれない
