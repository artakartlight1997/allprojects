# リナのスライムラボ

材料を入れてスライムを作るゲーム。**入れた量で手ざわりも色も変わる**。
できたスライムは のばす・つつく・はずませる であそべて、たなに残せる。
ブラウザだけで動く（サーバー処理なし・インストール不要）。

https://artakartlight1997.github.io/allprojects/slime/

## 遊びかた

1. **材料のびんをゆびでつかんで**、ボウルの上まで運ぶ。かたむいて出てくる
2. 出る場所は**ゆびのところ**。だから好きな場所にたらせる
3. ボウルの中を**ゆびでぐるぐる**すると、なぞったところだけまざる
4. 「できた！」で できあがり。名前・手ざわり・できばえ★が出る
5. 「あそぶ」で **のばす / つつく / はずませる** の3つ
6. たなに **12こ**まで残せる。あとから出してあそべる

## 自分の手でまぜる

ボウルの中身を **120このつぶ**であらわしている。つぶ1こ1こが
「自分と同じ中身でボウルをいっぱいにしたら何色になるか」を持っていて、
**ぜんぶの平均がいまの配合そのもの**になるようにしてある。

大事なのは「かってにはまざらない」こと。

- たらした絵の具は**そこにとどまる**。ボウルの中で青と黄が別々に見える
- ゆびでなぞったところだけ、つぶ同士が色をわけあう
- 青のとなりに黄をたらしてまぜると、**さかいめから緑になっていく**のが見える
- まぜ足りないと**しま模様がスライムに残る**（名前も「マーブル〜」になる）

色のやりとりはおたがい同じ量ずつなので、合計は変わらない。だから
**ぐるぐるまぜて全部そろったとき、できあがりの色とぴったり一致する**。
（テストで確認：つぶの平均 6.77 ＝ 実際の配合 6.77）

「まぜ」メーターは手を動かした量ではなく、**本当に色がそろったか**を
はかっている。まぜる手ごたえと色のそろい具合、両方がいる。

## 材料は11しゅるい

| 材料 | 何が変わる |
|---|---|
| のり / みず | かさ（大きさ）。少ないと「ちいさな」スライムのまま |
| ホウ砂水 | **かたさ**。手ざわりのほとんどを決める |
| フォーム | ふわふわ・つや消しになる。白っぽくなる |
| あか / きいろ / あお | 色。絵の具とおなじまざりかた |
| しろ / くろ | 明るさ |
| ラメ | きらきら光る |
| ビーズ | つぶつぶした手ざわり |

## かたさ ＝ ホウ砂水 ÷ (のり + みず×0.6)

この比 1つで手ざわりが決まるようにしてある。

| 比 | 手ざわり | どうなる |
|---|---|---|
| 〜0.14 | ベタベタ | よくのびるが すぐ ちぎれる。ほとんど はずまない |
| 0.14〜0.5 | ちょうどいい | いちばん よくのびる（0.30 が山） |
| 0.5〜 | カチカチ | のびないが よく はずむ |

## のばすと、ほんとうにたれる

三角形をのばすのではスライムに見えないので、ひもを**16このふし**に分けて
本当にたらしている（`strand.js`）。

- **つまんだところが伸びる。** ひもは玉の中心からではなく、
  さわった場所のふちから生える。玉もそこだけとんがる
- **ゆびを何本つかってもいい。** 2本3本で別々の場所をつまめば、
  ひもがその数だけ出る
- おもりがかかるので**まんなかが下にたれる**。つくえに届くとそこにたまる
- ゆびを動かすと**少しおくれてついてくる**
- ふしとふしのあいだの「かさ」は決まっているので、のばしたところほど細くなる
- ひっぱると**たまから中身が流れ出して**ひもに入る。たまはやせる
- 細くなりすぎたところで**ちぎれて、しずくがとぶ**

太さはいっきには変わらない。**よくのびるスライムほど細くなるのがおそい**。
だから本物と同じで、**ゆっくりひっぱればのびる／いっきに引くとちぎれる**。

## ひもの中を、中身が流れる

「細くなりすぎたら切る」と決めうちしていたのをやめて、
**ふしとふしのあいだの「かさ」を本物の状態**にした。太さはそこから出す。
かさはひもの中を流れて動く（`strandFlow`）。流れる理由は2つ。

**① 表面張力**（プラトー・レイリー不安定）
細いところほど中の圧が高い（1÷半径）。だから中身は**細いところから
太いところへ逃げていく**。細いところはもっと細く、太いところはもっと太く。
ほうっておくとひもはひとりでに**数珠つなぎにくびれて、いちばん細いところで
切れる**。水道の水がとちゅうからつぶつぶになるのと同じ現象。

**② おもり**
中身は下へ下へ流れるので、たれたところがふとる。

**ねばりが強い（よくのびる）スライムほど流れがおそい**（25倍の差をつけてある）。
だからくびれができるまでに時間がかかり、長くのびる。
逆にさらさらしたスライムはすぐ数珠になって切れる。
**「切れる」を手で書いていない**——形がひとりでにそうなる。

自動プレイで測った、ひっぱりきったときの太さ（半径÷玉の半径）。

| スライム | 太さの並び | くびれの数 |
|---|---|---|
| びよーん | 0.50 0.49 0.46 0.44 0.42 … 0.16 0.12 | **0**（きれいにすぼまるだけ） |
| ベタベタ | 0.41 0.36 0.36 0.34 … 0.28 **0.05** 0.27 | 4 |
| カチカチ | 0.38 **0.23** 0.32 0.29 … 0.22 **0.08** 0.23 | 5 |

**同じ材料でも量がちがえば別物になる**のが数字に出る。

| スライム | ゆっくり引く | いっきに引く | はずんだ高さ |
|---|---|---|---|
| ベタベタ | 26cm でちぎれる | **14cm でちぎれる** | 4 |
| びよーん | **38cm** | 31cm | 14 |
| カチカチ | 6cm でちぎれる | 9cm でちぎれる | 46 |

なお、これは**本物の流体シミュレーション（ナビエ・ストークス）ではない**。
ひもを1本の線として見て、そこに表面張力と重力による流れを入れたもの。
ひもが横にちぎれて分かれる、玉がつくえに広がる、といったことはしない。

## 色は絵の具とおなじまざりかた

RGB をそのまま平均すると「あお＋きいろ＝はいいろ」になってしまう。
絵の具は赤・黄・青が三原色なので、**RYB の立方体を三次元で補間**して
実際の絵の具の見た目に合わせている（`mix.js` の `rybToRgb`）。

| 入れたもの | できる色 |
|---|---|
| あお ＋ きいろ | **みどり** |
| あか ＋ あお | **むらさき** |
| あか ＋ きいろ | **オレンジ** |
| あか ＋ しろ | パステルあか |
| ぜんぶ | ちゃいろ |

絵の具の合計が多いほど色が濃くなる。しろ・くろ・フォームで明るさが動く。

## 名前ととくべつな称号

手ざわり＋かざり＋色 で名前がつく（「びよーんラメあおスライム」など）。
組み合わせが決まると称号が出る。

| 称号 | 条件 |
|---|---|
| ギャラクシー | ラメたっぷり＋よくのびる＋あお系 |
| ゆきのくに | フォーム多め＋ラメ |
| あられ | ビーズ多め＋よくはずむ |
| めいじん | のび最高クラス＋できばえ★5 |
| はちみつ | きいろ＋ラメ |

## ぷにぷにの動き

まわりに16この点をおいて、それぞれをバネで丸にもどしている。
つつくとその点がへこみ、となりへ波が伝わる。**やわらかいほどバネが弱く、
ゆれが長くつづく**ので、ベタベタとカチカチで手ごたえがちがう。

## 確かめたこと

- あお＋きいろ＝みどり など、絵の具どおりの色になること
- たらした絵の具がまざらずにその場に残り、なぞったところから
  まざりはじめること（まぜる前 0.00 → まぜたあと 0.88）
- つぶの平均が実際の配合と一致していること（＝ボウルの色と
  できあがりの色がずれない）
- ホウ砂水の量だけを変えて ベタベタ / びよーん / カチカチ に分かれること
- ゆっくり引くのと いっきに引くので 結果が変わること
  （ベタベタ 26cm → 14cmでちぎれる、びよーんは どちらでも もつ）
- ひもが ひとりでに くびれること。ねばりの弱いスライムだけ
  くびれが4〜5こ出て、よくのびるスライムは 0こ のまま
- くびれた ところで 切れて、しずくが とぶこと
- つまんだ場所からひもが出ること（上をつまむ→上のふち、
  左をつまむ→左のふち）
- ゆび2本で2本同時に出せて、はなすと両方ともかたづくこと
- のび・はずみの記録がスライムごとに はっきり差が出ること
- 900×460 / 667×375 / 568×320 / 1280×720 の4つで
  作る→あそぶ→たなに残す まで通してエラーが出ないこと
