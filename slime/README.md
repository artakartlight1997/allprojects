# りなのスライムラボ

材料を入れてスライムを作るゲーム。**入れた量で手ざわりも色も変わる**。
できたスライムは のばす・つつく・はずませる であそべて、たなに残せる。
ブラウザだけで動く（サーバー処理なし・インストール不要）。

https://artakartlight1997.github.io/allprojects/slime/

## 遊びかた

1. **材料ボタンを長おし**すると、おしているあいだ ボウルに入っていく
2. ボウルの上を**ゆびでぐるぐる**すると まざる（まぜるほど なめらか）
3. 「できた！」で できあがり。名前・手ざわり・できばえ★が出る
4. 「あそぶ」で **のばす / つつく / はずませる** の3つ
5. たなに **12こ**まで残せる。あとから出してあそべる

## 材料は11しゅるい

| 材料 | 何が変わる |
|---|---|
| のり / みず | かさ（大きさ）。少ないと「ちいさな」スライムのまま |
| ホウ砂水 | **かたさ**。手ざわりのほとんどを決める |
| フォーム | ふわふわ・つや消しになる。白っぽくなる |
| あか / きいろ / あお | 色。絵の具とおなじまざりかた |
| しろ / くろ | 明るさ |
| ラメ | きらきら光る |
| ビーズ | つぶつぶした手ざわり |

## かたさ ＝ ホウ砂水 ÷ (のり + みず×0.6)

この比 1つで手ざわりが決まるようにしてある。

| 比 | 手ざわり | どうなる |
|---|---|---|
| 〜0.14 | ベタベタ | よくのびるが すぐ ちぎれる。ほとんど はずまない |
| 0.14〜0.5 | ちょうどいい | いちばん よくのびる（0.30 が山） |
| 0.5〜 | カチカチ | のびないが よく はずむ |

自動プレイで測った差。**同じ材料でも量がちがえば別物になる**のが数字に出る。

| スライム | のび | はずんだ高さ |
|---|---|---|
| ベタベタむらさき | 48cm（ちぎれた） | 4 |
| びよーんあお | 49cm | 14 |
| つぶつぶきいろ | 47cm（ちぎれた） | 24 |
| カチカチあお | 32cm（ちぎれた） | 46 |

## 色は絵の具とおなじまざりかた

RGB をそのまま平均すると「あお＋きいろ＝はいいろ」になってしまう。
絵の具は赤・黄・青が三原色なので、**RYB の立方体を三次元で補間**して
実際の絵の具の見た目に合わせている（`mix.js` の `rybToRgb`）。

| 入れたもの | できる色 |
|---|---|
| あお ＋ きいろ | **みどり** |
| あか ＋ あお | **むらさき** |
| あか ＋ きいろ | **オレンジ** |
| あか ＋ しろ | パステルあか |
| ぜんぶ | ちゃいろ |

絵の具の合計が多いほど色が濃くなる。しろ・くろ・フォームで明るさが動く。

## 名前ととくべつな称号

手ざわり＋かざり＋色 で名前がつく（「びよーんラメあおスライム」など）。
組み合わせが決まると称号が出る。

| 称号 | 条件 |
|---|---|
| ギャラクシー | ラメたっぷり＋よくのびる＋あお系 |
| ゆきのくに | フォーム多め＋ラメ |
| あられ | ビーズ多め＋よくはずむ |
| めいじん | のび最高クラス＋できばえ★5 |
| はちみつ | きいろ＋ラメ |

## ぷにぷにの動き

まわりに16この点をおいて、それぞれをバネで丸にもどしている。
つつくとその点がへこみ、となりへ波が伝わる。**やわらかいほどバネが弱く、
ゆれが長くつづく**ので、ベタベタとカチカチで手ごたえがちがう。

## ファイル

| ファイル | 役割 |
|---|---|
| `site/mix.js` | 材料・色のまざりかた（RYB）・性質の計算・名前 |
| `site/slime.js` | ぷにぷにのバネ・スライムの絵・ボウルの絵 |
| `site/ui.js` | 画面（タイトル / ラボ / できた / あそぶ / たな）・入力・ループ |

記録は `localStorage`（`slime.v1`）に残る。

## 確かめたこと

- あお＋きいろ＝みどり など、絵の具どおりの色になること
- ホウ砂水の量だけを変えて ベタベタ / びよーん / カチカチ に分かれること
- のび・はずみの記録がスライムごとに はっきり差が出ること
- 900×460 / 667×375 / 568×320 / 1280×720 の4つで
  作る→あそぶ→たなに残す まで通してエラーが出ないこと

## 配信

`.github/workflows/pages.yml` が main への push で GitHub Pages に置く。
同じサイトの `/slime/` に入る。js を直したら `site/index.html` の
`?v=` の番号を増やすこと。
