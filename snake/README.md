# あおいのにょろにょろ

**スネーク**。えさを食べて体をのばす。全 10 面。
ブラウザだけで動く（サーバー処理なし・インストール不要・ライブラリなし・**画像も音のファイルも 0 個**）。

https://artakartlight1997.github.io/allprojects/snake/

## 遊びかた

1. 十字ボタン（パソコンは矢印キー）で向きをかえる。画面をなぞってもよい
2. えさを食べると体がのびて点が入る
3. きめられた数だけ食べたらクリア
4. **かべと自分の体**にぶつかったらおしまい

うしろへは曲がれない（すぐ自分にぶつかってしまうため）。

## えさ 4 種類

| | はたらき |
|---|---|
| りんご（赤） | 1 のびる・10 点 |
| きんのみ（黄） | 2 のびる・**50 点** |
| こおり（水） | すこしゆっくりになる・30 点 |
| ちぢみ草（緑） | **体が 3 マスみじかくなる**・20 点 |

とくべつなえさは 6 秒で消える（消える 2 秒前から点めつする）。むりに取らなくてよい。

## 面

10 面。速さが 4.5 → 8.6 マス／秒、食べる数が 8 → 28 こ とふえ、
3 面からはかべが出てくる（たて棒・よこ棒・四すみ・十字など）。

## 気をつけたところ

- **しっぽは当たり判定から外す**。次のコマで消えるマスにぶつかって死ぬのは理不尽なので
- **かべはレンガ色**にした。緑にすると体と見分けがつかない
- 体は 1 マスおきに色を変えてしましまに（どこまでが自分か分かりやすい）

## たしかめたこと

置き場所を自分で決めるロボット 3 段階に、10 面ずつ遊ばせた。

| ロボット | クリア |
|---|---|
| えさに近づくだけ | 6 / 10 |
| 先のスペースも見る | **10 / 10** |
| もっと広く見る | **10 / 10** |

先を見るほど強くなる。いちばん長くなったときで 32 マス。

- 効果音 12 ことBGM 2 つが本当に鳴っている（波形で確認）
- 667×375 / 900×440 / 1024×640 / 1280×720 でくずれない・コンソールエラー 0
