# ゆいの ケーキタワー

「Stack」みたいな **タイミング つみあげ ゲーム**。よこから すべって くる スポンジを、
タップで したの だんに かさねて、たかい ケーキを つくる。

https://artakartlight1997.github.io/allprojects/stack/

## あそびかた

- スポンジが したの だんに かさなる ところで **タップ**（スペース・Enter でも OK）
- はみ出した ところは おちて、つぎの だんは その ぶん 小さく なる
- ずれが ほとんど ないと「**ぴったり！**」。3かい れんぞくで だんが すこし 大きく なる
- まったく かさならないと おしまい。さいごに いちごを のせて かんせい！
- だんが ふえるほど すべる のが はやく なる。たかく なると よぞらに なる

| だん | しょうごう |
|---|---|
| 0〜 | はじめての ケーキ |
| 10〜 | おいしい ケーキ |
| 20〜 | パティシエ みならい |
| 35〜 | パティシエ |
| 50〜 | でんせつの パティシエ |

ベストは `localStorage`（`caketower.v1`）に のこる。
