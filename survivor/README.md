# りなサバイバー 〜まものの よる〜

**こうげきは ぜんぶ じどう**。うごいて まものを よけながら、まものが おとす ほしを あつめる。
レベルが 上がったら 3つの 中から 1つ えらんで つよく なる。
3ぷん いきのこると ボスが でる。ボスを たおしたら クリア。全3ステージ。

https://artakartlight1997.github.io/allprojects/survivor/

「ヴァンパイア サバイバーズ」から はじまった、いまも 人気の「サバイバー系」の あそび。
ボタンは いらず、うごく だけ なので 小さい 子でも すぐ あそべる。

## あそびかた

- 画面を おさえた ところが スティックの まんなか。ひっぱった ほうへ すすむ（やじるしキーでも OK）
- まものに ふれると HPが へる。🍙 で かいふく
- ⭐ / 💗 / ⚡ / 🪃 / 🌞 の わざ と、👟 🧲 🍙 💪 ⏱ の パッシブを そだてる（それぞれ Lv5 まで）

## わざ

| わざ | どうなる |
|---|---|
| まほうの ほし | いちばん ちかい てきに ほしを うつ（Lv が上がると ふえる・つきぬける） |
| ハートの わ | まわりを ハートが まわる |
| かみなり | 画面の てきに ときどき かみなり |
| ブーメラン | すすむ ほうへ なげて もどってくる |
| おひさま バリア | ちかくの てきに じりじり ダメージ |

## バランス

「てきから にげつつ ちかくの ほしを ひろう」じどう プレイで しらべた。
1〜2ステージは Lv 8〜16・400〜800ひき たおして クリア。3ステージめは ときどき まける くらいの むずかしさ。
てきが 270ひき でていても 60fps。記ろくは `localStorage`（`rinasurvivor.v1`）。
