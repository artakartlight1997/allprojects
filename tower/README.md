# あおいのハッピータワー

小学 4 年生の **あおい** が、タワーを のぼって にげるゲーム。
下からは **ママ** が「スイミングに いくわよー！」と 大きなふきだしを出しながら
上がってくる。つかまる前に てっぺんへ。**全 10 かい**。
とちゅうで お兄ちゃんの **まさき**、**パパ**、おともだちの **りな** に会える。
ぜんぶのぼると、じつは ゆめだった というエンディング。

ブラウザだけで動く（サーバー処理なし・インストール不要・ライブラリなし・**画像も音のファイルも 0 個**）。

https://artakartlight1997.github.io/allprojects/tower/

## 遊びかた

**そうさは 左右だけ。あしばに つくと かってに はねる。**

ボタンを押すタイミングを考えなくていいので、はじめてでもすぐ遊べる。
かわりに「どこに落ちるか」だけを考える ── そこがこのゲームのぜんぶ。

1. 左右の ◀ ▶ でうごく（画面の左半分／右半分をさわってもいい）
2. 下から **ママ** がのぼってくる。つかまるとハートが 1 つへる
3. ハートが 0 になる前に **てっぺんのゴール** へ！
4. あしばは 5 しゅるい（ふつう／うごく／こわれる／すべる／バネ）
5. **ほし** をあつめよう（とらなくてもクリアできる）
6. **かさ**＝ゆっくりおちる、**くつ**＝はやくうごける（どちらも 7 秒）
7. **おともだち** にふれるとたすけてくれる

パソコンは `←→`。

## ジャンプの高さと あしばの間かく

このゲームでいちばん大事な数字。

```
GRAV = 1250   HOP = 660
はねる高さ = 660 × 660 ÷ (2 × 1250) = 174 px
```

あしばのたての間かくは `gap × 0.86〜1.16` で、10 かい目でも最大 135 px。
**174 > 135** なので、どのあしばにもかならずとどく。

よこも同じ考えかた。前のあしばから **±130 px** の中にしか置かない。

```
上がる時間 0.53 秒 ＋ つぎのあしばの高さまでおちる時間 ≒ あわせて 0.8 秒
よこにうごける きょり = 290 px/s × 0.8 秒 ≒ 230 px
あしばの半分 42 px も足せば、130 px はよゆうでとどく
```

最初に作ったときは `HOP = 470`（高さ 88 px）で、間かく 96 px にとどかなかった。
**どうやってもつぎへ行けない**ゲームになっていて、自動テストが 0/50 で気づいた。

## 「とどかないならび」を作らないために

タワーは面ばんごうから作った**たねつきの乱数**で組み立てる。
だから同じ面はなんど遊んでも同じならび（おぼえてうまくなれる）。
そのぶん、**1 か所でも通れない場所があるとその面は永久にクリアできない**。

そうならないように 4 つ決めてある。

1. 一番下は **タワーのはばいっぱいのゆか**。最初のひとはねをミスしても下にぬけない
2. はじめの 2 まいは **かならずふつうのあしば**
3. うごくあしばは **もとの場所の ±56〜82 px** しかうごかない。
   タワー全体をうろうろさせると、±130 px で置いた意味がなくなる
4. こわれたあしばは **5 秒でもどってくる**。もどらないと、下に落ちたときに
   のるものがなくなって手づまりになる

3 と 4 がなかったときは、4・9・10 かいが自動テストで 0/5 だった。
入れたら 50/50 になった。

## ママ

| | |
|---|---|
| はやさ | 1 かい目 78 px/s → 10 かい目 136 px/s |
| じょうずにのぼると | 1 秒に 120〜150 px |
| はなれすぎたら | 1.45 倍で追ってくる（ずっと安全にはならない） |
| 近すぎたら | 0.82 倍にゆるめる（一気に終わらせない） |

ママより下に落ちても つかまり。**ママがゆかのかわり**なので、
下にぬけて「なにもできないまま終わる」がない。
つかまるとハートが 1 へって、210 px 上へにがしてもらえる。

4.2 秒ごとに大きなふきだしでさけぶ。ふきだしは**画面の上**に出す
（下に出すと、あおい本人がふきだしでかくれてしまう）。

```
スイミングに いくわよー！ ／ 合気道に いくわよー！ ／ 習字の 時間よ〜
ピアノの れんしゅうは？ ／ しゅくだい やったの〜？ ／ おかたづけ してからね！
つぎ そろばんよ〜 ／ えいご きょうしつ〜！
```

近づくと BGM もあつくなる（`bgmHeat()`）。画面の下の「ママ あと ○m」も
近いほど色がこくなって点滅する。ふりむかなくても「ヤバい」が伝わるように。

## むずかしいときの てだすけ

- 同じかいで **2 回つかまると**：ハートが 1 つふえる／ママが 120 px 下からはじまる
- **4 回つかまると**：ママがさらに 120 px 下から
- **3 回つかまると**：つぎのかいがひらく（クリアしなくても先へすすめる）

## エンディング

10 かい目をのぼると見られる（タイトルからもいつでも見られる）。
4 まいで、だんだん朝の色になっていく。

1. ママの声で目がさめる（あおいはベッドの中、Zzz）
2. タワーもふきだしも ぜんぶゆめだった
3. 「へんな ゆめ みちゃった」
4. パパ・ママ・あおい・まさき 4 人ならんでニコニコ。きょうは日よう日

おいかけているあいだのママは「まじめな口」で描いているけれど、
エンディングでは `happy` を立てて にっこりにしている。

## 画面の作りかた

たてを **VH = 450 に固定**してから拡大するので、どの端末でも同じ見た目・
同じむずかしさ。よこの 0 は「タワーのまん中」、たての 0 は「一番下」で
**上がプラス**。描くときだけ `sy()` でひっくり返す。

たてに持つと「よこ向きにしてね」と出る。

## テストのしかた

`tower/site/` を http で開いて、Playwright から `update()` を手で回す。
**じどうでのぼるロボット**に 10 かい × 8 回あそばせて勝率を見る。

ロボットは「はねたしゅんかんに つぎにのるあしばを 1 つ決めて、
そこへ向かって速度をあわせる」だけ。うでまえは「はねるごとに 1 回、
まちがった向きに 0.2〜0.5 秒うごいてしまう確率」で表す。

| うでまえ | 勝率 |
|---|---|
| 0.95（じょうず） | 58/60 |
| 0.70（ふつう） | 71/80 |
| 0.55（にがて） | 43/60 |

上がっていくとちゅうで目うつりして、**とどかないあしばを追いかけて落ちる**
のがロボットのいちばんのミスだった。人も同じミスをするので、
あしばの間かくはそれを見こんで決めてある。
