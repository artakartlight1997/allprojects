# りなの モノレール運転士

「電車でGO!」みたいな **うんてん ゲーム**。りなが モノレールの 運転士に なって、
レバーで スピードを かえ、えきの「とまれ」の いちに **ぴったり とめる**。

https://artakartlight1997.github.io/allprojects/train/

## あそびかた

- みぎの レバー（ドラッグ）か「▲ すすむ」「▼ とめる」ボタン、やじるしキーの ↑↓ で うごかす
  - **P1〜P4**：かそく（P4 が いちばん つよい）
  - **N**：なにも しない（すこしずつ おそく なる）
  - **B1〜B7**：ブレーキ　**EB**：ひじょう ブレーキ
- 「のこり ○m」を 見ながら ブレーキを つよく したり よわく したり して、スピード 0 で「とまれ」の いちへ
- **せいげん そくど**（まるい ひょうしき・メーターの あかい ところ）を こえると げんてん。
  10km/h いじょう こえると ATS で じどう ブレーキ
- ずれ 0.5m いない＝ぴったり！／じかん どおり／せいげん まもる で ★3つ
- 雨の 日は ブレーキが すこし ききにくい。よるや きりの コースも ある
- 「けいてき」ボタン・スペースキーで ファーン

## コース

千葉都市モノレール 2号線の えきの じゅんばん（千城台 → 千城台北 → 小倉台 → 桜木 → 都賀 → みつわ台 → 動物公園 →
スポーツセンター → 穴川 → 天台 → 作草部 → 千葉公園 → 千葉）の 12くかん。
**きょり・せいげん そくど・じかんは ゲームの ための もので、ほんものとは ちがう。**
千葉の モノレールは レールに ぶらさがって はしる かたちなので、まどの 上に レールが 見える。

クリアした くかんと ★の かずは `localStorage`（`monorailgo.v1`）に のこる。つぎの くかんは まえを クリアすると ひらく。

## しくみ

1びょう ごとの かそくど（km/h）を レバーで きめて、スピードと すすんだ きょりを けいさん。
けしきは「とおくの ものほど 小さく、まんなかに よる」けいさん（とうし ずほう）で かいて いる。
